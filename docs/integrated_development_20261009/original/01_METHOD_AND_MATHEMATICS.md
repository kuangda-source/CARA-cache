# WorldCache＋RA：联合近似、稀疏刷新与多精度调度的统一方法设计

**日期：2026-10-09｜版本：v1.0｜性质：方法开发方案，不是实验结果或 GPU 执行授权。**

## 0. 研究决定

以当前 WorldCache/Cosmos 实现为执行基础、以正确本地化的 RA-CFGCache 为联合控制基线，同时推进三个相互依赖的部件：

| 部件 | 对应原路线 | 新开发目标 |
|---|---|---|
| A：CFG 协调的预测与修正 | W1 | 让缓存近似服务最终 guided 输出，而不是两个分支各自优化 |
| B：成本可控的近似刷新 | 稀疏注意力／稀疏缓存 | 联合稀疏 attention、部分 MLP 更新，构成可执行的中间精度动作 |
| C：来源质量感知的多精度选择 | W3 | 在复用、修正复用、近似刷新、dense 刷新之间选择，同时维护缓存来源误差 |

暂名：**CFG-Coordinated Multi-Fidelity Refresh**。名称只作项目交流，不能据此宣称首创。

中心问题不是“历史是否比 RA 更有预测力”这一条窄假设，而是：**在 CFG 联合误差约束下，怎样协同决定读缓存的近似方式、刷新覆盖范围和刷新精度，获得更好的实际质量—时间前沿？**

三模块进入同一个开发周期；不要求每个模块先单独超过所有基线，才允许组合。开发可以有针对性地迭代。证据与消融用于解释改进，不作为无限期推迟完整方法的前置考试。

## 1. 事实基础与边界

本地事实来自用户上传的《WorldCache_阶段实验总结与研判材料_20261009(1).md》（以下简称 U1），未独立查询其私有仓库、视频与实时 GPU。

- U1 §2：Cosmos-Predict2.5-2B，A6000；28 个 block，前 2 层浅 probe、后 26 层深计算；768×432、93 帧；UniPC/Karras 实际 36 更新、72 个 CFG 调用。当前是 text2world，无参考图条件。
- U1 §3：W1 当前全局标量近似有明显局部信号，但七个接受视频 4 正 3 负，平均 LPIPS 下降仅 0.4388%。自身轨迹反例说明并非只有 off-policy 问题。
- U1 §4：已有 SpargeAttn 改 attention 边，不改 MLP；整组约省 5.33%，完整视频约省 0.29%／1.41%，覆盖率窄，mask 每次重建。
- U1 §7：实际 CFG 为 c+7(c−u)=8c−7u；三条已曝光轨迹出现强误差抵消。
- U1 §8：联合接口的真实局部和 Toy CPU 测试通过；真实完整策略等价仍待必要控制；已保存审计余额约 20.1048 GPUh，并非实时余额。

这些结果支持开发更合理的组合，但不证明组合已有效。局部误差、完整视频保真、绝对质量与实际延迟分别报告。

## 2. 与已有工作的关系

- **WorldCache [R1]** 提供探测、近似、阈值和执行基础。迁移后仍需本地公平比较；原方法不是“没有调度”。
- **RA-CFGCache [R2]** 提供 CFG 联合风险、传播校准和二元共同刷新。直接借用这些思想构建基线；不能宣称“我们首次考虑 CFG 耦合或传播”。
- **ToCa [R3]** 已有 token 特征缓存、模块差异与 CFG 同选择经验；**RAS [R4]** 已有活跃 query＋完整／陈旧 K/V 上下文；**DuCa [R5]** 已有不同缓存粒度的组合并强调随机／多样性对照。这些是可复用的技术基础，不是禁止进入部分刷新领域的理由。
- **SpargeAttn [R6]** 提供真实块稀疏核；**SpargeAttention2 [R7]** 支持将稀疏近似通过蒸馏式微调进一步改进。作者其他模型与硬件上的数字不能当成本地目标已达成。

本项目应争取的差异是：**CFG 协调的修正和近似刷新，配合显式记录近似来源质量的多精度控制，优于直接把这些组件串起来的组合。**“三级缓存”“共用 mask”“增加 MLP”均不足以单独充当全部创新。

## 3. 统一动作与状态

### 3.1 首版动作表

| 动作 | 真正计算 | 更新什么 | 主要误差 |
|---|---|---|---|
| C | 前两层 probe＋原缓存路径 | 可更新观察统计，不假冒新真值 | 漂移和既有来源误差 |
| A | C＋小型 W1 修正 | 近似读出；默认不改写 dense 真值 anchors | 修正误差、原缓存漂移 |
| S(ρ) | 后 26 层以指定稀疏／部分算子执行 | 新的近似工作缓存 | attention 裁剪、未更新 MLP、上下文陈旧等 |
| D | 当前两 CFG 分支真正 dense 深算 | 工作缓存和真实 dense 校准 anchors | 同当前状态、同参考后端下的创建误差为零 |

S 可以有两个执行档，而不是立即开放连续密度。首版优先联合动作 C/C、A/A、S/S、D/D。旧接口仍保留四分支动作能力以忠实执行原 WC；不把“接口支持四动作”变成“新控制器必须训练所有交叉组合”。

动作成本顺序是预期，不是事实；必须测量。S 若在当前形状更慢，控制器不应仅凭名字选择它。

### 3.2 双层缓存语义

保持两个概念分离：

1. **dense 校准 anchors**：只由匹配的真实 D 写入，供 W1、proxy 校准等使用。
2. **工作缓存**：可以来自 D、S 或部分更新，必须附带来源、最近实际更新时间、密度、质量估计与版本。

粗粒度 metadata 即可起步，不必立即给每 token 建复杂数据库。引入部分 MLP 时，再为选定层／块维护更新时间和来源。

`age=0` 只表示刚刚更新过，不表示相对 dense 真值无误差。部分 token 被实际重新计算，但其上游若近似、K/V 若陈旧，同样不是精确 teacher。

若 MF 仅表示“与 S 同量化后端、但保留全部 attention 边”，它不自动与原生 D 等价；后端差异仍须单独记录。

## 4. 数学连接：CFG 协调适用于修正和稀疏，而不只适用于调度

令当前输出误差为 e_c、e_u。实际合成误差为：

\[
e_g=8e_c-7e_u.
\]

定义共同和差异分量：

\[
e_m=(e_c+e_u)/2,\qquad e_d=e_c-e_u,
\]

则严格有：

\[
e_g=e_m+7.5e_d.
\]

所以“各分支误差较小”不是唯一目标；分支差异误差可能被强权重放大。这不是一条新的 CFG 理论，而是将已知结构落实到 W1 和便宜刷新算子的设计上。

### 4.1 理想共享输出 mask 的诊断恒等式

若在**最终预测输出坐标**用相同二值 mask M，将被选区域替换为当前真实输出，其他区域复用，则：

\[
e'_c=(I-M)e_c,\quad e'_u=(I-M)e_u,
\]

\[
e'_g=(I-M)(8e_c-7e_u).
\]

这说明共同刷新区域可避免人为造成两分支覆盖不一致。若 masks 不同，则没有上述简化。

**限制：**这只是理想输出替换的恒等式。真实稀疏 attention、部分 MLP 和 hidden mask 会通过非线性与跨 token 作用改变输出，共用 mask 不保证误差相关性更好。完整 dense 后 blend 可作诊断，不能作为加速实现；诊断 top-k 不是全局最优 oracle。

## 5. A／W1：从分支标量改为 CFG 协调修正

### 5.1 保留并解释现有信息

U1 定义 p=h2−h0、r=h28−h0。令 d=h28−h2，则 r=p+d，现有：

\[
\hat r_t=r_b+\beta(p_t-p_b)
=p_t+d_b+(\beta-1)(p_t-p_b).
\]

因此 β=1 是强且廉价的对照：使用真实当前浅层增量，复用旧深层增量。它不代替现有 W1，更不证明现有收益都是恒等项；应以实验区分。

首批不改 warp 位置。不能同时把整栈 warp 改成仅 deep 增量 warp，再把收益归因于 β。

### 5.2 首版实现：共同修正强度

先计算原缓存分支输出 v_b^0 和现有 W1 分支输出 v_b^1，定义 q_b=v_b^1−v_b^0。首版候选：

\[
v_b(\alpha)=v_b^0+\alpha q_b,\qquad 0\leq\alpha\leq1,
\]

两分支共用 α。这里是**输出空间融合**，不假定经过 warp／norm／head 后仍等同于 hidden 空间线性融合。

若同时评估两个 head 路径的实际开销不合算，则回到 warp 前系数参数化，以有限配置实测实际输出；不要声称两种参数化数学等价。

可用少量校准状态选择 α∈{0,0.5,1}，或拟合一个共享系数；随后才加 2–3 个采样阶段。现有 β、β=1 均保留作对照。

### 5.3 小参数联合监督

真实 teacher 只在离线诊断或已经合法执行的 D 上取得。目标：

\[
\mathcal L=\|8(v_c-v_c^*)-7(v_u-v_u^*)\|^2
+\lambda(\|v_c-v_c^*\|^2+\|v_u-v_u^*\|^2)
+\mu(\alpha_c-\alpha_u)^2.
\]

先共用 α，再允许两个受约束系数。分支项不是为了重新否定 guided 目标，而是避免只优化秩一二次型时出现两个分支大误差相互抵消的病态解。

在共享 α、忽略附加正则时，令 e_g^0 为原 guided 误差、q_g=8q_c−7q_u，校准集上的一参数最小二乘解为：

\[
\alpha^*=\operatorname{clip}\left(-\frac{\sum\langle e_g^0,q_g\rangle}{\sum\|q_g\|^2+\epsilon},0,1\right).
\]

这给出一个可以直接实现的低成本方法，不需要完整生成器反传。系数用于未见状态时仍需闭环校验；本式不保证 LPIPS 单调改进。

对 q_g 极小或有效数据不足的情况回退原近似；不能用当前 cache hit 的隐藏 teacher 偷偷拟合 α。D 时记录“决策前的预测—执行后的真值”可更新未来校准。

### 5.4 与 S 的连接

A 最先改善 C 路径。之后比较：从 D 工作缓存读取时的修正，与从 S 工作缓存读取时的修正是否需要不同强度。初版只增加一个来源类别，不先做每层×每 token×每阶段的大模型。

不要混用来自不同近似器／来源的风险校准。A 与 S 可能互补，也可能互相抵消；这一交互是研究内容。

## 6. B／稀疏：按四个层次开发，不混淆内存与计算

### 6.1 S0：已有 attention 边稀疏，作为可运行起点

保留完整 Q/K/V，跳过部分 QK、PV 交互。现有算子和逐层敏感性结果直接复用。当前 6、23、27 的保护结论针对 attention，不自动证明这些层的 MLP 也必须禁止部分计算。

### 6.2 S1：CFG 协调的 attention mask＋有限复用

第一改动是比较独立 masks 和共同 masks，在**相同实际保留边数／近似延迟**下衡量实际 guided 误差。

**实际接线顺序必须明确。** 当前成对接口只保证两侧浅层 probe 先可见，不自动保证每个深层的两侧 Q/K 同时可见。若深层仍按 c→u 顺序执行，首版可由 c 当前层生成 mask 并缓存，u 的对应层使用同一 mask、自己的当前 Q/K/V。这是可立即实现的 conditional-led shared mask；它可能偏向 c，需测 guided 输出，不宣称自动最优。

下一版才考虑深层按层交错，或合适 batch 化，在各层同时取得两侧粗 Q/K 统计，再用 max／受限 union 构成 mask。必须计入新峰值显存、两侧统计和执行顺序成本，不能把这项能力写成浅层 paired 接口已经提供。union 需控制实际密度，否则质量优势可能只是多算。

只有 S 已被上层选中后，才计算该 S 所需的深层 Q/K 粗统计；这些不是选择 C/S 前免费的信息。

第二改动是对 mask 缓存 2 或 4 次实际 S 执行机会，并用廉价漂移／最大年龄触发重建。必须记录跨越了多少去噪时间和 cache hits，不能只记 S 调用计数。attention 内容仍用当前 Q/K/V；重用的是拓扑，不是直接声称重用 attention 输出。

该动作可减少选择器开销，但不能保证显著加速。现有研究已涉及稀疏模式复用；它应成为系统部件或比较对象，不单独包装成全部创新。

### 6.3 P0：优先新增的“部分 MLP 刷新”

每个参与层仍保留完整 token 上下文，先用完整 attention，MLP 只对活跃时空块执行；非活跃部分复用该层缓存输出。先不改 attention K/V 语义。

若 F_l 是该层 token-wise MLP，则：

\[
\hat F_l(X)[M_l]=F_l(X[M_l]),\qquad
\hat F_l(X)[\overline M_l]=F_{l,\mathrm{cache}}[\overline M_l].
\]

随后正常 residual、门控与后续层。优先缓存投影后的 MLP 非线性输出，当前时间调制／gate 在正确边界重新应用；具体边界按实际源码核对，不能混用旧时间 gate。

这是实际跳过非活跃 token 的 MLP GEMM，而不是全量计算再 blend。gather/scatter 和当前规范化也计时。

先选 4–8 个测得 MLP 占比高、可用显存允许的层。只保留 ρ_MLP∈{0.5,0.75} 两档活跃比例。先同配额随机／轮换块，再加入少量风险块选择。首版共同活跃集合由已可见的双 probe、过去 metadata 或轮换表产生，不依赖尚未运行的另一分支深层 MLP 输入。全 attention 的 P0 可运行后，再接 S1，得到“边稀疏 attention＋部分 MLP”的 S 执行档。

粗略成本模型为：

\[
C_{P0}\approx C_{\mathrm{attention}}+\rho C_{\mathrm{selected\ MLP}}
+C_{\mathrm{other}}+C_{\mathrm{selection}}+C_{\mathrm{gather/scatter}}.
\]

这里的 selected MLP 只包含实际允许部分执行的层；不能拿整个主干 MLP 占比套到只改四层的配置上。

新增缓存容量先估计：

\[
M_{\mathrm{MLP}}\approx2L_sNd\cdot b_{\mathrm{elem}},
\]

其中 2 表示 CFG 分支，L_s 为选中层数，N、d 必须读取运行张量。不要存完整 MLP 扩展中间维，不默认 A6000 能装下全部 26 层副本；把容量、带宽和峰值实测纳入选择。

### 6.4 P1：全深层的活跃 query／token 刷新

这是更高上限的后续执行器，不是第一批的必要重写。活跃 Q 访问当前活跃 K/V 与缓存非活跃 K/V：

\[
O_M=\mathrm{softmax}(Q_M K_{\mathrm{mixed}}^\top/\sqrt d)V_{\mathrm{mixed}}.
\]

需要逐层 K/V 和适当的输入／输出缓存，真实处理位置编码、文本上下文与 time modulation。复杂度、显存、上下文陈旧均明显不同于当前整栈残差缓存。RAS 是直接先例 [R4]，不是当前项目已具备的能力。

先完整跑 26 层，再拿部分 token 输出更新缓存，不算 P1 加速。

### 6.5 选择更新区域

优先规则：对齐硬件块的时空分组；CFG 共用更新集合；保留轮换／均匀覆盖以防永久不更新。浅层差异、块年龄和来源质量可作 proxy，但不能把 hidden 的 8/−7 组合当作真实 guided 输出误差。

同配额比较：随机、均匀轮换、低成本风险选择。DuCa [R5] 表明随机是必须认真对待的强对照。若随机很好，就保留它，方法贡献可以来自联合控制和质量管理，而不是必须发明复杂 saliency。

## 7. 最关键的共同变量：新缓存的可用寿命

假设一次 a 类刷新成本为 c_a，之后允许总共 K_a 个调用构成一个更新周期，其他调用复用成本 c_C。在相同质量目标、近似稳定周期假设下：

\[
\bar c_a=\frac{c_a+(K_a-1)c_C}{K_a}
=c_C+\frac{c_a-c_C}{K_a}.
\]

所以便宜刷新未必省整段时间；它可能导致更早再次刷新。反过来，W1 若让近似源更好用，可能使相同 S 的长期收益增加。这是三部件应当共同开发的理由。

该式只是周期平均模型，不是对自适应生成的严格定理。真实 K_a 由轨迹、CFG 和控制器共同决定，最终以完整运行验证。

建议新增一个方法级图：横轴创建成本、纵轴在指定保真条件下的后续复用长度，对比 D、原 S、CFG 协调 S、S＋修正。不要用单步 relative error≤5% 代替终点保真条件。

## 8. C／W3：RA 基础上的多精度选择

### 8.1 第一版不必学习昂贵终点 Q 函数

复用 RA 的联合风险与传播先验 [R2]，给动作 a 建立自己的 proxy 标定：

\[
\hat q_g(a)^2=64\hat q_c(a)^2+49\hat q_u(a)^2
-112\hat\rho(a)\hat q_c(a)\hat q_u(a).
\]

每个 proxy 明确依赖该动作、工作缓存来源和年龄。它是经验风险，不是精确误差或质量保证。

初版策略可用：

\[
a_t=\arg\min_{a\in\mathcal A_t}\{\hat g_t\hat q_g(a)+\lambda\hat C(a)+\nu\hat B(\text{post-cache},a)\}.
\]

B 是新缓存来源质量／预期再刷新需求的低维惩罚，初版可由少量来源类别和年龄参数给出。各项标准化后在 CAL 选择少量权重。该公式是拟议控制启发式，不宣称 Bellman 最优。

更简单的实现是：在几档可行动作中选择预计风险可接受的最便宜档，再以来源质量惩罚约束频繁 S。二者选一，不同时开发两个大控制器。

### 8.2 近似刷新不能无条件清零

误差可概念化为：

\[
e_{t}\approx \text{创建误差经坐标变换后的项}+\text{后续漂移项}.
\]

D 消除同当前状态下的创建近似误差，不清除此前 latent／solver 偏移。S 产生新的近似来源，创建误差非零；P 的新计算部分也受上游近似影响。

因此区分：来源质量、工作缓存年龄、控制器区间累积量。RA 的区间分数是经验控制量，不是历史终点误差真值。允许经校准的重新基准化，但不可以仅因执行 S 就把来源误差和历史风险全记为零。

这里形成一个明确新增部件：**近似源更新合同＋来源条件化风险控制**。要与“RA 触发时机械替换成 S”“每次 S 当作 D 重置”的朴素组合比较，而不仅与原 WC 比较。

### 8.3 训练是工具，不是禁区

少参数系数、几档查表和小 MLP 都可在本轮使用。大模型冻结；第一版不需要 LoRA，也不需要先训练完整终点 critic。

若规则运行后明确出现可学习差异，再用同状态动作数据拟合小型 action-risk head。若稀疏算子在较高稀疏率下表现为稳定系统性偏差，可比较少量 adapter／LoRA 蒸馏式修正；它是计划内后续选项，受显存、数据与收益实测约束。

不把理论证明或大规模 oracle 搜索设为任何学习模块启动的通用前置条件。

## 9. 论文组织与可验证主张

论文愿景：**在 CFG 下把缓存读出精度、刷新覆盖范围和近似源质量作为一个协同控制问题。**

三个对应主张可以是：

1. CFG 协调修正比独立分支修正，在相近开销下更稳定地保留 guided／终点信息。
2. 联合稀疏与部分 MLP 执行器，在质量条件下产生真实更便宜、仍可复用的更新。
3. 来源质量感知选择，优于固定刷新档位与简单组件串联，并改善完整质量—实际时间前沿。

这是有足够方法与实验空间的论文规划，但“有三模块”不是投稿充分条件。需要越过的是有竞争力的组合基线，解释协同，而不是要求每个模块完全原创或单独成为一篇论文。

主结果至少展示调优 WC、合理校准 RA、直接 RA＋相同算子组合、最终方法。部分 token 工作为主贡献时增加 ToCa／DuCa 风格部分 MLP 控制；全深层 token 方案进入时再增加 RAS 相近实现。

正式确认时使用未曝光提示词、多个 seed、至少三档实际时间工作点；补绝对质量／运动守卫、重复计时、显存及一项模型／设置迁移。当前约 20 GPUh 是开发窗口，不是完整投稿实验预算。
