# 方向 B：OMR 优化——细分实验计划

**日期：2026-10-02｜版本：v1.0｜状态：资源与本地教师效果待核实**  
**上位规则：00；共用协议和来源：04；纠正执行器蒸馏接口：03。**

## 1. 核心目标和不做的事

在真实有效的 OMR 教师基础上，验证：

**效率目标：**在预先规定的质量容忍范围内降低真实总时间。  
**质量目标：**在匹配总时间内提高语义遵循 SA、物理常识 PC 及二者同时达标的 Joint。

OMR 用冻结的生成器、latent-to-embedding adapter 和 JEPA predictor，在部分去噪步添加纠正；其方法不是“再训练一个视频生成器”。[R2]

不把“JEPA 能量下降”“更接近 OMR 视频”“adapter cosine 更高”单独作为最终成功标准；更好的纠正可能使视频远离原生参考。不要使用 WorldCache 的 LPIPS-to-Native 作为本方向唯一主要指标。

首轮不训练新 adapter，不把原生 latent 当作无条件匹配的跨模型表示，不把 Wan2.2-A14B 的 adapter 直接套到 Wan5B/Cosmos 上。

## 2. OMR-O0：资源是第一道硬门槛

### 2.1 资源核实表

截至 2026-10-02，本次读取的 OMR 官方项目页仍将实现、配置、prompt 清单和 adapter 列为 Coming soon。[R2b] 用户本地或私下获得的资源可能不同，以实际文件为准。

| 依赖 | READY 的证据 | 未满足处理 |
|---|---|---|
| 原始生成器与 VAE | checkpoint、hash、参数化与成功生成 | BLOCKED 或保留原生准备 |
| 对应 generator 的 adapter | 可信权重、输入输出 grid、匹配预处理 | 不用随机权重冒充复现 |
| 对应 JEPA predictor | 版本、mask/window、层输出维度一致 | 不随意替换另一个 JEPA 版本 |
| OMR 更新与 schedule | guidance band、eta、时间/步长约定明确 | 先形成参数契约再运行 |
| 提示词与评测 | 样本 ID、评分版本、seed 明确 | 自建集须标不同设置 |
| 显存/卸载 | 实测峰值和可靠执行 | 按现有权限选支持平台 |

状态用 READY / PARTIAL / BLOCKED。PARTIAL 可以做代码映射和原生计时，但不允许写“OMR 复现完成”。联系作者需另有外部发信授权；本包不发信。

### 2.2 平台选择

第一选择是本地已经拥有匹配 adapter 且能稳定运行的设置。论文列出的 Wan 主配置与 CogVideoX 配置成本不同，且 adapter 不共享。[R2] **有一个能装进显存的生成器，不等于有对应的 OMR 教师。**

双卡分片/offload 是技术选择，比较方法必须一致并计入通信。使用较小配置时，标记为机制筛查或迁移设置，不冒充论文主结果。

论文分数不作为本地固定起点。400-prompt 质量结果与50-prompt效率结果来自不同子集，不得拼出一条本地质量—时间曲线。[R2]

## 3. 更新规则与两个“未来”的区分

以 clean time \(t\) 说明，令 \(x=\hat z_{\mathrm{clean}}\)，\(e=A_\psi(x)\)，上下文 token 为 \(e_C\)，视频未来 masked token 为 \(e_M\)：

\[
E(x)=\|P_\phi(e_C,\delta_M)-e_M\|^2,\qquad g=\nabla_xE(x).
\]

按 OMR 的 operator-splitting 记法：

\[
z_{n+1}=z_n+h_nv_\theta(z_n,t_n)-\eta_ng_n.
\]

\(\eta_n\) 已包含其定义下的步长处理，不得随意再乘一次 \(h_n\)。原文以 clean time 描述，代码可能使用 reverse noise level；必须核对转换。[R2, §3.2]

**目标侧梯度中的“未来”是视频内的 masked future tokens，不是未来几个去噪步骤。**多步去噪 rollout 是另一种价值验证，二者不混用。

### 3.1 为什么目标侧梯度可能便宜，也可能改变效果

记 \(d=P(e_C)-e_M\)，则全梯度可写为：

\[
g_{\mathrm{full}}=2J_C^\top J_P^\top d-2J_M^\top d.
\]

若只把 predictor 输出视为常量：

\[
E_{\mathrm{target}}=\|\operatorname{stopgrad}(P(e_C))-e_M\|^2,
\qquad g_{\mathrm{target}}=-2J_M^\top d.
\]

这是一个修改过的更新规则，不是全梯度的恒等变形。全能量在 \(-g_{\mathrm{target}}\) 方向局部下降，还需要 \(\langle g_{\mathrm{full}},g_{\mathrm{target}}\rangle>0\) 以及合适步长；并无一般保证。

停止上下文分支梯度也不意味着历史视频 latent 完全不变，因为 adapter 的感受野可能跨时间。严格保护历史需要额外 latent mask，并单独消融。

### 3.2 为什么梯度复用可能有效

若 \(\nabla E\) 在局部是 \(L_g\)-Lipschitz，则：

\[
\|g(x_n)-g(x_s)\|\le L_g\|x_n-x_s\|.
\]

它只是条件性依据；没有测得 \(L_g\) 时不能称为保证。相似方向也不保证最终任务更好，必须比较同次数的“刷新后保持”和“刷新之间不纠正”。

### 3.3 先算加速空间

设原 OMR 时间为 \(T_0+C\)，其中 \(T_0\) 是原生生成和固定开销，\(C\) 是纠正路径开销。如果只加速其中占总时间 \(f\) 的部分，即使该部分完全消失，理论总加速也不超过 \(1/(1-f)\)。

因此，predictor backward 若占很少时间，O2 不可能单靠移除它带来巨大的总速度收益。必须先计时，再决定主要投入方向。

## 5. OMR-O0S/O0Q：先建立有效教师

### 5.1 技术 smoke

四个开发场景，对比 Native、原始 OMR、纠正系数为零的接入版。确认置零路径不意外改变随机性、solver 或输出；确认未对生成器反向传播，且没有跨步保留巨大 autograd graph。

记录 generator、adapter forward/backward、predictor forward/backward、通信/卸载、VAE decode、部署统计的时间。无法直接算子拆分时用可信 ablation 测量，避免把模块计时相加两次。

### 5.2 教师收益筛查

从预登记的开发场景中取16，配对 Native/OMR，覆盖接触、遮挡、运动与形变等，但不要只挑论文或自己已知“OMR能修好”的样本。输入类别不是训练专家标签的自动真值。

主要报告 SA、PC、Joint、严重退化、盲评纠正方向、实际时间。展示原生正确被改坏与原生错误被修好的数量。

16/32 场景不足以稳定检出几个百分点的改变。不显著不等于无效；反之，少量漂亮案例也不构成可重复教师证据。先区分实现偏差、评分不可靠、效应小和任务不匹配，再决定是否购买更多样本。

**O1 的低成本筛查可在教师尚处小样本不确定时进行；但大规模蒸馏必须等待教师有足够可信收益。**

## 6. OMR-O1：稀疏纠正基线

### 6.1 唯一改变

保留原 guidance band，比较每个允许步调用、每2步调用、每4步调用；间隔必须按实际可用步数定义。未调用步不纠正。

先8个校准场景筛选，再16个验证场景。若已有强稀疏基线，复用结果。

### 6.2 两个强度口径

**固定单次强度：**调用步保留原 eta，检验冗余和可能过度纠正。

**强度控制：**在相同数目的小型 eta 候选集合上，为完整/稀疏方法分别校准；或预先设计累计 eta 对照。非线性状态更新下，相同累计 eta 不意味着相同纠正效果；不能称为严格等价。

建议强度网格从原强度的 {0.5,1,2} 倍起，只在校准侧，先做早停式小筛查而非全组合生成。遇到爆炸/退化按预登记规则停止，不继续盲扫。

### 6.3 决策

只要简单稀疏在相近任务表现下省时，就成为所有高级方法必须超过的基线。不能故意只和“每步完整 OMR”比来突出复杂方法。

## 7. OMR-O2：目标侧梯度

### 7.1 实现契约

生成器速度 detached；clean estimate 作为本轮 guidance leaf；adapter 的目标 token 仍保持可微。predictor 前向可以无梯度，但不能把整个 adapter 输出都 detach 后还期待有有效目标侧更新。

原始和目标侧方法先使用相同 guidance steps、mask、window、eta。只改梯度路径，不同时稀疏。

### 7.2 三组关键对照

A：原始全梯度；B：目标侧原强度；C：目标侧在相同调参预算下校准 eta。可在少量诊断状态另外做范数匹配，区分方向改变和幅度缩小。

记录 \(\cos(g_{full},g_{target})\)、范数比、上下文/目标两项的夹角与抵消程度，以及动作后局部能量和终点任务表现。

范数匹配若需要额外全梯度，只能当离线诊断，不能不计成本搬到部署。若 predictor backward 节省有限，O2 可作为质量候选而非主要速度候选。

### 7.3 允许的结论

可以说“这一配置下目标侧更新保留了大部分任务收益并降低成本”；不能说“原始梯度无损压缩”或“物理正确性由梯度保证”。

## 8. OMR-O3：梯度保持、衰减与刷新

在和 O1 相同的新梯度调用次数下，比较：

- S：中间步不纠正；
- H：中间步复用最近 detached 原始梯度；
- D：按 cache age 对旧梯度衰减；
- A：仅在简单已有信号触发时刷新，后置候选。

第一轮只做 S/H/D 中最小集合。复用原始 \(g_s\) 时使用当前 \(\eta_n\)，不盲目复制旧的最终 delta。若定义为复用已缩放 delta，则必须显式说明新的归一化规则并单独比较。

首次进入 guidance band 需要真实教师；跨条件、mask/window、分辨率、expert 或出入 band 时按预登记规则重置。任何必须额外 full teacher 的保护动作记入成本。

梯度相似度诊断在少量状态追加真值，不参与在线刷新。若每步先运行完整 predictor 才决定是否复用，把这项开销如实算入；默认优先用已有 latent/velocity 统计。

**O3 的核心胜负不是打败完整 OMR，而是同教师调用次数下胜过 O1。**否则更简单的稀疏纠正已经足够。

## 9. OMR-O4：只有方向瓶颈明确才微调 adapter

### 9.1 先诊断而不是先训练

对预选32–64个生成中间 clean estimate，参考路径用 decode→真实 JEPA encoder→同 predictor energy。用单位方向 \(d\) 做有限差分：

\[
D_dE_{ref}(x)\approx\frac{E_{ref}(x+\epsilon d)-E_{ref}(x-\epsilon d)}{2\epsilon}.
\]

先检验 epsilon 的数值稳定区间。方向可取归一化的 adapter 梯度和固定随机方向；不以随机方向相关性代替实际纠正方向效果。

参考能量只反映同一个 learned prior 的一致性，不代表物理真值。有限差分避免完整参考反向，但 decode/encode 前向依然昂贵，必须计账。

### 9.2 解锁训练的条件

有证据显示 adapter 在部署状态上的方向偏差影响后续结果，而不是仅 embedding 拟合不够漂亮；且已有匹配 adapter 可微调。

先做128–512开发状态的有界微调，保留原训练域回放，比较原adapter/仅状态适配/方向监督。预算不足以支持数据多样性时不声称该规模足以训练可靠adapter。

主干仍冻结。改变 adapter 后，旧梯度标签和学生权重不再自动有效，必须版本化并复验。

## 10. OMR-O5：移交给纠正蒸馏

教师输出优先定义为实际更新增量：

\[
y_T=\delta_n^T=-\eta_ng_n,
\]

或者把幅度与方向分开并在重建时严格使用同一约定。训练目标不是“世界物理规律向量”。

移交 03 中 EX-O1，先单学生，再专家。必须同时带上：匹配的模型/adapter、mask/window、guidance时间、原始/目标侧教师版本、标准化、学生可用输入、教师标签成本、训练/验证分组。

主强对照：原始教师、已优化稀疏教师、梯度复用、纯学生、周期教师刷新+学生。不同方法按真实总时间而非单看学生 forward 比较。

不把 E-W 的缓存残差标签和 E-O 的纠正增量混成一个通用回归标签；它们的坐标、语义、教师和目标不同。

## 11. 评价与投入门槛

### 11.1 主任务指标

沿用一个版本固定的 SA/PC/Joint 评分协议；Joint 是逐样本两项同时达标的比例，不是平均 SA×平均 PC。自动评测只是指定 evaluator 下的结论，应抽取盲评核查。

清晰度、运动幅度、时序伪影和内容退化为守卫。不能通过降低运动或让事件不发生来获得“更符合物理”的静态视频。

### 11.2 阶段目标

效率候选的建议投入门槛：在预设质量容忍范围内，较原始 OMR 总时间下降约15%，同时明显强于同时间的简单稀疏对照。

开发阶段可辅助观察教师增益保留率：

\[
R_Q=\frac{Q_{candidate}-Q_{native}}{Q_{teacher}-Q_{native}}.
\]

只有教师增益为正且有足够精度时才解释该比率；分母接近零则报告原始配对差和区间。约80%的保留率可作探索参考，不能替代冻结测试上的非劣性边界。

“相同时间更高质量”与“1.2×原生开销”可作为更远目标；不能把旧文献47/52分或1.71×直接当本地起点，也不因首次达不到1.2×就否定有效简化。

### 11.3 统计尺度

初始32测试场景×2种子只是一轮独立确认起点，不保证有足够功效检测3–5个百分点。按开发侧配对不一致率估算所需场景数，追加样本要重新提报预算。

给二值配对差 \(d_i\in\{-1,0,1\}\)，独立单种子场景的标准误可按 \(\sqrt{\mathrm{Var}(d)/N}\) 估算；多个种子嵌套于场景，不能当独立样本直接扩大 N。主要结果报告区间，不以“不显著”宣称等价。

## 12. 组合、确认和暂停规则

O1/O2/O3 单项有证据后，最多先组合两项；保留原始OMR、最佳简单稀疏、两个单项和组合。相同eta调参预算、显存策略和任务指标。

方法冻结后做独立确认，再选择一个迁移维度；没有匹配第二adapter时不要承诺跨主干结果。公开资源受阻时保存 O0 清单，主GPU回到已可执行方向。

| 观察 | 处理 |
|---|---|
| 教师在本地无可信收益 | 诊断设置与评分；不启动大规模蒸馏 |
| O1已保留收益且足够快 | 深化强基线或确认，不必加学习组件 |
| O2只让梯度幅度变小 | 加相同强度预算对照后再归因 |
| O3不超过同次数O1 | 暂停复用机制，保留简单稀疏 |
| teacher拟合好但学生终点差 | 走EX-O闭环补采/目标诊断 |
| 只有JEPA能量好 | MECHANISM_ONLY，不写物理能力提升 |

**最小论文闭环：**本地有效教师、明确成本瓶颈、超过强简单基线的质量—时间收益、机制诊断、独立确认和退化边界。无需同时包含缓存、MoE 和主干微调。
