# 当前主线：预算化缓存刷新规划

目标是在给定计算预算下分配视频扩散的完整计算步骤，使缓存推理更接近同输入完整 Native。当前执行模型只有 D（完整计算）和 light-C（轻量缓存复用）；F17-A2+lightC 的 A 属于对照，不是当前生成布局的操作。

## 机制与校准

1. 从已完成的旧输入敏感度实验测量单步缓存干预对最终 latent 的响应，同时取得逐步特征漂移。
2. 用终点响应和自上次 D 以来累计的漂移构造可分解区间代价。参数拟合及诊断资产位于 [principle_fit](../reports/cara_principle_fit_20261105/) 和 [principle_refit](../reports/cara_principle_refit_20261105/)。
3. 冻结后用动态规划在预算内选择刷新位置。优化对象是代理代价，不是真实 LPIPS 的精确全局优化。

原 [refit 报告](../plans/cara_next_stage_20261105/principle_refit_report.md) 保留旧预测、诊断和模型选择过程。G17/AVSLC 结果参与了冻结前的模型选择；不能把它们称为冻结后的独立确认。

## 已冻结版本

当前 [generator v1](../plans/cara_next_stage_20261105/generator_v1_frozen/FROZEN.md) 使用 M0A_all：κ_A=0.2915722788395509、β_L=0.514056728071378、ρ=0.10472664684826208、γ=0.3759502318511064。MEAN 特征来自原八输入，敏感度取几何均值、漂移取算术均值；固定首七步及第 36 步为 D。

允许 A 的规划也未选择 A，冻结 DC/DAC 对应项相同，nA=0。主线布局为 [R16C / R18C / R21C](../plans/cara_next_stage_20261105/generator_v1_frozen/frozen_masks_r16_r18_r21.json)，实际完整计算次数为 16/18/21，保持 36 步求解路径。

这些布局不根据 confirm10 或 primary11 结果再调参数。原生成脚本仍使用 `/workspace/flat_opt` 等固定校准工作区；其限制已在冻结说明中记录。当前运行消费冻结输出，不应为整理仓库重拟合或改写原脚本。

## 证据与下一步

最强的冻结后证据是 [primary11 完整报告](../reports/cara_primary11_r1_20261106/REPORT.md) 的八输入配对 R18C/F17 结果，以及五驾驶输入 16/18/21D 的质量—时间取舍。原完整确认门槛因拒绝和缺失仍不可评价。

待补的公平归因包括同 18D/light-C 的均匀布局、移除终点敏感度的漂移消融、按实际时间匹配的外部缓存和少步 Native，以及冻结后的独立确认。这些是后续研究建议，尚未派发。P/S/Q、ORR 和其他新模块暂停。

当前主贡献可以围绕区间代价与预算规划组织；新颖性、代理代价的归因和外部优势仍须对应证据，不能由内部 F17 对比直接推出。
