# 完整视频之后：先测实际部署成本，再扩展方法

2026-10-03。本文件是后续 CPU 实现与测量方案；[83 完整六输出卡](83_WC_FULL_OUTPUT_R1_CARD.md)已终态并审计，原冻结执行保持。后续轻量路径的实际 CPU 验证见 [85 结果](85_WC_LIGHT_PIPELINE_CPU_AND_TRACE_RESULTS.md)。本方案不构成第二张 GPU 卡，不授权训练、付费评分或新增人工评审。

## 当前证据能回答什么

两个曝光 CAL 的完整配对均已验证真实 S 刷新、近似来源进入官方 forecast window、后续 cache 读取、call70 清空、最后两次 dense 暖启动，以及完整 93 帧输出。每个场景437个真实稀疏注意力算子和29次近似来源读取，让机制验证跨过了“只有局部算子”的阶段。整卡 source/assets、六输出/来源/完整解码、实际费用与释放独立审计通过，详细结果见83与原回执。

首场景相对官方 WC 的 PSNR24.99dB、luma SSIM0.901、帧差运动量比0.986，是编码视频差异诊断。它不能证明语义、物理行为或原生完整计算质量；两个曝光 CAL 也不能作独立确认。这里不从这些值事后制定接受阈值。

人物场景PSNR17.48dB、luma SSIM0.705、帧差运动量比0.952，差异明显更大；原生WC deep38次，候选35次，9次CFG调用的full/cache选择改变。两场景第一处模型输出SHA变化都在首次S调用23；人物第一次full/cache分歧在call46。这些时间顺序不能证明质量差异由哪次刷新造成。视频帧的early/middle/late分段也不能当作去噪步骤的early/late。

因此不扩样、不叠学习器，也不把该配置推进为质量保持候选。下一先用现有回执做CPU轨迹/成本核查并建立轻量路径；下一GPU卡需要将保真问题与净部署成本一起具体化。若要区分稀疏近似和adaptive schedule反馈，必须单列解释性对照或事前固定两臂共同策略，不能把baseline未来trace偷偷提供给在线候选；当前哈希回执不足以计算同状态反事实误差。

官方359.89秒、S389.61秒是当前调试流程 wall。候选多了真实来源侧账本、稀疏入口检查与五次状态恢复，调试中还有大量状态/输入哈希、深拷贝、同步和共享 prepared replay。该数值不能提供公平的部署速度结论；局部算子或 deep+head 热耗时也不能替代端到端收益。

## 下一优先 CPU 工作

建立同一官方完整生成入口的轻量测量路径，先明确每项记录是否属于实际部署所需，再改变代码。

- 保留官方缓存判据、Gamma/flow/OSI、probe、dense 回退、guardrail、decoder policy、完整 sampler 和普通写文件路径。保留近似来源与真 D 的隔离、请求/模型/条件/CFG/group/epoch 绑定、nonfinite 拒绝、native reset 与必要清理。必要路由和核入口开销计入候选成本。
- 移除测量之外的 shadow/全张量哈希、五处复制恢复、评分原件导出和逐前向诊断。不能为了更好看而删除必要的来源验证；若后续要优化验证实现，单列版本并验证其拒绝能力。
- 两臂各自执行真实官方输入准备、完整采样、decode、guardrail 和写文件，不用第一臂预处理结果让第二臂少算。共同的初始 RNG、buffer/mode、输入协议须在计时范围外建立并由配对控制证明。
- 在计时入口/退出同步 CUDA；完整 pipeline wall 为主口径，sampler/decode 等分段时间作解释。加载、首次核启动、失败和 flush 继续计入总 GPU 预算，不能仅上报最快热运行。

CPU 门先证明轻量路径的官方/adapter D/D 控制、完整36/72与70计数尾部、来源失效/回退及失败分母。稀疏 toy stand-in 仍只作接线证据。完成后才冻结真实入口、payload、每臂工作量、顺序、成本及下一张独立卡；不能继承83已用的单次提交身份。

## 公平测量与后续比较

先在既有开发输入上检查轻量路径能否产生实际部署收益。预登记交替顺序和重复次数，将首次/热运行分开，保留全部成功与失败、各次时间和分散程度。固定 seed 和 protocol，但不要把同 seed 的重复当独立质量样本。比较官方 WC 与简单 WC+S 时，允许候选自己的官方 adaptive trace 改变；记录 deep/S/cache 调用数以解释成本，不能强制其遵循对照轨迹制造公平。

首轮保留sim0.1/cdf0.98、6/23/27 dense回退，避免同时改变路由、近似器和刷新规则。先回答三个问题：真实核及路由省下多少，必要来源检查花掉多少，剩余 pipeline 限制多少。若没有净收益，优先定位成本；若误差明显集中，再考虑降低稀疏强度、局部分组或刷新分配。复杂 H2、W3/RV 学习器和模块组合继续后置。

进一步的质量—时间前沿必须包含同版本原生完整采样、原生少步采样、合理调过的 WC 和候选。原生视频要满足当前输入、seed、grid、mode、decoder 与 guardrail 协议；旧 F1/评估输出未经这些绑定验证不能直接充当本卡原生质量参考。拟合/开发与独立 CONF 保持隔离；用曝光数据选参数后，确认集需在选定方法之后冻结。

本轮保真、时序和运动代理优先自动计算，不新增人工技术准入门。代理结果仍不能替代缺失的语义/物理证据。最终是否继续、调整或关闭候选，依据真实质量—时间比较；当前没有论文创新性或接受结论。
