## 方差分解

4个原CAL、seed0，各406个合法(s,t)格。对每个动作分别令y=ln(guided局部MSE)，拟合平衡双因素分解：

`y[i,j] = grand_mean + cell_effect[j] + scene_effect[i] + interaction[i,j]`。

j是完整的(target, age)组合，不是单独线性时间项。场景与格均等权，三种平方和正交相加。一个格只有每场景一次标签，交互残差不能再拆成独立测量噪声与真实内容交互。另以类别时间项＋类别步龄项做加性最小二乘，作为更简单的描述性模型。

| 动作 | 加性时间＋步龄 R² | 完整共享格解释比例 | 场景主效应 | 场景×格交互 |
|---|---:|---:|---:|---:|
| C | 68.32% | 75.72% | 8.30% | 15.98% |
| A(.5) | 79.99% | 82.58% | 6.75% | 10.67% |
| A(1) | 89.29% | 90.67% | 4.20% | 5.13% |

后三列相加为100%；第一列属于另一个模型。A_HALF采用实际保存MSE，A_ONE使用已接受FP64矩恒等式e2+2ed+d2。没有epsilon填充、负值截断或删除不利格。

共同时间结构强，支持优先验证共享规划。80%不是自动终止自适应研究的阈值：调度需要位置/动作的相对收益，少量交互也可能落在预算决策边界。场景整体尺度同样不能自动转换为刷新位置收益。

每折用其他三个CAL在同一格的**原始MSE算术均值**选择C/A(.5)/A(1)，再在留出CAL评分。教师标签逐格最优动作是有特权的解释性对照，不能当作真实闭环最优策略。

这些格可能互斥，没有配平动作数量、价格或可执行轨迹；以上百分比不是LPIPS收益、同预算收益或自适应上限。不读取污染旧价格，不读取任何在跑价格或PG-P1部分结果。它与660使用log均值等不同预测口径的诊断不合并。

四个CAL是样本边界，不对1624格做独立样本显著性推断。精确并列保留最优动作集合与可能后悔值区间；确定性输出仅按C、A_HALF、A_ONE顺序处理预测并列。

## 如何使用后续证据

1. **先读PG-P1完整接受。** 复用其既定选择，报告真实可行性、全视频LPIPS、请求时钟、尾部场景、代理与终点排序、全部校准GPUh。不以CPU通过或已启动替代结果；未选出可行策略不自动归因于缺少学习器。
2. **再读同自身状态的历史对照。** 固定当前状态、最近D锚点s，比较真实[p,s]与邻接影子[s−1,s]。这辨别较早锚点历史的影响。
3. **另列教师表到自身状态的总失配。** 该差异包含状态漂移，不能全部归因于历史。报告C/A_HALF/A_ONE动作排序、并列、后悔值、绝对误差和覆盖点；常量相关及零分母倍率记NA。
4. **据机制决定是否提出新试验。** 历史导致有损动作翻转，优先考虑历史表示；局部排序保留而终点排序差，才考虑敏感度与交互；共享规划在新输入上已有同时间收益，则继续共享规划。两CAL诊断仅提供机制线索，不足以设总体显著性门槛。

没有自动采用“80%”或“3%”作为决策阈值。未来若提出替代方法，先在CAL/先导范围估计可分辨收益空间与决策成本，再在新留出结果出现前冻结实际效应门槛、样本/seed与配对不确定性算法；近零oracle空间标为低区分力。既有选择合同与662关闭决定不追溯修改。

## 保留的技术判断

- **局部模型要考虑真实历史。** 当前教师格的source_anchor_steps=[s−1,s]；C依赖两个锚点，而稀疏部署可能是[p,s]。现有P2正针对这个缺口。
- **敏感度是向量传播的近似压缩。** 一阶形式为Δz_end≈ΣJ_t ε_t；标量Σw_t e_t不直接等价于LPIPS。注入效果可能依赖源步、动作、误差方向、幅度及solver历史。小型多位置/步龄/动作/幅度试验应先于10–20 prompt大采集；目前没有启动该试验。
- **在线D标签应使用刷新前旧缓存。** 反事实读出先完成，D再成为真实锚点。统一正数缩放目标函数不能改变固定硬预算DP的最优解；有效的校准必须能影响相对收益或另有明确预算目标。特征必须因果可得，双支readout/warp/归约全部计时。
- **轨迹聚合不会自动给出最佳动作。** shadow D只能补自身状态上的局部标签，不自动解决终点信用分配；隔离状态且计入成本。当前不执行DAgger。
- **O(T²)标签不等于一次Native费用。** 原完整卡6.900544 GPUh；正式COLLECT流水线约72–74分钟/条，含重复读出、搬运和保存且受共享GPU干扰，不能当作新干净报价。100 prompt=7 GPUh遗漏旁路成本。池化特征也不能替代精确读出所需临时完整锚bank。
- **已完成的L1结果独立保留。** 660/662说明预测幅度改善不等于刷新收益，且不能解释成只有场景尺度。此目录不重拟合L1、不增特征、不重启probe门控。

## 相关工作核对

以下原论文/官方仓库于本次讨论核对；它们提供设计参照，不替代Cosmos上的实证：

- [MagCache](https://arxiv.org/html/2506.09045v1)：跨prompt的幅度规律与单样本校准。
- [Learning-to-Cache](https://arxiv.org/html/2406.01733v1)：输入无关、随时间变化的路由，可生成静态计算图。
- [DiCache](https://arxiv.org/abs/2508.17356)：按样本浅层probe与缓存轨迹对齐。
- [CEM](https://github.com/leaves162/CEM)：时间/区间误差先验与DP。
- [DPCache](https://arxiv.org/abs/2602.22654)：小校准集、路径相关代价张量与DP，论文标注CVPR2026。

因此“代价模型＋DP”不是单独的新颖性依据。CARA需以CFG修正、真实历史条件、实测预算下的联合分配及公平闭环增量建立差异。
