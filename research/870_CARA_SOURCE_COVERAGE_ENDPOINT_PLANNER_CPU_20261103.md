# 870 来源覆盖与终点校准规划：CPU 原型通过

2026-11-03。用户同意“按设计先做 cpu 验证”。本轮把研究方向落实为可运行的方法原型：**用来源覆盖生成小型预算计划族，再由少量完整终点评价选择。** P0 的缓存写入证据支持研究这个结构；新方法的质量与校准效率将由后续完整视频验证。

## 已实现

[设计与运行说明](../plans/cara_next_stage_20261103/source_coverage/README.md)给出固定公式、候选规则和消融。来源距离同时计入归一化更新次数与噪声差，避免把平坦 sigma 区间的多次工作状态演化当作零寿命。双来源、四个固定阶段倾向、精确 D 配额与两遍 DP 生成候选，没有旧赢家掩码或局部误差回归输入。

实际 36 更新网格生成 **19D 12 条、22D 8 条**；单来源消融分别为 8/9 条，无阶段候选为主池预定子集。重复候选不补齐额度。每个计划保留来源消费者和替换记录，完整缓存与 solver 状态继续交由原入口执行。

终点选择器已实现完整候选×FIT 分母、全 93 帧、输入等权 LPIPS、参考与协议绑定、失败/缺失及实际费用保留；并列沿固定候选顺序。真实离线生成和选择 CLI 已通过合成终点记录测试。
