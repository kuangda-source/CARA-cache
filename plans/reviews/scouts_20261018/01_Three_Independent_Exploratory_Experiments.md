# WorldCache：三条独立增强路线的低成本探索实验（2026-10-18）

> **定位：探索，不是主线变更。** 本文只设计 X-A、X-S、X-R 三项可撤销试验。三者均允许得到负结果；未经真实正向证据与独立确认，不修改已冻结的 A/H1/FRONT_DENSE/论文主表，不恢复已停止的 F/B，也不自动启动任何 GPU 任务。结果出现正面机制线索后可以再安排一次有界修订，不要求一次试验就决定整个方向生死。

## 2. X-A：有限刷新区间内的连续修正（主假设：一次 A 的效果可能需要延续）

### 2.1 要检验的不同解释

- H-A1：仅 step21 的 A 修正幅度不合适（需要约束 α）。
- H-A2：后续到下一个真正 D 前继续用 A，能改善未来累积误差。
- H-A3：损失主要由缺少真实 D 的深层锚点所致；即使连续 A 也难代替。

**不预设**“锚点饥饿”已被证明，也不把“把近似 A 写成新的缓存年龄0”当作真实更新。核心简化式 `r_hat_t = p_t + d_s` 下，将自身预测写回再以相同 β 推进可能发生望远镜消去，并没有创造新 `d_t` 观测。

### 2.2 CPU 同状态幅度诊断

实际输出融合为 `v_A(α) = v_C + α (v_Phi-v_C)`，两CFG分支共享 α。设 `d=v_Phi-v_C`, `e=v_C-v_D`，则：

`q(α) = ||e+αd||²`，同状态诊断 oracle `α*=clip(-<e,d>/||d||²,0,1)`（零分母回退）。

- 预设 α={0,0.25,0.5,0.75,1}，看 q、最优 α 分布以及 `cos(e,d)`；已有 α 的对照要使用相同位置、相同张量和真实 post-RF 输出。
- 如果要拟合 shrink，最多使用一种低复杂度的阶段共享 α 或基于过去真实 D 的比例裁剪；系数在 CAL 拟合、按提示词留出检查，不使用当前 teacher 在线决定。
- 没有同状态 `v_D` 的位置只计资产缺口，不把其他轨迹的 `v_D` 当作 teacher。

### 2.3 最小完整视频 2×2（固定25D、固定其余D位置）

令 k=实际 step21；从 S25 已登记 mask 读取 k 以后至下一次真实 D 之前**确实执行 C 且允许读出 A**的集合 `I`，如果 `I` 为空，先停止该设计并换一个事前登记的有效区间，不能虚构延续效果。

| 臂 | k处 | I处 | 是否已有 | 说明 |
|---|---|---|---|---|
| G00 | C | C | N12 S25-C | 基础 |
| G10 | A | C | N12 S25-A | 单次A |
| G01 | C | A | 待做 | 仅后续持续读出 |
| G11 | A | A | 待做 | 初次+持续读出 |

- 其余步骤、保护位置、真实 D mask、年龄与来源策略完全相同，不更新任何假 D 锚点；不得因 A 触发额外 D 而继续称“同25D”，发生则单独报告实际 mask。
- 四个 CAL 场景 seed0；优先复用 N12 G00/G10。新做最多 **8条正式视频**＋有限预热。记录全93帧 LPIPS、每场景变化、真实 time、动作序列、age/source，特别核查 `G11-G10` 的额外作用。
- 若幅度 CPU 诊断呈现一致且明显增量，再申请不超过 **4条视频**的 `G10-shrink` 或 `G11-shrink` 单一对照，**包含在余量预算中**；不并行搜索一堆 β/α。

**继续的信号**：同一固定 D mask 下，G11 对 G10 有可识别的终点改善且费用增量合理；或 G01 解释了后续作用；或 shrink 在留出同状态点有明确改善。无须在这次短卡达到论文级显著性。

**停止的信号**：连续 A 不改善或稳定恶化，且已有幅度诊断显示仅调 α 无可用空间；或 G11 改善极小、不足抵偿实际新增读出费用。允许一次有原因的实现/区间选择修复，不滚动调到开发集好看。

## 3. X-S：阶段曲率共享计划＋转换区轻量门控（两项都试，分开记账）

### 3.1 S-CURV：先尝试用曲率相关得分生成 26D 共享计划

只使用**离线开发校准**的 Native 轨迹，定义预设启发式（不是解析最优定理）：

`s_j = g_j² · ||v_j^Native-v_{j-1}^Native||²`；同时记录不含 g² 的时间差分版本作 CPU 对照。这里度量是离散总变差，不称为严格几何曲率；不同求解器/时间网格下需重新校准。

- 先使用2–4条旧CAL完整Native轨迹估计每步分数；该费用若需重新生成不能声称零成本。
- 以 `FRONT_DENSE_C` 26D 作为初始候选，只提出 **1次合法的等配额 D/C 位置交换**（或经受保护、age和来源检查的预算可行计划）；保持 D=26、其它复用动作全部为 C；避免把“多算 D”记成调度优势。
- 如果候选和前密 mask 完全一致，记录“未提供不同计划”并关闭 S-CURV，不用 GPU。若不同，旧CAL四提示词×1 seed **最多4条新正式视频**，按相同 Native 参考评估；随后停止大范围计划搜索，除非有正面信号。
- 比较 `FRONT_DENSE_C`、候选、UNIFORM_C（已有资产可用），同时列出计算最终成本；不能仅因同26D就称同费。

**支持**：合法共享计划在至少一个固定预算取得值得复验的终点优势；**否定**：结果重复前密或明显更差且无独立机制信息。

### 3.2 S-GATE：step21 的输入特定“该不该少一次D”

定义当前动作前**可见**的浅层差：

`p_g,t=8p_c,t-7p_u,t`， `z_t=||p_g,t-p_g,t-1||/(μ_DEV(t)+ε)`。

- 该量测的是浅层去噪变化，不叫视频物体运动；`μ_DEV` 只由训练折历史估计。额外读前步 p 及归约的真实开销需要计时。
- 在线决策仅在已预登记的一个合法转换位置（首先 step21）作 **D↔A**，其它动作固定。若后续开第二窗口，应是新卡而非这一轮隐式追加。
- 决策标签必须是同一 pre-action state 的 **完整生成后果**：`y_i=LPIPS(A21)-LPIPS(D21)` 和 `ΔT_i=T(A21)-T(D21)`；不是 `q_A` 或视频 prompt 类型。比较高/低 z 对删 D 的损失排序。

**最省 GPU 的设计：成对后缀银行。**

1. 利用已有 N12 四CAL中的 `S26-C` 与 `S25-A` 配对后果作开发指导。只在那些确有同一前态并执行同一后续固定规则时使用。
2. 额外预登记 **6 个新的探索 DEV 提示词，单 seed**（避免 CAL、N07、旧确认及未来保留测试），每个生成 `D21` 与 `A21` 两臂，共 **12条正式视频**＋有限预热。所有提示词原样登记；拒绝按注册缺失保留，替换仅使用事先登记的候补清单。
3. 每个 prompt 的 D/A 两臂都真的运行到终点。这样之后任何**只在step21选择一次 D/A**的确定性门控，都可以在 CPU 上由两臂结局精确组合，不必再为每一个门控重复生成视频。
4. 在四CAL预设 `μ,θ` 或小样本秩规则，新六提示词只检验，不事后为其逐prompt调阈值。与“全部D21”“全部A21”“相同平均 D 配额的随机选择/均匀混合”“按 z 选择”对比；可列出只做诊断的 oracle 上限，不能部署 oracle。
5. 在各方案**相同平均真实耗时或同减少D次数**下比较总体视频 LPIPS、逐prompt最大退化、预算与拒绝。若门控只跳过更容易的视频，同配额随机组合就能反映是否有新增信息。

**支持**：z 在新探索提示词能把“一次D可省但终点损失小”的样本与损失大的样本区分，且在相同平均成本下优于固定/随机混合；**否定**：输入间损失排序与 z 无关，或性能不超过简单混合。样本小，只作方向筛查，不称稳定泛化。

## 4. X-R：方向与边缘加权风险（先做诊断，不以训练新控制器为前提）

**验证的问题**：同状态 guided MSE 是否掩盖了不同方向/区域的终点损失差异？这里是“相对速度方向平行/正交”，**不是**已知的数据流形切向/法向；不能预设正交误差更有害。

### 4.1 共享 X-S bank 收集输入

在同一 pre-action state，D21 分支已得到 `v_D`；读取或廉价计算 `v_C`、`v_A`，检查 CFG `8c−7u`、RF位置、对应张量形状/时间步/来源一致。诊断采集如果产生head额外开销，应与正式计时分开记录。为每个状态绑定其 D/A 完整后缀终点损失 `ΔL_T`。如果 N12 某场景只有视频没有同状态teacher，先登记缺口；新 bank 有机会补齐。

### 4.2 预先固定的指标（不调几十个系数）

令 `e=v_A−v_D`；`u=v_C/(||v_C||+ε)` 为可见方向近似。离线也计算用 `v_D` 定义 u 的诊断上界，但不使用它构造在线特征。

- `q_MSE=||e||²`。
- `q_parallel=<e,u>²`，`q_perp=max(0,q_MSE-q_parallel)`。
- `q_edge=Σ W·e²`，`W` 从 `v_C` 的空间 H/W 有限差分构造，归一到平均1，并预设裁剪到 `[0.5,2]`；系数 `γ_edge=0.5` 作为唯一首版试值。
- `q_combo=Σ W·e_perp²+0.25||e_parallel||²`，仅作探索性备选。这里 `e_perp` 是张量正交投影，W 可逐位置广播。

**必要对照**：时间/来源先验、q_MSE、q_perp、q_edge、q_combo。以 prompt 为单位，评价预测 **同状态 A21 相对 D21 的终点 LPIPS 增量** 的秩相关、最差反例、以及在控制已有基线（同一step时控制prompt而非制造时间效果）后的新增排序信息。若拓展多个 step，必须按 step/source 分组，不能让时间方差冒充方向收益。样本量仅用于筛查，不计算虚假的“统计显著”。

### 4.3 在线可用性核对

风险标签 `q_MSE/q_perp/q_edge` 本身都含当前真实 `v_D`，**不能在线用于决定要不要执行 D**。即便这些指标离线更接近终点，也还不是有效调度器。只有它们与 pre-action 廉价量（`v_C`、`v_A-v_C`、p、z、方向/边缘）之间能建立稳定关系，才值得下一步用轻量预测或 gated correction；这一轮优先通过共享 D/A bank 的离线配对选择来测试，不单开 C 方向 GPU 卡。

**支持**：相同step、相同后缀条件下，相比 q_MSE 排序出现有意义增量，且可见预动作代理也有信息；**否定**：没有稳定增量，或所有改进依赖不可部署的当前 `v_D`。关闭 X-R，不恢复之前已停止的空间FFT/Haar F。

## 6. 三个方向的“加入主线”规则

首次GPU／离线正信号仅意味着**允许再开发一次**，不是直接将增强写入论文。正信号后：独立冻结方法 → 少量全新输入确认 → 清楚的同时间强基线与单模块归因 → 真实部署成本与风险边界，再讨论纳入主稿。

如果某一条路线没有可实现收益或即便诊断 oracle 也缺乏有意义空间，立即停该路线，保留一页实验记录；不影响其余两条。若两条都正向，可再单独设计组合实验，不能自动把探索结果相加。

## 7. 最短执行摘要

1. **立即只读 E0**：先核对 N12 实际mask、已有连续修正卡状态、所需teacher和后缀标签；三线CPU起步。
2. **X-A**：同25D，补连续A的G01/G11，区分step21和以后读出的作用。
3. **X-S**：从Native差分形成一个合法且不同的曲率计划（若存在）；同时在step21建立6提示词D/A后缀银行，以相同平均D预算检验z门控。
4. **X-R**：复用银行，比较方向/边缘风险与普通MSE对真实终点代价的解释，检查能否转化为在线廉价代理。
5. 三线分别总结为 `CONTINUE / REVISE_ONCE / STOP`；**未经新增独立结果，均不修改冻结主线。**
