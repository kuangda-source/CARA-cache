# 原 Codex 对话接续：从固定配置到可复现的区间策略生成器

## 当前任务

阅读同目录 `01_Method_Definition_and_Validation.md`，把新的研究问题落实为一个最小可执行算法，而不是继续人工寻找 Cosmos 的好步数。本文是新提案，不追认 v6 已实现，也不授权修改已有科学结果或自动增加 GPU 预算。

用户要求：同一套规则输入模型/采样器/少量校准数据/真实时延预算，输出 D 边界与区间 C/A 覆盖。允许跨模型重新标定参数，但不能每个模型根据 TEST 重新发明规则。

## 第一步：只读核对实际项目状态

1. 读取 v6、最近实验和执行队列，确认已经实现的范围、正在运行的卡与冻结配置。
2. 读取原 v5 修订方案，列出本次优先级调整：方法生成器原型与单预算闭环应在最终大规模 TEST 前完成；不静默暂停已授权任务。
3. 盘点 Native、合法源历史、连续 probe、同状态 C/Phi/D velocity 或二阶统计、完整终点 LPIPS 与费用资产。
4. 没有保存的量标记缺失，禁止从视频推断 hidden；不得把四 CAL 的特定 step21/22/23/33 写进通用选择规则。
5. F/B 保持结束，旧 P 大卡保持暂缓。不迁移旧卡名、范围或权限到本任务。

## 第二步：先交付 CPU 规格和生成器原型

输出：

- `policy_generator_spec.md`：输入/输出、区间与读出语法、真实状态契约、两类预算、完整终点评价、数据隔离。
- `interval_grammar.py`：节点1…N+1；s→r收费D_s和内部读出；终端不收费D；校验保护/年龄/锚点/D-A不重叠。
- `budgeted_planner.py`：对已提供的有限代理图做预算DP，保存少数不同拓扑计划；每个边界变化后重建A窗口。
- `test_planner.py`：小图穷举与DP一致、改变N后合法性、费用只计一次、目标预算无法满足时返回明确状态。
- `asset_reuse_and_gaps.md`：哪些真实表能重用、哪些是teacher-conditioned/off-policy提案、哪些需要实际采集。

CPU合成验证只证明程序逻辑，不写成 Cosmos 结果或策略成功。

## 第三步：设计一张有界单预算真实卡

建议开发档：CAL_FIT四个既有开发提示词、一个真实目标预算、最多8个不同计划的终点评分；具体数量按真实报价固定。

候选由固定算法产生：预算合法的强简单C/A、低代理代价区间计划、多样化计划、有限联合邻域。不得看某个视频变好后手动插入一个“专门的例外步”。

所有候选使用同一组CAL、相同seed、同Native参考、同计时边界。保存：计划、局部代理分、真实终点、实际费用、动作/来源/solver轨迹、拒绝和失败。

真实费用中包括新的教师采集、额外head、完整候选输出、预热、校准评分及必要搬运。读取已有评分虽不增加运行成本，也应标记它属于算法可见信息，基线获得可比初始信息。

只在当前权限和预算足够时按已确认规则执行；不足则一次性提交完整范围、预计成本、上限和待决事项，不机械拆卡绕过整卡确认。

## 第四步：主比较与冻结

主比较不要只打均匀：

1. 同时延前密C/A；
2. 相同GCR、只优化D位置；
3. 相同候选语法、局部代理最终选计划；
4. 相同语法、真实终点联合优化；
5. 等额查询的随机或简单局部搜索，作为搜索效率对照。

若要使用CEM或Golden Path式基线，按原论文定义实现并明确适配；不要把未经验证的“类似版本”当成官方完整复现。

初步有意义后，用同一代码生成第二预算以及第二模型/设置的计划，只换适配数据与校准参数。新独立主表在方法/对手/预算/评价冻结后执行；不能借用旧H1的N07/N08/N10来替代新区间结果。

## 本轮应避免的偏移

- 不把“自动搜索”本身视为充分创新；要有同等搜索预算下的新增价值。
- 不将区间加性代理解释为真实终点严格可加，也不声称DP给出全局真实最优。
- 不为了让计划不同而修改规则；若同一计划在新输入上工作良好，固定部署是合法结果。
- 不让任意概率模型、MixLinear、P-ACR、FFT或Block实验重新变成当前生成器的前置条件。
- 不同时试十套打分器。先用已定义提案表和真实终点筛选跑通一个完整版本。
- 不根据TEST改变语法、保护、窗口、alpha候选或停止条件。

## 向用户汇报的格式

1. 与实际v6/在途卡的差异与兼容性；
2. 已完成的CPU交付，不把设计写成结果；
3. 一张去重后的真实开发卡与完整报价；
4. 最关键的算法结果：同预算相对强简单计划是否有增量、增量来自读出覆盖还是边界、校准花费；
5. 下一步只给一个最有信息价值的决定，不再每次扩一大套计划。
