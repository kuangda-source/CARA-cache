# WorldCache 调度独立价值：结果研判、文献与方法修订

日期：2026-10-16  
性质：基于用户报告的研究分析与待验证设计；没有查询远端、运行新 GPU 实验或改写既有卡。  
证据基础：`WorldCache_Results_and_Open_Questions_for_6pro_20261016(1).md`，报告第4–7节。N07在材料中只确认启动，不能推断当前终态。

## 0. 推荐结论

继续研究调度，但不继续以“更复杂的逐步风险回归器”为默认推进方向。

当前最有依据的结构是：

**CFG一致修正读出 + 对完整生成结果校准的预算化共享计划 + 有条件的在线例外。**

推荐首先改进“优化什么、怎样评价完整计划”，再判断状态信息是否值得用于个体化决策。共享或离线计划并不天然缺乏算法价值；但把前密后疏换个名字也不是新贡献。需要超过强简单规则，并证明更低的标定成本、更好的跨预算/跨设置迁移或更优的真实质量—时间关系。

F/B保持停止；P不是本轮调度修订的前置项。MixTrend暂不扩网络或频谱自由度：T2并不是MixLinear原方法，因此本轮不能否定MixLinear；但已有证据不足以说明增加历史模型容量能解决当前最主要瓶颈。

## 1. 事实与解释分开

### 1.1 当前成立的事实

| 结果 | 已有证据 | 不能延伸成什么 |
|---|---|---|
| 修正A具有独立作用 | N06相同D位置下，A相对C/plain平均改善约3.52%、5.98%、3.29% | A在所有场景、所有工作点必胜 |
| 位置分配非常重要 | 同26D+10C，前密C与均匀C的LPIPS均值约0.05821与0.22758 | 早期误差遵守某种已证明物理规律 |
| H1没有超过最强简单阶段规则 | FRONT_DENSE_C均值比FIXED_A低约0.659%；FRONT_DENSE_A更低，但A次数不同 | H1已在同真实时间被严格支配，N06计时为并发诊断 |
| T1学到主要是阶段调整 | regret下降64.83%，step23解释100.39%净收益；时间only几乎等效 | 65%视频质量或运行时间改善 |
| T2有预测接口的高代价失败 | 一个负风险投零状态regret38.4711；统一回退后大幅恢复 | 历史永远无用，或回退收益就是历史收益 |
| 当前局部标签不能证明闭环 | 只有8种更新位置，原策略D来源状态 | 已覆盖全部36更新、P来源、新策略访问状态 |

N05的A_NO_P相对RA_DEFAULT是约1.08%额外主时间换9.67%平均保真失真下降；相对WC_DEFAULT有质量和时间的共同改善。H1相近时间下明显更接近完整Native参考，但它相对少步Native的LPIPS优势不等于绝对观感/物理质量优势。

### 1.2 当前最合理的解释

1. 时间/噪声阶段具有较强公共结构，逐输入预测可能只是在重新学习一个阶段偏差。
2. 局部风险目标与完整结果/缓存更新价值错位；把局部目标拟合得更好未必改善最终视频。
3. 历史版本失败的一部分来自不合法风险预测被解释为“零风险”，而非历史信息本身；但当前没有稳定增量支持加大预测器。
4. 同一个D预算下，刷新位置、首次近似时刻、缓存年龄分布、后续solver历史一起改变，不能唯一归因于“早期传播强”。

## 2. 本轮最相关的新增文献

以下是外部研究，不是用户实验结果；截至2026-10-16核对。预印本不等于已录用论文，作者结论不直接迁移为Cosmos/UniPC结论。

### R1. The Golden Path Hypothesis: Reusable Schedules in Diffusion Caching

arXiv:2609.39343v1，2026-09-30预印本。研究固定模型、采样、近似器和预算下，共享缓存计划与逐prompt自适应计划的差异。作者在四个图像/视频模型上提供共享计划可跨prompt保持竞争力的证据，并强调完整终点评价。它最直接支持“不要把每个输入都走不同路径作为目标”，但不证明当前前密策略是Cosmos最优，更不证明静态计划总优于动态计划。

### R2. CEM: Plug-and-Play Fidelity Optimization for Diffusion Transformer Acceleration via Cumulative Error Minimization

ICLR 2026，arXiv:2512.23258。将去噪位置与缓存区间共同建模，以累计误差代理和动态规划构造缓存计划。可借鉴“从逐步判断转为区间计划”，但其代理最优不等于真实终点全局最优。

### R3. SODA: Sensitivity-Oriented Dynamic Acceleration for Diffusion Transformer

CVPR 2026，arXiv:2603.07057。离线刻画时间/层/模块敏感性，区间DP与部分计算结合。可借鉴预算分配结构；本次不因此重启F/B。

### R4. ReCache: Learning Budget-Aware Caching Schedules for Diffusion Models via REINFORCE

arXiv:2606.06060。直接使用完整生成的保真/质量目标训练预算条件计划，不反传完整扩散过程。支持“终点目标值得直接优化”，但现有预算不足以默认复制完整强化学习训练流程。

### R5. BAG: Budget-Aware Gating for Diffusion Caching

arXiv:2608.09231v2。以离线搜索计划监督预算感知在线门控。给出在线适应的另一类正面先例，但应以真实计划后果监督，而非仅扩大单步MSE预测网络。

### R6. Learning-to-Cache

NeurIPS 2024，arXiv:2406.01733。学习随时间而异、与输入无关的层缓存路由，最终可得到静态执行图。说明“学习/优化得到共享策略”与“人工固定规则”不是同一概念。

### R7–R9. 决策与策略学习基础

- Smart “Predict, then Optimize”：学习目标应反映下游决策误差，而不只预测MSE。
- Reinforcement and Imitation Learning via Interactive No-Regret Learning：利用行动后续成本及当前策略访问状态进行改进。
- Safe Policy Improvement with Baseline Bootstrapping：信息不足时保留基线行为。这里仅借鉴思想，不能移植其有限MDP保证到当前连续生成系统。

## 3. 为什么当前H1的目标会错过刷新真正的价值？

令完整状态为

\[
S_t=(z_t,\mathcal C_t,\mathcal D_t,\mathcal H_t^{solver}),
\qquad S_{t+1}=\Psi_t(S_t,a_t).
\]

其中包含latent、工作缓存、可信完整历史以及UniPC历史。当前局部目标为

\[
J_t^{local}(a)=c_a+\lambda g_t^2q_t(a).
\]

它把一次更新的结果压缩成当前误差范数，没有完整表示：D更新下一段的参考、A不更新D锚点、后续访问状态改变、未来计算次数变化。

真正的目标应由终点任务定义，例如

\[
\min_\pi\ \mathbb E[L(V_\pi,V_{Native})],\quad
\mathbb E[T_\pi]\le B.
\]

这不要求直接实现完整最优控制。关键是实验选择候选时使用真实完整结果，而不是把局部regret当作最终奖励。

### 3.1 对D的一个误解

同状态D的局部误差定义为零，不代表已偏离的状态回到原生轨迹。一个精确恒等式是

\[
\tilde v_t-v_t^{Native}
=(\tilde v_t-v_t^{full}(\tilde z_t))
+(v_t^{full}(\tilde z_t)-v_t^{full}(z_t^{Native})).
\]

第一项是当前近似，第二项是以前误差改变状态后留下的影响。对于多步求解器，还需要将其历史纳入状态。RA的经验传播系数能部分反映影响，但不使所有动作历史可由一个标量完全表达。

### 3.2 step23不能只算当前账

将step23的D改A，会改变step24及之后读取的锚点、当前状态和支持域回退时刻。因此，局部便宜约一次D，不意味着完整轨迹恰好省一次D。应至少用一个完整后缀或完整视频确认该候选，而不是在局部标签上继续增加预测器。

## 4. 推荐路线一：修正感知、直接终点优化的低维共享计划

这是近期首选，不要求在线内容自适应。

### 4.1 优化对象

将计划写作

\[
\mathcal S=(a_1,\ldots,a_N),\qquad a_t\in\{C,A,D\}.
\]

固定检查点、采样网格、CFG与读出版本。直接在开发数据上优化

\[
\min_{\mathcal S\in\mathcal F}\ \frac1m\sum_i
L(V_i^{\mathcal S},V_i^{Native}),\quad
\widehat T(\mathcal S)\le B.
\]

\(\mathcal F\)包括初始化、保护、支持域和来源合法约束。时间模型只筛候选，正式确认使用真实费用。若实际回退使预算超额，报告超额，不能悄悄当作matched-budget。

### 4.2 不从指数空间盲搜

以H1、FRONT_DENSE_C/A及合法强阶段表作为种子，只生成极少数邻域：

1. 保持D数量与读出配额，交换一对边界附近D/复用位置。
2. 将一个合法D改为A，检验是否在稍低费用下仍保持可接受失真。
3. 固定D位置，调整少数C/A或\(\alpha\)档位；明确这改变A费用。

先不改变P、骨干、CFG或solver。每条候选用同一套开发输入评价，不按场景选择赢家。一次只产生3–6个预登记候选，允许1–2轮有依据的局部改进。

### 4.3 这与手工调step23的区别

单独step23只能是诊断。方法化需要：明确的预算输入、固定的候选生成/选择规则、有限离线成本、对不同预算/模型按相同流程生成计划，以及留出确认。

不是声称“共享计划”原创；潜在增量在CFG一致A与C/D的联合分配、对最终任务目标的低成本搜索、源/支持约束和实际费用的兼容。必须面对CEM、Golden Path、ReCache等相关工作。

## 5. 推荐路线二：区间/半马尔可夫调度，作为共享计划的系统化升级

缓存动作改变的是接下来一段计算。以两个真实刷新点i、j之间的区间作为单元，附带读出规则r（例如阶段A或C/A混合）。

用\(\ell(i,j,r)\)表示区间损失代理，\(c(i,j,r)\)表示真实费用模型。离散化预算后：

\[
F(j,b)=\min_{i<j,r}\left[
F(i,b-c(i,j,r))+\ell(i,j,r)
\right].
\]

边界规定：区间成本不能重复收费D；虚拟终点不额外收费D；保护刷新应作为必经节点；超支持长度不能作为合法边。

**只对这个代理图，DP才是精确最优。**真实各区间误差会相互影响，D也不清空solver/latent偏差。若W1依赖最近两个D，状态只记最后一个i还不够，需扩展历史或先使用β=1。因此DP只用于产生少数候选，再用完整视频重排和确认。

该路线不是又增加一个大模块。CEM/SODA已有直接先例，应从其区间建模出发，新增读出与费用一致性，而不是重新包装动态规划。

## 6. 推荐路线三：强阶段计划 + 小型状态残差例外

若共享计划之后还存在可预测的同阶段差异，才做这一层。

### 6.1 先判断是否有条件信息增量

现有标签上可计算描述性空间：

\[
G_t=\min_a\mathbb E[J_t(a)\mid t]
-\mathbb E[\min_aJ_t(a)\mid t]\ge0.
\]

它比较一个共同动作与每状态oracle，必须条件于可比来源/预算/合法集。有限样本的oracle乐观，只作局部空间诊断，不代表真实终点上界。用LOPO构建阶段表，不能用全数据阶段均值反哺留出模型。

针对step23：单独剔除其贡献后报告增量；也看固定step内排序和尾部。若增量只剩统计噪声，停止扩历史模型，不等于停止共享调度。

### 6.2 预测偏离基线的收益，而不是重学整个风险

设基线\(\pi_0\)来自路线一。离线同状态干预后按同一个冻结延续策略继续，分别记录终点损失与真实后续时间。

\[
Y_t(a)=
[L_T(\pi_0)-L_T(a\rightarrow\pi_0)]
-\mu[T_T(a\rightarrow\pi_0)-T_T(\pi_0)].
\]

两个量分开保存，便于后续不同费用偏好；\(\mu\)是新目标的权重，不能复制旧局部\(\lambda\)。

模型形式可从

\[
\hat Y_t(a)=m(t,\sigma,age,source,a)+h_\phi(o_t,a)
\]

开始。先用少量状态特征和线性/浅树，不马上增加MixLinear双路径。仅在留出开发组支持时学习历史残差。

### 6.3 处理尾部而不把所有新动作都禁止

- 绝对MSE使用非负输出或适当变换；signed收益可以为负，两种语义分开。
- 负的绝对风险预测不能剪成0并解释成“非常安全”。
- 当前/历史模型使用完全相同的有效域、回退与费用。
- 无足够支持时执行\(\pi_0\)，不是自动最贵D。
- 第一版限制每视频一次或极少数例外，反事实数据对应其实际延续规则。
- 主评价用决策遗憾、严重误判和真实终点，而非总体MSE。
- 小样本无法支撑严格概率保证；不要将启发式置信回退写成数学安全证书。

## 7. 新发现及需要避免的重复错误

1. T1当前约65%收益主要是纠正旧阶段表的step23，不是内容模型成功。
2. 某个高保真预算上简单前密规则很强，不代表在所有预算、读出和设置上都最优。研究应从任意26D扩展成少数实际费用档位，而非执着在同一个点击败前密。
3. 同26D不是同费用；10A和5A会改变价格。选择“多用便宜A，少一次D”的候选具有成本依据，但必须真实闭环验证。
4. 不能用“65%局部regret下降”证明终点收益；也不能用当前实验否定MixLinear原论文。
5. 当前N08五角色没有FRONT_DENSE_C/A；若最终论文强调调度超过强简单基线，应另补必要的平衡计时，而不是拿N06并发计时拼主表或静默替换N08。
6. 缺ViCLIP权重是评价链资源问题，不是生成失败；不把当前LPIPS研究直接提升成物理质量改进。

## 8. 建议的论文收束

现有A与阶段分配仍然是可写的主线。主张应从“内容自适应控制器”调整为证据支持的“修正感知的计算计划优化”。

动态例外若有独立收益，再升级为混合静态—动态方法；没有就保留零/低在线开销的共享计划。该结论不是因为静态策略能自动构成创新，而是当前研究应把预算条件计划、CFG读出和终点目标组织为具体、可复验的算法。
