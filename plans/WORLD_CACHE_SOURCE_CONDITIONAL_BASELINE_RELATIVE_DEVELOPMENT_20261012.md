# WorldCache 研究设计优化：来源条件化估计与基线相对调度

2026-10-12。依据新N2研判文档与本库377/380/382/383/384，并新增385解析CPU检查。本文登记下一轮设计，不更改当前在途54路径的算法/参数/源码，不重跑已经完整验收的N1/N2。原材料见[来源清单](../manifests/wc_n2_review_documents_received_20261012.json)。

## 1. 核心问题与方法主张

继续围绕一个问题：在相同质量需求和真实费用约束下，怎样协调两个CFG分支的读出与刷新，并管理带误差的P工作来源。

W1提供来源/阶段条件化的修正读出；P提供较便宜的更新执行器；W3按动作的实际效果和成本选择。三者协同开发，不要求每个模块先单独形成稳定优势。不把普通联合刷新、局部误差二次式或“使用MPC”本身写成原创贡献。

下一版主候选：**来源条件化的相关修正 + 基线相对的多精度刷新**。已有P_OFF（D来源阶段A、P来源C）作为默认策略π0，A_NO_P作为较低成本的强对照；当前来源规则不是全局最优保证。

## 2. 与当前在途384卡如何衔接

384已经改为g²经验权重、来源A分价、当前/未来同一年龄1–6的rho支持、固定D-A/P-C和可选P-A。完整144采样CPU/生产CPU已通过，36正式＋18预热的唯一GPU卡正在执行，source f9f3fd7及649文件不改。

本次新增内容是：实际读出收益按来源/阶段标定；区分相对误差尺度与绝对MSE；解析候选可选区间；默认策略尾部价值；H2的匹配费用对照；独立确认和P执行器费用。它们不能倒写成在途版本已经实现。

新版本D来源固定A是一项明确规则。只有在真实运行中选中了对应读出，才能报告实际A覆盖，不能说优化器已学会选择D-A。AV28两次完整预热中，基础新H1/H2仍A=0，可选P-A版有18次A；已有主动D，但这是预热执行信息，完整正式评分待。

## 3. 四个对象必须绑定

每个标签与实际动作同时记录：

|对象|必要记录|
|---|---|
|来源|动作前D/P种类、working birth、birth phase/error、true-D历史、source/projection版本|
|读出|C、实际阶段β1 A、冻结γ融合A；实际α/warp/head/RF/CFG位置|
|误差|同状态同目标guided误差、归一化分母、传播gain定义、该动作而非另一个动作的标签|
|费用|完整CFG pair，已付probe与增量费用边界、候选头、维护/选择/gather/scatter/sync|

同时区分工作源年龄、真D参考间隔、rho支持年龄；它们不互换。已付δ的实际probe参考缓存和σ间隔也需源码/快照核对，不能因rho索引按P年龄查询，就自动宣称δ来自同一P基点；已有P漂移仍标TRANSFER。该项是校准对象核对，不是已经确认实现存在错误。A修正不是新的独立观测，P不是真D。D只消除当前算子近似误差，不恢复原生轨迹，也不清除已经进入latent/UniPC历史的偏差。

## 4. 数学目标与尺度

当前在途版本优化g²×normalized MSE经验分数，保持原定义。它尚未校准成绝对终点误差，不能因gain平方就宣称解决了local-to-final。

N1实际归一化为 `q_norm=MSE/s²`，其中s²是当前同状态dense guided输出的mean-square energy；12点该分母相差2.3502倍。若使用平方传播解释，应有 `g²s²q_norm=g²MSE`。时变s²不能全部并入一个global lambda。

**下一候选的主标定目标预先选为实际绝对guided MSE**，直接由同状态teacher标签拟合少量来源/阶段系数。无需在线调用teacher获得s²；不能把当前teacher能量当线上特征。旧归一化分数作为对照保留，不追改旧参数。

以现有已付的CFG联合probe漂移δ和来源出生误差估计b为低维输入，首版可用：

- D来源：`qC_hat = k[D,phase] * δ²`。
- P来源：`qC_hat = (sqrt(b_working) + sqrt(k[P,phase])*δ)²`。
- 对实际阶段/融合A：`qA_hat = r[source,phase,readout] * qC_hat`。
- 新P：使用同状态**实际P执行器**的出生误差标签，按动作前来源/阶段估计，不直接借P来源C的系数代替。

这些是经验估计，不是严格误差上界或独立噪声方差模型。r允许大于1；不为产生A而截成有收益。P出生误差按其出生时实际来源/执行器版本记录，不设零；A读出不重复把同一来源当新观测融合。

g沿用已绑定传播先验，以g²乘绝对MSE做代理；多步交叉项/方向/非线性仍需实证。λ的单位为秒/所选风险单位，必须新标定，不能复制旧8.6496或2280.8958。旧源分价含已有计时的线性头开销迁移，下一版也需实际profile复核。

## 5. 读出层与更新层

读出层提供可行C/阶段A/相关融合A及对应费用、误差估计。更新层比较最佳可行读出、P、D。D来源C不再被规则永久删除；未可靠估计的状态仍使用π0的已验证默认行为，受同一保护/rho支持限制。

不是先真实执行C/A/P/D全体再选oracle。线上只用已付信息与预先校准模型；如新增候选头或选择统计，真实费用计入。假如允许先做廉价probe再决定P/D，其probe不是免费。

目标是少量有效偏离π0，不是追求四个动作都有次数。基础π0、自由读出和偏离规则分别记录，不能把固定选择写成学习发现。

## 6. 基线相对行动价值与短时域

理想问题为：

`Q_pi0(s,a) = E[remaining_time + lambda_video * terminal_LPIPS | current_state=s, first_action=a, then pi0]`。

相对默认a0的收益为 `DeltaQ = Q_pi0(s,a0)-Q_pi0(s,a)`。质量收益与成本收益分别保留，再按预先冻结的工作点组合。这里lambda_video与局部MSE代理的lambda不是同一个量。

**仅把同一分数减去基线常数不会改变argmin。** 实质改动必须是改善收益标签/状态转移/默认策略尾部估计，而不是重命名目标。

可部署近似采用：

`J_H = sum_{k=0}^{H-1}(incremental_cost + lambda_MSE * g² * q_abs_hat) + V_tail_pi0(s_after_H)`。

先H1，H2保持相同动作合法域和报价。尾部至少考虑距离rho支持到期/保护D还有几步、来源出生误差、π0之后的预计更新与复用代价。不把窗口以外风险当零，不声称近似V是严格最优价值函数。少量两臂后果用于校正是否值得偏离；必要的置信余量也只能作为小样本经验诊断，不能说概率安全保证。
