# 三模块协同开发：首窗口实验卡与接续

2026-10-10，v1.2；配套[方法总设计](WORLD_CACHE_INTEGRATED_MULTI_FIDELITY_DEVELOPMENT_20261009.md)。**设计提报，所有新卡尚未选择/执行。** v1.1更新预算窗口，v1.2接入单次4GPUh自主门槛；不改变既有登记与训练范围。

## 1. 首窗口交付

交付能完整生成视频的 BASE-R 和候选 ABC：WorldCache＋本地校准 RA＋CFG 协调修正＋至少一种真正部分计算刷新＋来源感知选择。优先让方法运行，以完整视频选择修订；不是继续只做“方向值不值得”的机制审查。

开发流程：必要接口控制／RA 基线 → A 与 B 开发（软件可交替，GPU单槽）→ 尽早 AB-naive／ABC → 1–2轮问题驱动修订 → 冻结一个候选的小确认。A/B 不必先单独胜出才允许组合。

## 3. MF-00-R：校准 RA 与共同基线

**问题：**完整运行本地 RA 式联合控制，保持采样器/CFG，建立公平开发参照。

- 沿用Cosmos2.5-2B、guidance7→实际8/−7、35请求／36 UniPC-Karras；两probe均在决定前实际支付。
- 保留调优WC和简单共同刷新作为控制；明确原saliency proxy与官方Di proxy差异。BASE-R采用一种明确代理，不把两种定义混作同方法。
- 为共享anchor C/D 策略建立自身轨迹。CAL标定rho与时间传播；别用混合anchor历史硬套共享表。
- 传播校准使用同状态单次复用干预与其后正确的完整续推，保留UniPC历史。现有数据只有对象/条件完全兼容才复用；局部教师、未保存交叉项、另一原生轨迹不能补造传播表。
- 小规模校准可以是预算适配RA实现，明确统计规模、平滑/插值和与原论文区别。rho=0或g=1版可作消融，不替代合理校准RA主基线。
- 同一CAL、同调参机会先一个中等实际时间点；暂不全阈值搜索。合法D的pre-prediction/post-truth可供A/B校准共用。

**交付：**校准资产/源指纹、执行映射、完整WC/RA视频与实际费用；干净计时另路径关闭teacher/hash/dump。这里是迁移基线，不单独宣称创新。

## 4. MF-A：guided 目标下的 W1

**假设：**β=1和共用修正强度能区分浅层恒等成分与真正增量，联合监督能改善复用后的guided输出。

对照固定：原近似、β=1、原W1、CFG共享α。原warp/Gamma/head与保护设置不同时改。首批α∈{0,0.5,1}或一参数二次拟合二选一，先全局，再按结果选择一种有限扩展。

优先4个CAL场景AV28、Human、misc、AV51，各2个合法预登记状态；最多8起点。已有tensor需检查是否同时具有v0、v1、同状态teacher、真实CFG和条件，未保存不补造。可与B共用一次合法状态采集。

先固定路由作机制隔离，随即接BASE-R闭环完整视频。完整视频包含原正例和两个困难反例；不只在Common/Human换seed。报告guided与分支MSE、系数/退化分布、全93LPIPS及新增head/读写成本。共享输出融合不得冒充hidden线性等价。

## 5. MF-B1：共同mask与有限复用

**假设：**同实际稀疏预算下，协调覆盖更适合guided输出；有限拓扑复用减少路由成本。

对照：原dense D、匹配量化全边MF、当前独立S、conditional-led共同mask S。首批同4场景×2阶段最多8真实起点；沿已验收敏感attention层/核，不重跑104全层矩阵。

层c先算mask；层u用自身当前量化Q/K/V及共同拓扑。深层双QK联合打分不作为首版已有能力。两档强度，记录每层/head的实际保留/执行block数、padding、路由/量化/LUT/核/同步时间和峰值显存。公共CDF参数不保证同密度；匹配实际预算后再比较，不用更密mask解释成选择收益。

共同mask能运行后加入复用2／4次实际S机会的一个版本，记录跨去噪步的年龄和重建。完整深层组成本必须测；小收益仍可进入组合，不要求先超过全部视频基线。

## 6. MF-B2：真正部分 MLP／P0

**假设：**在少数层跳过非活跃MLP，能扩大attention-only之外的刷新节省空间。

- 从实际source映射norm/modulation/projection/gate边界，先4–8层的容量与成本估计，再冻结具体层集合。
- 全token attention，MLP只执行gather后的活跃块；其他位置读投影后层缓存，再用当前gate，禁止完整GEMM再blend作为加速。
- 比例0.5／0.75；共用CFG块集合，同配额随机/轮换先行，廉价风险选择另对照。布局依据实际latent/hidden，不能用93视频帧作token时间长度。
- 初始化/缓存不兼容时dense安全回退；D刷新更新完整层缓存，S/P标近似来源，D-only校准anchor分离。
- 新增缓存字节、峰值VRAM、当前norm/gate、selection、gather/scatter、真实MLP GEMM、attention及整组wall全记。

一组真实正确性调试和必要干净组计时后，尽早在困难场景完整运行BASE-R＋P0；再接B1成为联合S档。源码变化只补受影响控制，不先开展每层发表级矩阵。全深层活跃query/陈旧K/V方案P1留到另一次具体扩大提案。

## 7. MF-C：同动作集合下的来源感知选择

**假设：**保留S/P的创建误差、工作年龄和RA区间风险各自语义，能改善A/B直接组合的完整质量—时间。

首版C/A/一个保守S/D，规则或查表；动作proxy按近似器和D/S来源校准，成本来自实际clean measurements。只在选S后支付深层QK统计。小系数/查表拟合纳入开发，尚未实施训练。

对照固定：

1. BASE-R触发D时按固定规则用S替换，保留合理来源处理，称 **B**。
2. 同A/B执行器，简单分配动作，称 **AB-naive**。
3. 同算子/强度/系数加入来源感知模式选择，称 **ABC**。

“S当D清零”只作明确弱消融，不能是唯一组合基线。S之后频繁D，检查来源质量、密度与寿命，而非只评价一次S的速度。后续小head可用同状态Yq/Yt目标，不要求先大量采Q标签才让当前规则生成视频。

## 8. 端到端比较与分批安排

| ID | 配方 | 目的 |
|---|---|---|
| BASE-N | 匹配Native35；必要时已有/新Native23 | 保真参考与少步强基线 |
| BASE-W | 调优原WC | 本地旧方法 |
| BASE-R | WC＋Cosmos校准RA | 强联合控制基础 |
| A | BASE-R＋CFG协调修正 | 读出部件 |
| B | BASE-R＋固定规则近似刷新 | 执行器部件 |
| AB-naive | 同A/B＋简单分配 | 直接组合 |
| ABC | 同A/B＋来源感知选择 | 核心方法 |

逐批运行必要配对，不把所有阶段和参数在所有场景做笛卡尔积。具体执行卡须先固定场景、seed、所有输出/对照/重复、失败分母、调参机会、参数选择规则和完整forecast；没有冻结卡时不得把此表叫已登记GPU矩阵。冻结后不删控制或成功子集验收。

若A/B单项弱、AB/ABC有效，保留交互，再补2×2消融；不以单项阈值阻止组合。比较选择器时固定算子/密度/参数，比较算子时记录不同动作计数和真实成本。full数相同不是wall相同，S/D数也不是等预算。

## 9. 数据与指标合同

开发场景来自 `configs/cal_w1d8.jsonl`：AV28=`av_28b7cf08-cfb8-41e4-8b1b-d669aa69e632`、Human=`human_199`、misc=`misc_13398218_3840_2160_60fps`、AV51=`av_51b45829-502e-4143-9c32-c026bd6ab191`，原seed0/guidance7/35步。已有Native只在请求、solver、后端和初始噪声匹配时复用。接口卡的seed3不是这些视频的替代参考。

已曝光CAL允许记录明确的有限调参，不能称CONF。冻结一个候选后，先4个未参与设计的新prompt×1seed，只跑匹配Native、RA、候选；有信息价值再补第二seed，不把小确认称论文完成。

主指标：场景等权全93帧LPIPS、真实采样和完整推理时间；报告均值、中位、每场景、尾部和退化帧，不能把帧/多个状态作独立样本。辅助SSIM/RGB、帧差、清晰度、运动/语义自动代理；不新增非必要盲评或人工审核。

诊断和clean速度分开命名。候选真正使用的probe、选择、校准查表、缓存读写、mask、gather/scatter、head和decode边界不能漏算；teacher/hash/dump/评测从部署计时移出，但全部研究GPU进程费用入原账本。拒绝、失败、OOM及未完成路径保持分母；失败配置、证据不足、方向否定分别定性。

## 11. 正常修订与收敛

- guided改善但终点不佳：检查适用阶段/来源/路由耦合，优先小自由度修订；不自动扩大网络。
- sparse组快但全流程不快：拆实际覆盖、mask/scatter、后续D频率与来源寿命。
- 随机/轮换已很好：保留它，贡献可来自联合控制和质量管理。
- S后频繁D：调整来源模型或一档密度；不把单次加速当总收益。
- 单模块弱、组合有效：报告交互，补必要对照。
- 一版失败：保留全部结果，允许1–2轮有具体诊断的修订；实测净收益和成本决定保留/取舍，不以单阈值淘汰整个方向。

S组省10–20%、完整方法匹配质量快约10%或匹配时间失真降约10%可作争取目标，**不是成功承诺或机械停止线**。稳定小收益、尾部保护、校准成本下降也综合评价。投稿证据另提报多prompt、多seed、三工作点、重复计时及迁移。
