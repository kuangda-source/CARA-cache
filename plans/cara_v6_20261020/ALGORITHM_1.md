# Algorithm 1草稿：CAL编译、冻结、部署

1. 绑定模型/权重、solver完整时间网格、CFG/精度/backend、输入协议与支持边界；读取有限共享计划生成器及CAL名单。
2. 对每个预登记候选先执行typed dense move/drop，生成最终D集合；据最终`next retained D`生成连续A区间，剩余为C。若保护、来源年龄或重叠不合法，拒绝该配置。
3. 仅在CAL获取完整实际终点和同定义时间；按实测时间预算、预登记质量/tail约束，选择所有提示词共享的候选。初轮后至多一次原因明确的科学修订。
4. 冻结候选、真实B1/B2、baseline参数、fallback/输入/源码和评价协议，再保留独立TEST。TEST不得参与第3步。
5. 新请求初始化空D历史。逐实际更新：D执行双分支完整计算并写真实来源；C执行原缓存读出；A用当前浅层增量与严格过去D残差构造候选，原warp/head/RF顺序不变，post-RF以共同α融合后执行一次原solver更新。A/C不改写D锚。
6. 未来部署的支持域异常须在动作执行前真实D回退并计费；本次固定mask开发诊断对非法/不支持状态直接失败，两种模式不能混淆。
7. 输出最终视频、实际D/A/C与来源序列、失败/拒绝/回退、完整费用与时间边界。共享序列不宣称逐输入在线调度收益。

第2、3步已有本地纯结构/合成矩阵接口；第5、6步新scope的生产适配和实际CPU尚待，不把此草稿当GPU执行证明。
