# 原理模型 refit：G17 mini-test 诊断 + 重拟合 + 校准成本（零 GPU）

数据：旧 dataset 234 个评估点 + 24 个新点 = **258 点 / 68 layouts / 30 组**。新 run 与 H 批次同卡同 host，F17 bit 级复现，所以并入 H 组截距。所有排名指标都只报 LOLO 或前瞻（训练时不含 G layouts）。脚本：common.py, diag.py, refit.py, meanfeat.py, gen2.py, subsample.py, prereg.py, plots.py。

## 1. 诊断：G19 为什么排错
- 先在旧数据上复现预注册：M5f 的 G17/G19/G22 vs F17 为 0.847/0.678/0.435，和原预测一致。实测为 0.931/1.222/1.012。M1 预测 0.831/0.630/0.428，M0 预测 1.073/0.984/0.783。旧模型在 4 个输入上对 5 个 arm 的 Spearman 多为负（M5f：O1 −0.6，O3 −0.1，N1 −0.2，N3 +0.1）。
- **G19 的额外 D 都在前段**。以 F17 总误差为 1，M5f 下误差的分布是：8–20 步占 0.946，21–27 占 0.052，28–35 只占 0.002。G19 在 8–20 多放 D，被算成把 8–20 段误差从 0.43 降到 0.13（G17→G19）。与此同时，28–35 的全 A 尾巴被算作几乎零成本（σ^2.72 倾斜让尾部免费）。M1 下 28–35 也只占 0.115。
- **长 A run 属于外推**。旧数据中 A 的 age（距上一个 D 的步数）≥4 的步一共只有 20 个，最大为 5。G17 的 A run 到 age 7，G22 到 13，G19 到 15。所有旧模型都假设 A 因子 1−κα 恒小于 1、与 age 无关，所以 A 越多越好。
- **尾部不是免费的**。N3 上 F17_D27 为 0.894、F19_A2_LATE4 为 0.848（均 vs F17）。M5f 预测两者都 ≈0.999，而 M0A 能部分体现出来。
- **输入特异的早期 s(t) 不是主因**。4 个输入的 s/s_MEAN 在 8–20 步约为 0.8–1.9（N1 在 12–14 步达 1.67–1.88），但模型本来就用逐输入 s。把所有输入换成 MEAN s 后，LOLO paired 只降约 0.015–0.02（M0 0.919→0.899，M0A 0.924→0.907），G 排名结论不变。

- 修正 1：A 因子 = max(0, 1−κα) + ρ·α·(age−1)。**只用旧数据就能识别出 ρ=0.185**（κ=0.389，β_L=1.08），也就是说 age 1–5 的短 run 已经显示出这个趋势。这是唯一一个前瞻（不含 G）就把 G19 判成 4/4 输入最差的模型。前瞻 mean ratio vs F17 为 G17 1.208 / tail 1.123 / G19 1.323 / G22 1.049，实测为 0.931 / 0.953 / 1.222 / 1.012。
- 修正 2：σ floor φ 拟合到 0，没有作用。late-A 罚项只用旧数据时不可识别（lt=0）。σ 倾斜加上新数据后 g 从 2.72 塌到 0.205（M5f 全量），说明“尾部免费”被新数据否定。
- **仍然错的地方**：所有模型都把 G17 预测得比 F17 差（M0A 的 LOLO 为 1.27，实测 0.93）。4 个 G arm 的完整顺序在任何模型下都不正确。M0A 的问题是线性 age 罚项过度惩罚 age 6–7 的 A，同时 A 和 light C 的相对价值没有被确定：全量拟合得到 β_L=0.514（light C 优于任何 age 的 A），而去 G 的拟合得到 β_L=1.115（age ≤2 时 A 优于 C）。

## 4. 校准成本子采样（M0A；5 折 layout 留出；G layouts 始终不进训练；每格 20 次重复）
GPUh = Σ 训练 run 的 T_pred + 每个输入一次 Native（252.67 s）+ 0.946 GPUh × 输入数。

| N 输入 | M layouts | paired 中位数 | paired p10 | G19 判为最差的比例 | GPUh |
|---|---|---|---|---|---|
| 1 | 20 | 0.936 | 0.857 | 0.49 | 1.90 |
| 2 | 50 | 0.938 | 0.873 | 0.53 | 4.52 |
| 4 | 50 | 0.952 | 0.914 | 0.71 | 8.17 |
| 6 | 50 | 0.956 | 0.911 | 0.88 | 12.11 |
| 6 | all（约 139 点） | 0.956 | 0.911 | 1.00 | 12.25 |
| all 24 | all | 0.943 | 0.921 | 0.80 | 18.18 |

- held-out paired Spearman 很早就饱和（N=1、M=10 时中位数已有 0.91–0.94）。它主要反映“D 越多越好”这一结构，**区分不出模型好坏**：M5f 在这个指标上中位数 0.95–0.97，但 G19 判为最差的比例始终是 0。
- 真正的瓶颈是 A/C 结构参数（ρ、β_L），要到 **N≥4、M≈50（约 90–140 个点）才饱和**，对应约 8–12 GPUh。再加入 16 个 DEV（MEAN 特征、每个输入只有 4 个 layout）不再提升。
