## 核心定义（符号不要冲突）

```
ratio = h/H                         # 实际冻结噪声坐标
p_pred = p_s + ratio*(p_s-p_old)
d_pred = d_s + ratio*(d_s-d_old)
FULL   = p_pred+d_pred
nu     = p_now-p_pred
DEEP   = FULL+nu
IG     = FULL+kappa*nu
BAND   = FULL+kappa_H*nu+(kappa_L-kappa_H)*P_L(nu)
```

`P_L` 为每帧、每channel、真实二维token网格的互不重叠2×2块均值复制，边界块按实际面积；不做padding引起的虚假正交。κ不与ratio、原β、原post-RF alpha混用。

首轮κ∈[0,1]、CFG两支共享；κ=0/1必须复现FULL/DEEP实际输出。现有A=p_t+d_s不是DEEP，不混淆。历史仅来自过去真实D；当前Dense仅shadow评分。

## 实际guided校准

复用FULL=f00、DEEP=f11；补f10、f01，计算uL/uH与交互w。加一个真实中点f(.5,.5)检验响应面。

以实际 guided error 的Gram矩阵拟合1/2参数。即使raw分解正交，也保留输出Gram交叉项。Band的轻收缩默认lambda_reg=.05，中心是训练fold的Scalar最优，不扫正则强度。

两个prompt留一训练/测试；每fold只有一套系数，不能在留出状态用teacher重算κ。拟合提出的参数还要过真实Phi，不以raw LS或四角插值分数冒充实际误差。

原E1身份一致可复用时，附录规划最多84次guided适配器重放/168分支（两新角、中点、LOPO实际验证及可选全数据拟合重放）。这是适配器计算，不是免费；所有模型驻留/数据搬运/输出保存计入完整报价。
