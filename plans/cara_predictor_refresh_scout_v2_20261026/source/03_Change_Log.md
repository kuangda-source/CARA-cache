# V1 → V2：本次实际修改

## 直接吸收

1. 将 DiCache / DCTA 加入同状态、固定掩码读出对照，不只补 related work。官方算法与 common-adapter port 的身份分开。
2. 固定主噪声坐标；敏感性坐标不参与事后选最优。
3. 收紧1624用途：仅使用原相邻锚点条件下的guided二次统计，不推演不存在的分支向量或独立稀疏H变化。
4. 将转换路径检查置于新特征采集后的第一项，分别检查原生head重放与WC路径。
5. 保存CFG两分支真实p/r和实际历史，并以shadow teacher方式避免污染父轨迹。
6. 继承CAL66的独立质量门，不用LPIPS正结果覆盖MUSIQ失败。
7. 将2×2定位为小样本机制筛查，不以Gamma一个标量判成功。
8. 保护后续新输入确认和迁移的条件式预算，不将所有余额消耗在旧CAL。

## 修正后吸收

- 方向持续性不能只看cos>0；使用 `2<u,v>-||v||²` 检查方向和幅度是否一起合适。
- 不以 `cos_d <= cos_r` 提前淘汰；用显式浅层预测误差与深层预测误差的交叉项判断实际价值。
- “零GPU”仅指已有数据不新增模型生成。导出缺失特征、teacher前向、质量模型和I/O仍计费。
- 旧0.18秒不是新预测器的固定成本；新增锚点也未必恰好一份，必须测真实执行差额。
- 不要求预测器单独“消除转换路径误差”；路径差和预测差会相互作用，应检查完整guided输出。
- 原“先2×2再另开RA卡”改成可合并：RA已验固定掩码可作为预登记布局之一；避免重复消耗。
