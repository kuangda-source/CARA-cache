## 本轮决策

1. 主线以约 1.5× 的实测去噪＋解码加速为近期目标；19D 是首个可行性试点，不是永久固定算法。18D 为预先指定的相邻高速预算，25D 作为高保真配置保留。
2. S（CFG 感知刷新分配）与 Q（CFG 感知缓存编码）先独立。S 优先在高速预算证明算法增量；Q 先证明真实字节—失真优势，不承诺提升速度。
3. 基线与环境问题优先补齐，但只补受影响部分，不重跑完整历史工程。读取已完成输出与主张身份，不为每张小卡重建监督系统。
4. S/Q 未成立时，按失败原因最多启用一个备用假设，不同时重开所有旧线。
5. 新批采用保真优先评价提案：LPIPS 主指标、PSNR/SSIM/参考时序与盲审补充；MUSIQ 是辅助。旧质量门和历史验收保持原结论，不追溯重判。
6. 原 DEV128 已是后续选型的开发资料。原未曝光 TEST 继续保护，不重新划分来清洗历史。
