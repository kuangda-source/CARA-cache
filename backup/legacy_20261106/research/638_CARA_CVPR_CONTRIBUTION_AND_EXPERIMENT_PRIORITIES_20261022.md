# CARA 面向 CVPR 的贡献与实验优先级

最值得推进的主线是：**修正读出提高缓存区间的可用性，再通过一个可复现的程序联合选择刷新边界、修正覆盖和强度，在实际时间预算内获得更好的完整视频保真。** 现有实验证明了修正覆盖的价值；下一步让这种价值成为自动生成、可迁移的策略。

这是研究判断，不是投稿录用预测。CVPR 的官方评审材料强调有意义的贡献、技术可靠性、实验设计和洞见，并不要求每个指标全面领先。[CVPR 评审培训](https://cvpr.thecvf.com/Conferences/2026/ReviewerTrainingMaterial)

## 最有说服力的现有证据

1. **连续修正带来了可归因的完整视频收益。** 已接受的 Window24 在相同 25 次完整刷新和相同刷新位置下，连续 A3 相对纯缓存 C 的平均 LPIPS 降低 26.63%，相对单次 A1 降低 19.77%；四个开发场景均改善。核心时间相对 C 的单次开发均值增加约 0.24%。这个控制直接支持“修正覆盖值得规划”，适合做论文机制主图。4 个场景是独立场景单位，93 帧用于完整视频评价。[完整结果](604_WC_WINDOW24_FULL24_ACCEPTED_CONTINUOUS_CORRECTION_RESULTS_AND_CAL12_NEXT_20261019.md)
2. **已经存在清晰的高保真工作点。** N07 的共同可评分新输入上，H1 的 LPIPS 约 0.0507，WC_HALF 约 0.3264；在相同六个质量/时间身份的联合队列上，H1 相对 Native 的开发速度约 1.267 倍。N08 在两个固定输入、三轮配对重复中独立确认 H1 约 1.265 倍核心加速。这支持高保真推理的应用价值；N07 与 N08 分别承担新输入保真和重复时间的职责。[N07](../reports/wc_paper_N07_R2_complete_results_analysis_20261017.json) [N08](../reports/wc_paper_N08_balanced_full40_terminal_independent_acceptance_roundoff_r1_20261017.json)
3. **已有把发现转成方法的基础。** 固定语法、实际输出统计、异质动作费用、有限候选生成与完整轨迹选择已经定义清楚。完整视频、同状态控制、逐帧复算和真实费用使后续主张可以直接接受检验。N10 已有 129 个原视频的 645 项有效自动评分，可支撑多维质量分析；它复用 N07 视频，不作为额外独立样本。[方法条件](624_WC_REPRODUCIBLE_POLICY_GENERATOR_THEORY_VALIDITY_AND_EVIDENCE_20261021.md)

这些结果适合组成“发现—机制—可用工作点”的开篇。CPU 接入、资源下载和运维可靠性放在复现材料，不占据方法贡献的位置。

## 当前最需要取得的一条结果

**在相同实测时间预算和可比校准机会下，自动生成的策略在新输入上提供强简单前密方案难以获得的质量/成本收益。**

这是最值得投入算力的比较。现有 N07 的 H1 与 FRONT_DENSE_C 的 LPIPS 分别约 0.05067、0.05018；FRONT_DENSE_A 约 0.04894。它们给出了一个有价值且明确的起点：将新方法的优势建立在联合生成的作用上。仅展示大幅优于某个快速失真基线的 LPIPS，不能区分改进来自读出、刷新分配还是更多计算。

贡献定位还需接住近邻工作：CEM 已经将离线区间误差与动态规划用于缓存策略；Golden Path 已研究共享策略、近似读出与完整终点搜索。建议把“有用的新联合决策及其计算效率”作为贡献，把 DP 作为实现工具。[CEM](https://arxiv.org/html/2512.23258v2) [Golden Path](https://arxiv.org/html/2609.39343v1)

## 按论证价值推进实验

| 优先级 | 原有队列与动作 | 完成后应得到的核心证据 |
|---|---|---|
| 1 | 原 BANK24：6 个冻结 DEV、D21/A21/Native、18 正式 + 6 warm；接既定同 D 配额与 X-R 离线分析 | 四 CAL 固定规则在新 DEV 的表现，以及收益是否与选择/修正方向一致 |
| 2 | 原完整 1624 真实区间表与独立动作价格，14 完整路径，保留已批整卡 12 GPUh 上限及新机准入条件 | 哪些区间值得修正、修正的真实价格，以及可复现的生成器输入 |
| 3 | PG-P1：0.80 Native 实测预算、固定 Q≤8、首4+后4、一次 SELECT 冻结；按完整卡报价/CPU后执行 | 第一张由代码产生的策略优于可比前密 C/A 的完整终点质量—时间图 |
| 4 | PG-P2：同读出下只优化刷新、固定刷新下优化覆盖、联合生成、纯代理与同额简单搜索；统一信息/Q并列完整校准 GPUh | 明确改进来自哪项决策，以及有限校准预算是否花得更有效 |
| 5 | PG-P3 的第二预算与第二模型/设置重校准；PG-P4 冻结后新 TEST、自身重复计时和质量 | 同一个生成程序能否适应预算/模型变化，并在最终新输入中保持收益 |

此排序对应原已登记队列，不改当前 24 路、1624 格或校准/测试划分。P1/P2/P3/P4 尚未准入的卡继续完成各自范围、全量费用和生产验证；不把旧 N07/N08/N10 的结果当作新生成器结果。

## 最值得做好的四张图

1. **修正延长缓存区间的机制图。** 相同刷新位置，展示 C、单次 A、连续 A 的完整视频失真、运动区域与对应真实动作价格；从现有 Window24 与后续真实区间表衔接。
2. **质量—实测延迟前沿。** 主对照使用原定官方 WorldCache 配置、RA 与强前密 C/A；主表在相同模型、输入、seed、精度、帧数和计时边界下比较。将当前“同 D 次数”控制与“同实际秒数”应用比较各自说清。
3. **相同校准机会下的生成过程。** 展示 Q、候选实际质量、一次联合修订带来的增量，以及累计校准 GPUh。算法归因允许共享相同资产；完整成本比较保留各方法真实所需准备费用。
4. **同程序重校准后的迁移图。** 第二预算或第二模型重新测表、自动生成、冻结评测；记录哪些边界/覆盖自动发生变化。把“方法换模型仍成立”落实为程序复用。

最终 TEST 使用新身份，以 prompt 为统计单位、seed 为组内重复；报告平均值、尾部和拒绝/失败分母。LPIPS 与主体/运动/语义质量并列读数，不将视频内帧数当成独立样本，也不把 Native 保真自动等同于物理能力。若论文主张落到物理预测任务，再为该主张增加相应任务指标。

最新近邻 SpectralCache 已将谱特征预测用于世界模型缓存，后续比较应核对其模型、协议和实现是否可比；不直接横比不同模型和质量指标下的加速数字。[SpectralCache](https://arxiv.org/abs/2610.02660)

## 长程执行与验收

每张长卡按实际 launch 的整卡估时设置一次半程检查及一次预计结束后的终态收件。半程检查进程、日志错误、完成量、显存、磁盘、锁及费用，保留冻结方法；终态核验全范围原件、完整评分、控制、释放与账单，并重算主要统计。若提前终止，按终态失败处理；若到时仍在运行，按实测剩余量重新估时一次，不盲目重派。

当前最紧迫的科学问题已经可以用现有队列回答：**联合生成是否在实际预算内把修正的价值转化成可复现、可迁移的完整视频收益。** 优先让这一点形成强证据，随后围绕它组织主文。
