## 1. 研究问题与目前判断

研究对象是在同一视频生成骨干和采样网格上，用缓存复用减少昂贵的完整计算，同时保持相对原Native生成的内容、运动与细节。当前主线使用Cosmos生产入口；近期实际GPU实验在同一台两卡服务器的RTX A6000上执行。

核心问题分为三层：

1. **可行性：** 在19次完整刷新预算下，能否找到比均匀刷新更好的速度—参考保真工作点？
2. **方法性：** 能否用固定、可复现的风险规则产生该布局，而不是靠人工指定步骤？CFG两分支误差的相关项是否提供独立价值？
3. **竞争性与泛化：** 该规则能否超过强简单布局和端点预算搜索，并在未用于选择的输入、额外种子及预算/网格上保持收益？

**已有最强证据：** 在四个旧CAL输入、seed0上，F19-C相对同19D且时间几乎一致的Uniform19-C，平均Alex LPIPS误差降低46.82%，4/4输入同向；相对Native35，注册T_DD加速1.703×，完整请求加速1.486×。

**仍未回答：** S-CFG是否改善完整自由生成视频、是否优于S-DIAG和F19-A1、是否优于预算搜索赢家。F19-C的LPIPS为0.249365，尚未达到原Fast研发目标约0.10，因此目前有明确相对优势，但高速高保真目标还没有同时实现。

**当前解释（待评审，不是新增实验结论）：** 布局选择有价值已经有直接证据；CFG风险作为布局生成方法的独立贡献仍需一次有辨识性的完整视频比较。

## 2. 术语、数据和评价口径

### 2.1 术语

| 名称 | 本文含义 |
|---|---|
| D | 一次完整刷新动作；19D/25D指完整刷新次数，不是总采样更新数 |
| C | 既有缓存复用动作，沿用原读出实现 |
| A1 | 在指定、距最近真实D为1的新增复用位置使用既有A动作；并非对所有C步替换，也不是新增独立训练模型 |
| Native35 | 请求35步、运行时实际36次更新的全计算参考 |
| Shared25-C | 25个D，其余更新使用C的高保真参照 |
| F19-C | 手工指定19D布局，其余17次更新使用C |
| Uniform19-C | 在真实噪声坐标上由确定性均匀覆盖程序产生的19D布局，保持共同保护点和合法历史约束 |
| S-BR / S-DIAG / S-CFG | 用三种局部误差目标，按同一规则生成刷新布局 |
| Q | 在固定布局下，对实际被C读取的缓存做有损编码；独立于S的刷新位置选择 |
| BudgetSearch19 | 从Uniform19出发，用完整双FIT视频端点评价驱动SA＋HC搜索的预算适配基线 |

这里的“端点”指完整自由生成后的输出视频，而非扩散过程某个中间状态。

### 2.3 指标与时间

- **主要保真指标：** 固定Alex LPIPS到同输入、同配置Native参考，完整93帧，先视频内平均，再对输入等权。它衡量参考保持，不等同于无参考视觉质量。
- **辅助指标：** PSNR、SSIM、逐帧LPIPS曲线；参考误差的帧间变化、梯度误差与能量比。PSNR用整段RGB均方误差转dB；全等输出保留无穷值。参考时序差会受运动错位影响，不直接称“纯闪烁”。
- **T_DD：** 去噪循环入口前同步，到VAE解码完成后同步的连续墙钟，包含必要在线复用逻辑、等待和解码。尽管名称中有DD，它不只是神经网络前向时间。
- **T_request：** 完整驻留模型请求时间，和T_DD分别报告；加载、预热和校准成本另列。
- **聚合：** 正式与登记计时重复先在输入内求均值，再对输入等权；加速比为Native均时除以方法均时。B36的prompt bootstrap仅作探索区间。
- **研发目标：** T_DD约1.5×且平均LPIPS约≤0.10；它是研发方向，不是普适感知阈值，也不事后改变已完成实验的接受规则。

## 5. S：CFG感知风险能否产生更好的刷新布局？

### 5.1 数学设计

在同一状态、同一历史、post-RF输出坐标中，令缓存输出相对完整输出的两分支误差为e_c、e_u：

```text
C = mean(e_c²)
U = mean(e_u²)
K = mean(e_c e_u)

q_BR   = (C + U) / 2
q_DIAG = 64 C + 49 U
q_CFG  = 64 C + 49 U - 112 K
```

当前程序guided组合系数为a=8、b=-7；通式为a²C+b²U+2abK。负提示词分支不一定是空无条件分支。CFG与DIAG的主差异是交叉项，BR为附加参照。使用FP64归约并与直接guided误差核对。

三目标共用归一化、prompt/父轨迹权重、时间权重和合法候选集合。从同一个起点枚举一次合法remove-D/add-D，按R(add)−R(remove)排名，固定平局规则，无正增益则保留原布局。预算19D、总更新36次、保护点和历史支持不变。这是一轮机制筛查，不是任意多轮搜索。

### 5.2 已完成真实采集

两个FIT输入×两个父策略（Shared25-C、F19-C）×27目标位置，完整108个同状态标签。实际10条路径、468 pair、936分支readout及151个文件完整接受；GPU释放、CPU后处理和唯一结算完成，实际 **3.039352411 GPUh**。

目标步为8..35去掉24。必要shadow只用于评分，不更新部署缓存、求解器或RNG；父策略和不同中间状态不作为独立prompt计数。

### 5.3 F19起点：三目标选择相同

BR、DIAG、CFG都从170个合法候选中选中 **删除D21、加入D35**。原选择已独立精确复现。

这一结果说明三种风险在该离散选择问题上的最终执行相同。即便局部风险或排序不同，也无法用同一个生成策略证明CFG相对DIAG的端点增量。原S冻结保持，不把三个名称当作三种不同方法重复生成。

### 5.4 通用Uniform19起点：出现可区分输出

依照事先采用的初始化敏感性设计，复用同一组已接受FIT风险，使用确定性Uniform19作为另一个起点，仍只做一次交换：

| 起点 | BR | DIAG | CFG | 不同执行策略数 |
|---|---|---|---|---:|
| F19 | D21→D35 | D21→D35 | D21→D35 | 1 |
| Uniform19 | D22→D35 | D22→D35 | D25→D35 | 2 |

新增历史组合及选择器生产路由已做CPU验证。三种受影响策略在两个FIT、ON/OFF/AUDIT和两种flow下，完整36步guided轨迹、终态latent/RGB及RNG与相同配置的旧固定掩码入口一致；这里使用的是明确的微型模型测试，不是真实权重视频结果。

**关键解释：** Uniform19起点提供了检验CFG交叉项的可辨识条件，但风险仍采自Shared25/F19父轨迹，未重新采集Uniform19父轨迹。局部风险跨历史、跨状态转移是否可靠，是需要完整自由生成检验的假设。现在不能声称CFG已优于DIAG，也不能用CPU数值一致性证明视频改善。

## 8. Q、邻近预算与迁移的进展

### 8.1 Q缓存编码

Q固定原Shared25-C与原精度，不同时改变刷新布局。比较独立两分支表示I=(r_c,r_u)，与共同/差分表示M=(m,δ)，其中m=(r_c+r_u)/2、δ=r_c−r_u。量化为真实INT4/INT8打包，按每token通道128一组，计入scale、padding及未压部分。

同实际字节候选中分别用BR和CFG真实输出失真选codec。R16/R12表示每对对应元素的payload位数，不是整个缓存精度；payload压缩不能直接称总显存或峰值下降。

原Q1已完成12保存状态、111 pair/222 head的实际读出，数值控制、释放、CPU分析及实际0.298756494GPUh结算接受。R16的两目标在各表示内选相同codec；R12中I-BR选(4,8)、I-CFG选(8,4)，M-BR/M-CFG均选(8,4)。这给出了部分选择差异，但尚无完整视频、部署峰值或吞吐收益。Q-END保持独立评估，不作为S成功的前提。

### 8.2 F18、Q5与第二骨干

- F18是事先指定的相邻18D预算，已有CPU组件准备，未形成新GPU科学结果。
- Q5在这里指50步采样网格验证，**不是缓存量化位宽**；Native50参考CPU组件已验证实际51更新，方法mask、映射、整卡范围与费用仍待。
- Wan第二骨干与原最终确认输入后置。当前不应把旧CAL上的正向信号写成跨模型、跨预算或新输入泛化结论。

## 9. 对现有证据的综合分析

### 9.1 已能支持什么

1. 在当前四旧CAL/seed0/同19D条件下，F19布局相对确定性Uniform布局具有明显参考保真优势；这不是靠多用D或明显增加请求时间得到的。
2. A1在该F19布局上有较小但四输入同向的自动指标增量；感知增量尚不清楚。
3. S三风险已在真实父轨迹上完整采集、独立重建；F19起点的同mask现象是真实结果。
4. 通用Uniform起点使CFG与DIAG产生不同合法策略，下一轮能够检验该差异是否有完整视频价值。

### 9.2 哪些解释尚不能成立

| 待检验解释 | 当前缺口 |
|---|---|
| CFG交叉项构成已验证的方法贡献 | 只有局部风险和选策差异，没有新的完整端点比较 |
| F19已解决高速高保真目标 | LPIPS约0.249，高于原约0.10研发目标 |
| A1具有明确可见质量优势 | 自动指标改善未在单人粗粒度审阅中体现 |
| 当前胜过所有同时间外部缓存 | WC/RA为FIT UNMATCHED，且为本地适配 |
| 14GPUh基线与S实际费用公平匹配 | 仅上限相同，查询方式、选择目标与实际成本不同 |
| 四CAL结果已证明泛化 | 单seed、开发集多次使用，需冻结后新输入确认 |
| CPU检查数量代表方法效果强 | CPU证据主要支持执行正确性和数据完整性 |

### 9.3 当前最值得评审的研究风险

- **局部到端点的错配：** 新mask改变后续缓存历史和latent；父轨迹q不是刷新动作的真实端点边际收益。Uniform初始化还增加了父分布与执行分布的差异。
- **初始化与交叉项的归因：** 从F19到Uniform后才出现可辨识差异。该分支有事前设计依据，但新的端点比较仍必须作为开发性机制检验，不能当成独立最终确认。
- **搜索基线目标错配：** RGB MSE搜索与LPIPS主评价不同，可能影响竞争解释；当前运行不能按部分结果改变目标。
- **预算公平：** “同允许上限”与“效率更高”的论证需要同时报告实际校准GPUh、查询数、端点性能和部署请求时间。只看赢家质量或只看硬限都不够。
- **对照强度：** F19-A1必须保留。若S只赢DIAG却不赢F19/A1，说明机制有差异，但部署价值仍有限。
- **工程投入与研究信息量：** 已做大量组件CPU验证。后续应围绕尚未覆盖的真实风险补齐整卡，避免重复验证已接受组件而延后关键视频比较。
