# 来源感知 C/P/D：从固定 P0 到联合动作选择

2026-10-10。接续 [236](236_WC_A_PLUS_P0_EXPLICIT_SEMANTIC_SOURCE_COMPOSITION_20261010.md) 和现行多精度计划。本轮是控制器实现与参数单位检查，不改变正在运行的 232 载荷、288 条 CPU 路径，也不替代待确认的 RA＋A 完整 32 路径卡。

## 要做出的方法

复用本地 RA 的双 paid-probe 联合几何及传播先验，增加共同 P 动作。完整 D 仍更新真实 dense anchor；P 更新工作来源，具有非零创建误差，不能把 RA 区间累积量清零。A 沿用已实现的共享强度读出，第一版固定一种 A 配置，不同时训练 A 风险模型。

在本轮规则中，记 RA 双分支 proxy 为 q，近似工作来源的创建 proxy 为 f，P 相对漂移系数为 k、非零创建 proxy 下限为 b，传播系数为 g：

- C 的新增经验风险：g(f＋q)。
- P 的新增经验风险：g(b＋kq)；完成 P 后工作来源创建 proxy 设为 b。
- D 的本步创建近似风险设为 0；只有实际双 D 完成才重置区间累积分数和 dense anchor。

选择“区间累积＋本步风险”满足既定阈值的最便宜可行动作。成本输入必须包含两分支、实际 A 额外 head、路由和缓存维护；不硬编码 C<P<D。若 P 更慢或缺少同单位创建 proxy，它不会因名字是近似刷新而被优先选择。第一版最多连续两次 P，作为预登记的来源约束；此约束是否必要由后续消融检验。

以上是低参数经验规则，不是终点误差上界。P 来源上的 paid-probe 与过去 D 的 RA 校准存在分布差异；保留原传播/相关先验属于显式迁移假设，须通过完整视频确认，不能写成已经重新校准的 P 来源模型。

## 单位是本轮必须解决的具体接口

真实 P0 八个起点可给出 sqrt(MSE_P/MSE_C) 的无量纲相对系数。它们不能单独给出 RA `WC_PAID_DELTA_Y` 单位的 b，也不能提供 clean C/A/P/D 成本。因此，本轮只按新登记统计四种 P0 模式的全部八个比值与中位数，保留每个场景/位置；不利用整组计时冒充 clean 动作成本。

控制器接受绑定版本与单位的外部质量/成本输入。缺少正的 b 或可核对单位时，P 明确不可用；CPU 用显式 SYNTHETIC 参数验证完整控制逻辑，不自动生产一套看似已校准的服务器参数。下一次真实接线时在实际 D/C/P 同状态记录中同时保留 paid-probe、实际 guided 误差和完整动作耗时，建立单位转换；不先训练 Head。

## 本轮预登记范围与对照

1. 真实旧资产只读分析：原四场景×step12/30×六模式完整 48 行，四 P 模式各八个创建误差比；沿用原八起点/144 计时分母，绝不把旧描述性分析改成事先选策略。
2. 纯 CPU 数学/事务验证：无 P 时，对多个 synthetic proxy 序列逐步核对原 RA 的全部 36 次决策与状态；P 后 C、连续 P、强制 D、逆成本顺序、未知质量/成本回退、失效 paid pair、未完成分支拒绝、历史恢复、过期决策与伪造分数拒绝。
3. score-only 不改变部署历史或 RNG；提交只在实际两分支完成后发生。来源创建步、dense anchor、工作年龄、连续 P 和区间分数分别记录。
4. 当前阶段不安装真实 sampler 选择器、不运行 GPU、不变更预算、不宣称终点保真或真实速度。完成核心后接入已有 A＋P0 sampler；实际动态轨迹、状态恢复、GPU 配置另绑定新卡，不修改封存载荷。

真实 P0 局部误差改善说明 P 值得参与选择，整组收益约 0.3%–1% 提醒我们还要测净成本。控制器不以这一个数字否定方向，也不预设增加 P 必然更快。
