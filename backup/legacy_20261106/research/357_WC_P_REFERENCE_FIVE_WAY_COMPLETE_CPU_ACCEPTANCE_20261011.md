# P 五读出同状态完整 CPU 独立验收

**五种缓存读出已能在同一个实际状态上完整比较，且评分后继续原部署轨迹。** 两种光流设置的完整 CPU 执行和全张量独立读取均通过。这个结果解决的是实验实现与可比较性，下一步可进入真实模型入口准备；还没有产生真实模型的 P 参考误差、视频质量或加速结果。

## 本轮回答的问题

旧 E4c 已观察到全部 12 个 P／D 来源年龄对中，P 的局部 guided 误差高于 D；Human 早期 age4 为 8.4598 倍。那两臂随后各自生成不同 latent，不能把差异完全归因于读出公式。本轮固定每个来源自身当前的 latent、条件、求解器历史、缓存和 D 校准统计，比较五种读出，分离参考点与系数的作用。

新假设仍为 H-P-W1-WORKING-REFERENCE：在 P 来源上，使用当前 P 工作参考的 probe／prewarp residual，比沿用过去 D 参考更合理。系数仍只来自真实 D；P 不成为真实 D 或零误差锚点。五个版本为官方 C、新 P scalar、旧 D unit、新 P unit、旧 D scalar。先计算一次同状态完整 teacher 并恢复；前四候选分别恢复；最后旧 D scalar 继续原轨迹。两 CFG 分支的误差以实际 FP32 `8e_c−7e_u` 差向量、FP64 MSE 归约比较，所有版本均保存。
