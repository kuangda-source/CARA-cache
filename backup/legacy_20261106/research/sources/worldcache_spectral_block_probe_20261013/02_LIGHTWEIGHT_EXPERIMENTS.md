# 频域特征 F 与部分 Block 执行器 B：轻量探索计划

日期：2026-10-13。状态：PROPOSED；未启动 GPU、未修改主线。

## 0. 目标与不变事项

当前只回答两个问题：频率结构是否提供超出现有 proxy 的动作信息；部分 Block 是否提供比四层部分 MLP 更好的真实成本—误差折中。理论有依据即允许试验，不要求先证明必然成功。

保留当前 A_NO_P、P_OFF、RA 及原 E2。用户已暂缓的 13h P 参考卡保持 USER_DEFERRED_RESULTS_DISCUSSION_FIRST，不执行、不缩卡绕过、不重复催批。本探索是新问题、新配置，不替换其科学对象。

先在旁路获取信号，再做小型完整视频桥接；未通过桥接不并入主线正式配置。最多一条昂贵 GPU 作业。最新预算／授权必须从项目当前状态核对，报告44.04GPUh只作历史快照。

## 1. 轻量的实际含义

- 无生成器训练、LoRA、大型预测器或全量 benchmark。
- 共享父轨迹、来源状态和同状态 dense teacher，不能两条分支重复买同一批数据。
- 一开始不做全26层×多稀疏率×多频带×多种子矩阵。
- 研究总预算先提报不超过6 GPUh；所有加载、生成、恢复、重试、取证与收尾计入。不保证这个上限能完成全部目标，按实测完整配对缩减；预算不够时不留下无法比较的单臂。
- CPU 代数验证已在随包脚本完成，不代替项目CPU接口和真实设备验证。

## 2. 四个阶段与候选费用上限

| 阶段 | 内容 | 提报上限 |
|---|---|---:|
| E0 | 资产检查、CPU数学与已有张量分析 | 0新增GPUh |
| E1 | 共享小数据／少量真值与频特征设备计时 | 1.5GPUh |
| E2 | 部分执行器同状态筛查与少量来源延续 | 1.5GPUh |
| E3 | 一个幸存频特征＋一个执行器的完整视频桥接 | 2GPUh |
| R | 合法修复、配对补完及必要重复 | 1GPUh |

这些是提案，不是既有执行许可。每阶段按实际项目规则启动，严格超过8GPUh的完整卡确认规则不通过拆卡规避；本方案不将6GPUh视为自动授权。

## 3. E0：先检查可用材料，避免重新取证一遍

读取现有 CURRENT_STATE、最新报告、冻结源码、在途任务、账本和合法任务范围。保持主线默认分支无改动，新增独立 feature flags。

检查现有保存内容是否包含：

- 决策前 p_c/p_u，source id及其probe；D/P各自真实时间、age、历史来源。
- 可还原的token网格及空间／视频时间轴；FP类型、padding、position信息。
- 同一实际状态上的完整输出teacher及C/A实际候选输出。
- 新执行器需要的合法历史逐层残差。只有整栈残差时，不能宣称已具备逐层缓存。

只保存标量／视频时无法事后恢复浅层频谱；只保存当前层输出时不能构造过去层残差。缺失标注为MISSING，需要时并入E1真实取数，不能伪造或直接从视频FFT替代。

输出 feature_inventory.md、branch_scope.md、split_manifest.json。若已有架构CPU等价不变，复用已有证据，不新建一个巨大的审计框架。

## 4. E1：F 探索与共享标签

### 4.1 数据

起点为四个既有CAL提示词各最多四个自然状态，共16状态。尽量覆盖中/后阶段、D/P来源及合法age1–6；不是强制全笛卡尔积。

状态只能根据执行前元数据（阶段、来源、年龄）预选，不按teacher收益选最好点。自然不出现的格子标缺失，不通过无标签的强制P冒充自然样本。

若16状态只能判断明显的实现问题，仍有信息信号时扩至最多32状态；不把小数据不显著叫理论失败。所有新增标签和续推都服从1.5GPUh上限，超额则重新规划，不自动扩。

### 4.2 模型／特征对照

| ID | 特征 |
|---|---|
| F0-full | 原有RA/raw proxy＋source、真实tau、Delta tau、age |
| F0-sub | 相同8–16通道子集的raw能量＋同样元数据 |
| F1 | F0基础＋Haar低频/细节及CFG相关统计 |
| F2 | F0基础＋小规模2D FFT两频带复差分统计 |

两个频带使用同一当前滤波器比较当前与来源，先固定频带边界。最多保留2–4个新增可学习系数；不要按source×phase×band分别拟合一堆小模型。

初始观察F1/F2后只保留一个进入全视频。时间变化滤波器、完整3D FFT、全通道变换暂不全部加入。

### 4.3 输入因果性

F特征必须在待跳深层计算前可得。当前完整误差、当前未执行attention map、未来视频只能作为离线标签。不能先算完整deep再说FFT门控很便宜。

读出的源probe、warp参考、时间、branch必须绑定真实source。P_OFF来源规则不被这一探索静默替换。

### 4.4 标签：不是让新指标评价自己

对每个状态共享teacher：

    q_C=mean((v_g^C-v_g^D)^2)
    q_A=mean((v_g^A-v_g^D)^2)
    y_CA=q_C-q_A.

A使用对应冻结读出和阶段强度，记录合法性／fallback。不能使用新频权误差作为唯一标签，然后用它证明新频权最优。

保留旧固定阶段/source特征作为强对照。判断F是否改善真实unweighted guided误差或动作收益排序；当前N2的A=0和rho支持域问题不能被FFT掩盖。

拟合和验证按提示词整组划分；单状态行随机拆分不合法。四提示词可做留一提示词探索，但不能视为独立泛化。归一化只用训练部分。

主要诊断为动作遗憾和成本—误差动作下包络，相关系数仅辅助。lambda使用同一预登记值／开发小网格，不针对每条终点选lambda。

### 4.5 特征的真实成本

先完成固定形状warm-up，使用设备计时统计完整操作链，在一组代表形状上例如10次预热、30次测量；所有真实费用仍计入研究预算。

计时包括子集读取、布局、滤波/FFT、聚合、cache谱更新、kernel launch和同步。分别报告只计算特征和“特征＋现有控制”的增量。

工程目标可设新增整条推理成本<=0.5%，超过1%先尝试Haar、降低调用频率或减少布局搬运。不是超过1%就理论失败：最终要看节省是否覆盖成本。

### 4.6 进入下一步的参考信号

跨提示词探索中，F1/F2相对同元数据raw对照的加权动作遗憾减少约15%–20%，且不是纯阶段规律；或已有明确可解释的动作区分值得小续推。

小样本区间过宽标INCONCLUSIVE。若F1与F2相当，优先较低真实开销者，不因FFT更有论文感而保留它。

## 5. E2：P-Block小型执行器筛查

### 5.1 候选上限

共享E1状态，起步只在两个CAL、每个两个合法中/后阶段起点测试。deep teacher用于整组同状态guided误差比较；各候选都用自己的中间状态自然走完该次网络调用。

| ID | 设计 | 第一批范围 |
|---|---|---|
| P0 | 当前四层50% MLP部分更新 | 基线 |
| B-M8 | 八层50% MLP部分更新，attention全算 | 1个预登记层集 |
| B-L2 | 2个Block复用旧residual，其余当前计算 | 1个预登记集合 |
| B-Q2 | 2个Block中完整当前K/V，50%活跃Q、输出、MLP；非活跃用合法旧residual | 1个预登记集合 |
| D-stateful | 完整当前计算并维护对应合法缓存 | 匹配成本/误差参考 |

本表不是所有项目必须实现。若QKV布局不支持实际部分Q，不进行昂贵kernel重写，记录实际开销先测B-M8/B-L2。若某候选有信号，再把M8扩M12、L2扩L4、Q2扩更多层，最多新增一种，避免矩阵爆炸。

B-Q-stale（陈旧K/V）先只在一个已经验证的层做离线误差差分，不作为本批主要完整执行器；只有fresh-KV成本确实受K/V投影限制才提报。

### 5.2 层集和mask如何选

按已有／新增的少量设备profile与可用显存选择层集，事前登记，不能看终点后选择幸运层。

token共享同一CFG选择集合，先用均匀轮换为主，补同配额固定随机。无attention matrix物化、无复杂重要性网络。旧attention稀疏算子坏层不能自动当成所有精度/部分MLP场景的永久禁区，但已有失败边界不得静默忽略。

整block residual与逐子层residual是不同候选，不能把旧absolute hidden写回当作current residual保持。

### 5.3 合法缓存和状态

从真实过去D或已定义的部分来源采集新增层缓存，初始化/维护计费。新partial更新为P-v2，携带非零出生误差；不更新真实D校准历史。

每层/每token可以有不同age。第一批固定轮换保证覆盖，并保存对应age。不能给所有状态统一age=0掩盖混合来源。

新执行器的出生误差、后续漂移和成本表不沿用P0当真值；没校准之前不能拿它自由进入原W3全域。

### 5.4 精确的对照和计时

- fresh-KV活跃attention与same-input dense对应行比较；这是局部实现验证。
- 整组guided误差与同一实际latent的dense teacher比较；这是网络近似质量。
- 设备计时含选取、残差读写、K/V维护与所有实际head，不能只测一层快kernel。
- 同时记录新增驻留内存与瞬时峰值。方法缓存与诊断checkpoint复制分列；显存上限沿项目安全余量，不降低保护来跑完。

D无维护、D维护候选状态、候选P-v2三种费用区分。重放前恢复副本在计时外，但部署确需发生的写回在内。

### 5.5 不用单个5%局部误差线淘汰

寻找成本—误差非支配点。一个比P0明显便宜、局部误差稍高的候选，也可进入小终点桥接；单局部MSE最低不代表最好。

工程发展目标：双CFG deep组比匹配D省至少约5%，争取10%以上；这是投资参考。若仅省约1%且误差更差，先诊断覆盖与访存，允许一次有依据修订；仍无变化则暂不扩该实现。

### 5.6 极小来源延续

对一个幸存P-v2，最多4个起点比较P0/P-v2在相同预登记后续C/A策略中的age1/2结果。不能强制age超支持域然后称自然部署失败。

若采用固定后续掩码，这是受控来源诊断；若用同一自适应函数，要记录不同后续动作与费用。两者不混称。

## 6. E3：完整视频桥接——成功才并入主线

先在两个专门用于探索、且不属于E2/正式CONF的提示词上，冻结一个频率候选F和一个执行器B，生成：

| 方法 | 作用 |
|---|---|
| P_OFF基线 | 强候选 |
| P_OFF+F | 频率增量 |
| P_OFF+B | 执行器增量 |
| P_OFF+F+B | 小组合 |

另需匹配Native参考；缺失参考的成本计入同卡。先1 seed，最多8候选视频+2参考。若F或B没有入围，则不强行补齐所有格子。

优先采用受控macro动作掩码的最小桥接：P/D位置固定于基线合法轨迹，B只替换已有P，F在预登记的非刷新位置选择C/A。各自latent、solver、cache自然演化。这是因果／机制桥接，不是全自由在线调度。

如要进一步宣称可直接并入在线主线，需要另做一个极小闭环：F只读取当下可用特征，B按开发侧出生误差/age1–6重新校准，保留原保护规则与合法性；全部事件自然发生。不能把受控掩码的收益叫可部署调度已经有效。

E3的2GPUh若不足同时做两阶段，只完成受控桥接并报告，在线确认另提案。不能为了“成立再加入”而把未执行在线验证写成已通过。

指标：完整93帧LPIPS＋相同时序/清晰度/运动守卫；时间含真实方法开销，单次时间仅筛查，不宣布稳定加速。原生保真不是绝对物理质量。

至少两个代表输入各三次平衡顺序重复计时，可由预算允许的幸存路径完成；否则计时结论暂定。来源/动作覆盖、A可选性、保护D、缺支持D逐项报告。

## 7. 进入主线的条件与出口

F：相比raw+source+tau强对照，确有新增判断价值；真实开销可回收；不是用自己的加权指标循环证明成功。

B：完整当前上下文和残差语义正确；真实成本产生可用优势；新来源不因后续频繁重算吃掉全部节省。

正式主线合入要求：冻结一个候选，至少完成小型新探索输入闭环及干净时间筛查，形成相同时间更准或相近质量更快的可复验信号。5%左右净改善可以作为继续投入参考，不是必须达到的定理或投稿门槛。

| 结果 | 动作 |
|---|---|
| F有用、B无明显收益 | F先进入W3开发，P0不变 |
| B有用、F不及Haar/raw | 使用B与简单选择，不强行FFT |
| F局部有用、终点无改善 | 先检验local-final和成本，不立刻增加控制器容量 |
| B单次快、整段不快 | 检查来源寿命、动作频率、维护税；不是直接否定部分Block |
| 两者组合有效、单项弱 | 允许保留组合，补2×2归因；不强求单项都显著 |
| 数据不足或源码不支持 | INCONCLUSIVE/TECH_BLOCKED，不写科学FAIL |

每个实现允许一次有明确原因的修订，不搞无界参数搜索。已有E2和主线方法确认始终不被本探索替代。

## 8. 报告最小字段

实验ID、冻结方法hash、父状态/来源hash、提示词分组、seed、真实tau、视频token布局、分支、source类型与age、D校准间隔、feature计算时机、teacher是否只读、实际稀疏集合、同状态guided误差、动作成本、未来成本、峰值内存、终点指标、失败与拒绝、累计实费。

模型配置和开销相容性不满足时，不复用旧秒数。源数据没有的字段不自动补0。
