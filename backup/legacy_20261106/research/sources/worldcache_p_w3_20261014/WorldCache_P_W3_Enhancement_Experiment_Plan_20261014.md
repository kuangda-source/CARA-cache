## 1. 统一问题与验收定义

我们希望从现有的 `C/A/D` 精度选择，扩展为「**低成本、可校准的输出修正 + 成本合理的中间更新动作 + 可理解的选择器**」，而不是为了图示完整强行保留四个动作。

现有 post-probe 费用：

| 动作 | 现有双分支 post-probe 费用 | 局部语义 |
|---|---:|---|
| C | ~0.16846 s | 原样缓存读出 |
| A（D 来源） | ~0.33811 s | 修正读出，不能创建可靠 D 来源 |
| P0 | ~6.17331 s | 旧部分 MLP 更新，出生误差非零 |
| D | ~6.25420 s | 两分支完整计算并更新可靠 D 历史 |

旧 P0 比 D 仅省约 1.29%，在一步目标下很难成为有竞争力的中间动作。新增 P **不是沿用旧 P 的报价或 q 标签**，而是从真实执行重建成本、误差与来源语义。

统一两种成功形式：

1. **直接局部改进**：相同合法状态下更好的真实 `guided MSE–post-probe cost` 组合；
2. **闭环改进**：相同输入与原生参照下，最终 `LPIPS–full generation time` 前沿改善，或者相同费用下更少失真。局部有效不自动推出闭环有效。

只要合成 `P+W3` 有可信净效益，允许单个模块独立效果较小；反之，单个回归损失降低、动作频繁改变都不等于成功。

## 2. 阶段 E0：免费数据清点与数学诊断（尽量 0 GPUh）

### E0-A. 冻结环境与数据边界

1. 冻结 **H1、A_NO_P、WC/RA 对照**的代码哈希、采样器、精度、加载／计时边界、seed、提示词清单。旧 CAL/CONF 只是复现与诊断用，不再伪称新独立确认。
2. 建立 `EXPL_DEV`（仅探索／模型选择）与 `PAPER_TEST_RESERVED`（未来正式独立冻结）两组 prompt ID；不重叠，也不将 160 路径最终测试设计直接消耗在探索中。
3. 从已完成 H1/F/B 归档提取真正可用的 **各 CFG 分支输出** `v_c, v_u`、C/A 候选、D 真实输出、时间／来源／年龄／动作原因。若只有 guided 标量或 RGB，**不能假设有分支级真值张量**，需要受控补采。
4. 读取已经完成的 FIXED_A/FIXED_PLAIN 数字以定义「静态规则已经解释多少」。不重复原卡。

### E0-B. H1 决策可改进空间

当前 H1：

\[
J_n(a)=c_a+\lambda g_n^2\hat q_a,
\quad
\hat q_C=k_{src,phase}(\delta_n+f_n)^2,
\quad
\hat q_A=r_{src,phase}\hat q_C.
\]

对每步输出 `legal_actions`、保护／缺支持原因、当前 `q_hat`、`g_n`、费用和 `J`，求最近与次优候选分数差（decision margin）。C/A/D 情况下可另设：

\[
x_n=\lambda g_n^2\hat q_C,
\quad
\frac{c_A-c_C}{1-r_n}<x_n<\frac{c_D-c_A}{r_n}
\]

该区间在 `0 < r_n < 1`、对应来源费用一致且 C/A/D 合法时才成立。对 `D31` 读取**实际 decision reason**，验证是否为 age=7 超出校准覆盖，不靠序号推测。

产出：各步骤「规则强制、模型主动、与动作边界距离、跨 prompt 方差」表／图，以及在可计算真实局部 oracle 的状态上，H1 是否存在有效选择余量。**不以“新序列必须不同”作为目标。**

### E0-C. P 的物理可行性盘点

审计现有接口能否独立执行单个 CFG 分支的 deep、head、RF；是否可以将一侧真实 D、另一侧近似结果表示为**不同来源身份／年龄**。若现有缓存是两个分支共用的不可分来源，先把它列作工程边界：第一轮只做“单边输出修正、不提交新来源”的局部实验；不能将近似输出冒充完整刷新。

产出一页状态契约：`valid_D_c, valid_D_u, working_c, working_u, source_id, age_c, age_u, birth_error`, `cached_hidden_exists`。**velocity 级修正不能直接反推出合法深层 hidden 缓存。**

## 3. P-ACR：非对称 CFG 刷新

### 3.1 最简单的数学定义

给定现有 A 从当前合法同状态得到的两侧实际输出 `bar_v_c, bar_v_u`，和完整 D 输出 `v_c^D,v_u^D`。定义：

\[
\Delta_c=v_c^D-\bar v_c,
\quad
\hat v_u=\bar v_u+\eta\Delta_c,
\]

\[
\boxed{v_g^{P_c}=8v_c^D-7\hat v_u=v_g^A+(8-7\eta)\Delta_c.}
\]

对称候选 `P_u`：

\[
\Delta_u=v_u^D-\bar v_u,
\quad
\hat v_c=\bar v_c+\zeta\Delta_u,
\quad
v_g^{P_u}=v_g^A+(8\zeta-7)\Delta_u.
\]

基线误差 `e_b=bar_v_b-v_b^D`，离线真实最优标量仅用于潜力上限：

\[
\eta^*=\frac{\langle e_u,e_c\rangle}{\|e_c\|^2},
\qquad
q_{P_c}^{oracle}=49\|e_u\|^2(1-\rho^2)
\]

（`q` 归一化须和原 guided MSE 一致，零范数时设无效）。另一侧是 `64||e_c||²(1-ρ²)`。在同一 A 基线上：

\[
\frac{q_A-q_{P_c}^{oracle}}{q_A}=\cos^2(e_g^A,e_c).
\]

**高 CFG 分支误差相关性不是半刷新有效的充分条件。**特别要看 oracle 对 A 是否已有足够净误差收益。

### 3.2 先验动作包络（仅局部）

在 `c_A < c_P < c_D, q_D=0, 0<q_P<q_A` 条件下，P 能在某个正权重下严格胜过 A 与 D，必须满足：

\[
\boxed{\frac{q_P}{q_A}<\frac{c_D-c_P}{c_D-c_A}.}
\]

对完整 C/A/P/D 还要胜过 C，并考虑支持约束。**旧 P0 1.367% 门槛不能直接套到新 P 上**；需实测 `P_c`/`P_u` 当前双 probe 后费用。若单边 deep 接近双 deep 一半，门槛可显著放宽，但“3.2 秒”仅是假设，不是已实测。

同时输出完整 `(cost, guided MSE)` 离散动作下凸包及当前冻结 `lambda*g²` 选取，避免只比较单个比值。来源更新可能改变后续成本，因此局部包络只是筛查，不是完整轨迹的必要充分条件。

### 3.3 P1：只读 oracle 与状态选择（0 GPU 优先；缺数据才补）

**状态：**四个已曝光 CAL 提示词中，按既有 H1 *真正由优化器主动选择 D* 的前中期位置各选 2–3 个，少量 A/C 位置作负对照；初步 12–16 个 paired 状态。不要把强制保护 D 当作可以安全替换的位置。

**同状态对照：**`C`、`A`、`D`、`P_c(η=0)`、`P_c(η=1)`、`P_u(ζ=0/1)`、开发期固定标量，以及 **current-state oracle（明确不可上线）**。另留一个 FasterCache 风格的历史 CFG 差分基线，避免把已有的跨分支预测当原创。

**可先用已有 D 真值 + A 输出离线合成**，若可取到这些分支级张量，第一轮不必再算真正的单边 deep。记录每状态 `q_A, q_Pc*, q_Pu*, gain, source, age, λ`、oracle 进下凸包情况及适用权重窗口。

**进展信号：**在若干受约束可替换 D 的状态，至少一个方向有可识别的质量—费用潜力，且不是只在当前状态 oracle 调参才能成立。不是规定必须所有状态改善。

### 3.4 P2：真实单边算子／报价（建议上限 1.5 GPUh）

只选择 P1 中有代表性的约 8–12 个局部状态（含有利与不利对照），从同一父状态恢复执行 `P_c/P_u`：

- 双分支均正常付浅层 probe；只一侧执行 deep；另一侧 A + 固定、**只从开发历史估计**的传递系数；
- 不读取当前被跳过分支的 Dense 真值作为在线输入；
- 真实测量 post-probe 动作费用、包含控制及必要 head 的费用；重复次序交替、前置预热，记录波动；
- 测 `guided MSE`、`q_P/q_A`、新动作下凸包、显存/张量驻留与合法来源接口；
- 非提交式试算恢复父模型状态／scheduler／RNG，不污染原 H1 轨迹。

首轮 **不做空间 FFT、不训练大网络、不修改旧 P0，不将 P_c/P_u 结果伪称为可靠 D 历史**。若 P1 的 oracle 已接近 A 且价格很高，允许 P2 缩减或暂停，避免无效开销。

### 3.5 P3：合法闭环（进入阶段 5，仅在 P2 有信号后）

两种实现身份必须分开：

1. `P_asym_readout`：当次 guided 预测由单边真实计算改善，但**不承诺**改写可复用深层来源；
2. `P_asym_refresh`：只把真实计算的一侧登记为真实 D 分支来源，另一侧作为近似或旧来源；维护分支级年龄、适用条件与后续读出。若当前 WorldCache 不能合法表达双来源，先不实现第二种。

只有第二种闭环才可以声称验证「廉价刷新创造了更好的未来缓存」。

## 4. W3-MixTrend：历史趋势感知动作价值

### 4.1 不复制旧 F 的空间 FFT

MixLinear（ICLR 2026）研究**时间序列**的分段局部预测和低秩频谱趋势。本项目仅借鉴「局部＋长期的低成本分解」；输入是**36 个去噪更新上的因果观测历史**，不是 93 帧视频的时间谱、也不是旧 F 的空间 H/W FFT。

首批 **优先简单时间域模型**，低秩时间频谱作为 *可选比较*，只有其确有额外决策收益才考虑上线。冻结 Cosmos 主干，不训练 LoRA。

### 4.2 与 H1 直接对齐的标签

对于同一合法状态下的反事实 C/A/D 输出，令真实绝对 guided MSE 为 `q_C,q_A,q_D=0`，收益指标：

\[
y_{CA}=g_n^2(q_C-q_A),\qquad y_{AD}=g_n^2q_A.
\]

对应含费用差的动作 margin：

\[
M_{CA}=\lambda y_{CA}-(c_A-c_C),
\qquad
M_{AD}=\lambda y_{AD}-(c_D-c_A).
\]

`M_CA>0` 表示 A 比 C 值得，`M_AD>0` 表示 D 比 A 值得（均是同一步、动作合法且费用正确时）。实际 C/A/D 选择仍比较全部 `J`，不只顺序阈值，且合法集合需先裁剪。`q_C-q_A` **可以是负数**，不能强制假设 A 在每个状态都更好。

当前 H1 现有的 `source×phase`、漂移、年龄、`g²` 是强基线；训练新模型只拟合其**增量或残差**，不完全推翻来源与阶段表。

### 4.3 特征与因果限制

在 action 决策之前可用的观测：当前和历史浅层 drift 的标量、两分支廉价统计、来源／真实年龄、合法支持、噪声坐标（建议实际 `log σ` 或 log-SNR）、上一步动作、上一次完整刷新的年龄。历史窗口先比较 `L=4/8/16`，可用前缀不足时 mask，并保留每一步实际噪声时间差。

**不允许**使用当前跳过分支 teacher、未来动作、未来 probe、最终 LPIPS、当前被选择动作之后才更新的状态变量。若要计算高维 `p_t-p_{t-1}` 方向，先检查显存／数据是否已有；优先存廉价小维统计或固定的低维 sketch，不为历史预测保存多份完整 2048 维 probe 张量。

某些 `p_t-p_s` 引入来源重置不连续，短期差分应使用真正相邻的可比 probe；跨来源切换可使用 reset flag 或隔离窗口。

### 4.4 W1：离线标签采集（建议上限 1.5 GPUh）

1. 尽量复用已有开发 H1 轨迹上**真实 D**的位置：该步已经有两个分支 Dense 输出，可以额外保存前置 `C/A` 候选读出，形成同状态标签；只记录算法执行时真实可得的前置观测。
2. 非 D 位置的 `q_C,q_A` 若缺 teacher，先在少量边界状态做非提交式 paired D，不必全 36 步重算所有反事实；完整成本计入任务。
3. 训练组取已有 CAL 与专门 `EXPL_DEV` 输入；验证按 **prompt 分组**（可再按 seed 细分报告），禁止随机把同视频不同步骤拆入 train/test。
4. 使用少量新探索提示词，例如 6–8 个、不与正式 `PAPER_TEST_RESERVED` 重合；记录实际标签覆盖的阶段、动作来源和边界距离，避免只用 D 数据造成偏置。

样本不足时先使用确定性低维回归，不强行拟合可学习的复谱网络。

### 4.5 W2：CPU 模型比较（0 GPU 优先）

| 版本 | 特征/算法 | 回答的问题 |
|---|---|---|
| T0 | 原冻结 H1 来源×阶段表 | 原基线 |
| T1 | 当前漂移／来源／时间 + ridge，直接预测 `y_CA,y_AD` | 改标签就够了吗？ |
| T2 | T1 + 分段局部趋势、EMA、斜率／曲率／波动度 | 短期历史有独立收益吗？ |
| T3 | T2 + 长窗口低秩时间域线性趋势 | 长期结构有用吗？ |
| T4（可选） | MixLinear 式局部＋低秩**时间频谱**，小 rank 2/4 | 频谱是否比 T3 实际改善决策？ |

固定训练／验证清单，调参只在训练折，少量固定超参。输出 `M_CA、M_AD` 回归偏差、按提示词局部 oracle-regret、合法动作混淆矩阵、边界点 margin 误差、复杂度和推理耗时。

对 `q_A` 预测保持非负，`q_C` 可由 `q_A+Δ` 重建并按物理约束处理；统一记录约束修复比例。不得把不同任务（C/A 与 A/D）独立计算出的误差结果拼成自相矛盾的风险表。

**发展信号：**在未参与拟合的探索提示词上，T2/T3/T4 至少一种相比 T0/T1 改善决策 regret 或高价值边界识别，且新增在线成本较低。仅 MSE 降低、动作不同或历史拟合更漂亮均不是合入依据。

### 4.6 W3：真实选择器测试

若有候选，就在完全相同的 C/A/D 合法集合、来源保护、控制费用下替换风险估计，不人为放开 age 支持或取消保护让它更容易出动作差异。先冻结预测器与校准数据，再测真实闭环质量与时间。允许得到与 H1 相同的动作序列：那是有信息的结果，不能为了展示动态而调整参数。

## 5. 组合实验与真正的论文合入判据

### S1：最小闭环，建议累计上限 3.5 GPUh

**输入：**4–8 个仅供开发使用的提示词、固定 seed、已经存在的 Native 参考尽量复用。采用配对的统一主计时；如需新参考必须一起补齐。

| 配置 | 用途 |
|---|---|
| H1 冻结 | 已有效主线，绝不重训／追改 |
| H1 + Trend | W3 历史预测的独立作用（C/A/D） |
| H1 + P-ACR | 新中间执行器是否有真实净值，需合法来源契约 |
| H1 + Trend + P-ACR | 两者组合是否改善前沿（条件允许） |

探索先固定较小数量的配置／lambda，不做所有组合大矩阵。如果 P 仅为 `readout` 而不是 `refresh`，必须在表中如实命名，不能计为源寿命重置。新 P 动作的预测误差表和实际费用须重新标定，不能沿用旧部分 MLP P0 的 `m_birth` 与 `c_P`。

**核心终点：**完整93帧 LPIPS（每种方法与相同 prompt/seed 的 Native 配对）、全路径真实时间（文本编码＋去噪＋VAE解码、控制额外费用计入）、每类动作数、优化器主动 D 次数、保护／缺支持回退、source age、峰值显存、视频接受／拒绝。报告逐提示词数值与总均值，不把局部 MSE 当成终点。

**评价准则是“是否新增实用工作点”而非固定百分比硬门槛：**同等质量省时间、同等时间更准，或者组合出现明确质量—成本改进。若 P 单步加速漂亮但未来 D 增加吞掉成本，归为不成立；若 Trend 改善局部排序而实际动作和 LPIPS 均无变化，归为暂不合入。允许局部收益弱但组合正向时继续做一次可解释的归因。

### S2：阶段结果如何收束

| 结果 | 处理 |
|---|---|
| P、Trend 都有效 | 选择较简洁的策略，真实新来源校准；作为更强主候选进入正式论文基线 |
| 仅 Trend 有效 | 维持 C/A/D 主架构，P 不进入主文 |
| 仅 P 有效 | 原 H1 保留，新 P 作为真实精度层级；避免声称内容感知 W3 改善 |
| 组合有效、独立增益小 | 允许保留组合，但补最小配对归因与费用报告 |
| 两者均没有端到端增量 | 不再继续扩探索；已有 A＋H1 主线继续正式补验与写稿 |

任何探索后改写最终方法、lambda 或训练输入，均需要**重新冻结**并在真正未见过的 `PAPER_TEST_RESERVED` 中验证，不能把 EXPL_DEV 再称独立泛化。
