# CARA：浅层创新量增益读出——推导与有限预算实验计划

日期：2026-10-27。实验暂称 `IG-Scalar / IG-Band`，不是已验证的新方法名。

**任务性质：** 本文是新的研究设计和 Codex 接续输入。未查看 DEV128 中途结果，未连接服务器、修改仓库、预约预算或启动模型/GPU实验。原 E1/E2 若已冻结，不覆盖或静默加臂；使用兼容资产，新增分析和候选登记为独立补充。用户要求积极探索、不以僵硬小样本门槛过早否定；原安全、数据身份、预算和正式质量合同仍然保留。

## 0. 本轮决定

主攻一个问题：

> 历史全残差外推与当前浅层观测之间的创新量，能否作为深层预测误差的低成本补偿方向？一个统一增益够不够，粗结构与细节子空间是否确实需要不同增益？

先固定 D 布局，只研究读出；不同时开发刷新门控、神经选择器、EGAFNet 边缘网络、时空多频带、单分支刷新或旧 GRAPH。与旧 F 的区别必须落实在实现上：旧 F 用频率统计预测动作，本轮直接改变 residual 提案，是一个新的分尺度读出候选，不以“仅诊断”为名绕过冻结范围。

本轮并行保留两个最小模型：
- `IG-Scalar`：一个共享增益。
- `IG-Band`：两个空间尺度的共享增益。

**不要求 Scalar 先胜出，才允许 Band；不要求每个状态都改善；不再把 8/12、5% 或某个方向余弦作为唯一生死门。** 局部结果用于判断是否值得支付一轮完整视频，不代替完整视频。允许一次有明确原因、有独立配置身份的有限修订，不无限加模块。

## 2. 精确的预测族：从二选一到一个连续读出

对 CFG 分支 b∈{c,u}，定义 r=p+d。过去两次真实 Dense 锚点为 s'<s，当前为 t。真实单调噪声坐标 xi 沿用 E1：

    xi_t = (sigma_start - sigma_t) / (sigma_start - sigma_end)
    h = xi_t - xi_s > 0
    H = xi_s - xi_s' > 0
    lambda_t = h/H

`lambda_t` 只表示外推跨度比，不与费用目标中的 lambda 或创新增益 kappa 混用。坐标/分母不合法时记录支持缺失，按原部署 fallback；不伪造 epsilon 后宣称原方法有定义。

    p_pred = p_s + lambda_t*(p_s-p_s')
    d_pred = d_s + lambda_t*(d_s-d_s')
    r_FULL = r_s + lambda_t*(r_s-r_s') = p_pred+d_pred
    nu = p_t-p_pred
    r_DEEP = p_t+d_pred = r_FULL+nu
    r_IG(kappa) = r_FULL+kappa*nu

因此 kappa=0/1 精确退化为 FULL/DEEP（raw residual 恒等式）。原 A 是 p_t+d_s；一般情况下并不属于上述 FULL/DEEP 两端，不能把 DEEP 与 A 混名。

同一 kappa 或同一组 band kappa 供 CFG 两支共享，但各支使用自己的 p/r 历史。只由过去真实 D 更新锚点；预测结果不写成新的 D。

## 3. 比“信任浅层”更准确的数学解释

当前 p_t 已由真实 shallow prefix 算出，不是统计意义上带有测量噪声的缺失观测。

令：

    eps_p = p_pred-p_t = -nu
    eps_d = d_pred-d_t

则：

    e_FULL = eps_d+eps_p
    e_DEEP = eps_d
    e_IG(kappa) = eps_d+(kappa-1)*nu

在某个状态的 raw 平方误差下，非退化创新量给出：

    kappa_star = 1 - <eps_d,nu>/||nu||²
               = <r_t-r_FULL,nu>/||nu||².

对多个状态拟合一个参数时，将分子分母分别按预先固定的 prompt/state 权重求和，再相除；不能平均各点 kappa_star。

这揭示了本轮的可检验假设：

> 浅层创新量与深层剩余外推误差具有可复用的相关结构，能提供一个用于补偿深层误差的方向。

若两者内积接近零，raw 最优 kappa 接近 1（DEEP）。kappa<1 或 >1 可能是在保留/放大浅层创新量，以抵消深层误差；不等于当前浅层观测“错了”。不预设 kappa_L 大于 kappa_H，更不由 kappa_H<1 直接宣布 MUSIQ 下降的因果原因。

一般线性算子 K 满足 e=eps_d+(K-I)nu，其无截距最小二乘解为：

    K_star = I - E[eps_d nu^T] E[nu nu^T]^{-1}

奇异时需要正则化/伪逆。这里是未中心化二阶矩；只有显式中心化后才称协方差。我们不估计巨型矩阵，仅研究 1 或 2 参数子类。

这只是当前状态 raw MSE 的线性估计理论，不继承 Kalman 线性高斯假设、终点最优或稳定性保证。

## 4. 两尺度读出：不需要完整 FFT

### 4.1 主分解固定

按每个 latent 视频帧、每个 hidden channel 的真实二维空间网格划分互不重叠 2×2 token 块。

P_L：块内均值复制回该块（最近邻恢复）；边界不完整块按实际元素数求均值。
P_H=I-P_L。

于是 P_L 是欧氏内积下的正交投影：

    P_L²=P_L, P_L^T=P_L, P_L P_H=0, P_L+P_H=I.

这应称“粗结构/细节子空间”或两尺度分解，不声称等于理想 Fourier 低高通。不要沿 channel 序号做空间频率分析，也不混淆视频帧轴和扩散更新时间。若 token 拼接含其他条件 token，只对真实视频 token 子网格作用，其余保持恒等或原规则并单列。

第一版不搜索 kernel、截止频率、块原点或 3D/多尺度方案。若用双线性插值或重叠低通，则通常不再正交；仍可研究，但需要保留完整 Gram 交叉项，且是另一算子身份。

### 4.2 候选

    nu_L=P_L nu; nu_H=nu-nu_L
    r_BAND = r_FULL+kappa_L*nu_L+kappa_H*nu_H

等价实现：

    r_BAND = r_FULL+kappa_H*nu+(kappa_L-kappa_H)*P_L(nu).

因此部署只需一次低通、若干逐元素运算和一次“新提案”的转换；不必先分别算出 FULL 与 DEEP 的完整输出。原 alpha 若需要 WC-C 输出，则该旧费用仍存在，不能声称整步只有一个 head。

### 4.3 两频带的真实自由度与可利用空间

在 raw 正交空间、固定数据权重、无约束无正则条件下，令：

    B_L = Σ omega_i ||nu_i,L||²
    B_H = Σ omega_i ||nu_i,H||²

两 band 分别的最优增益为 k_L*,k_H*。全局最优增益是 B 加权平均，且：

    Q_scalar* - Q_band*
      = B_L*B_H/(B_L+B_H) * (k_L*-k_H*)² >= 0.

退化能量的 band 不可辨识，回退到统一增益，不能用巨大系数制造改善。加盒约束时，Band 仍包含 Scalar，因此训练最小值不差，但上式的简单等号不能直接沿用。非线性转换、CFG 输出、留出数据和真实视频也不继承该保证。

**关键：Scalar 没有收益，Band 仍可有收益。** 合成反例：FULL=(0,0)，nu=(1,1)，teacher=(1,-1)。在 [0,1] 中，统一增益最优为0，平方误差仍2；两band取(1,0)，误差为1。离散二选一和统一增益都不能成为否决分尺度模型的前置门。

## 5. 拟合必须对齐实际 guided 输出

定义冻结父状态 i 上：

    z_i^b(k) = (1-alpha_t)*v_C,i^b
               + alpha_t*Phi_i^b(r_FULL,i^b+K nu_i^b;W_i)
    f_i(k) = s*z_i^c(k)-(s-1)*z_i^u(k)
    e_i(k) = f_i(k)-v_D,i^guided.

当前 s=8，但代码从真实 CFG 配置读取，不把8写死为一般模型常量。Phi 包含实际 warp/head/RF。共享 k 与 alpha 不使 Phi 自动线性化，也不保证两支误差一定抵消。

### 5.1 Raw 闭式拟合只作初始化和机制分析

可用保存的 p/r 做 raw scalar/band oracle；按支拼接得到的最优也不是 guided 最优。单状态 teacher 系数只标 ORACLE/DIAGNOSTIC，不在部署时读当前 teacher。

### 5.2 用四角实际输出建立极小响应面

计算：

    f00=f(0,0)     # FULL
    f10=f(1,0)
    f01=f(0,1)
    f11=f(1,1)     # DEEP
    uL=f10-f00; uH=f01-f00
    w=f11-f10-f01+f00
    e0=f00-v_D

FULL/DEEP 若与原 E1 身份完全相同可复用。新转换只补两角。不需要重新跑 deep teacher 或整条生成，但 adapter 重放可能仍需 GPU 和模型驻留，费用必须计入。

一阶代理：e≈e0+kL*uL+kH*uH。
构造 prompt 等权、prompt 内 state 等权的：

    G_ab = Σ omega_i mean(u_i,a*u_i,b)
    b_a  = -Σ omega_i mean(e0_i*u_i,a)
    J(k) = constant - 2 b^T k + k^T G k.

**不要因为 raw P_L/P_H 正交就删除输出空间的 G_LH。** head、warp、CFG 可以混合两方向。

若需稳定小样本估计，Band 只使用一个预先固定的轻微收缩：

    J_reg = J + lambda_reg*tr(G)/2 * ||k-k0*1||²

其中 k0 是训练 fold 上统一增益，默认 lambda_reg=0.05，无网格搜索。报告未正则 oracle，但不据其挑超参数。

### 5.3 非线性检查不变成新大卡

在每个状态额外检查实际 f(0.5,0.5)；计算 w 及中点代理偏差。四角/中点说明代理何时失真。

如果一阶代理排序不可靠，允许使用：

    e≈e0+kL*uL+kH*uH+kL*kH*w

在 CPU 上搜这两个参数的小响应面，再只对提出的参数执行实际 Phi 验证。不把四角插值称为任意增益上的精确模型，不增加骨干反向传播。

原 E1 的 FULL/DEEP 可复用时，12状态增加：两新角24次、统一中点12次、LOPO提出的Scalar/Band实际验证24次，共60次 guided适配器重放（120分支）；可选全数据重拟合两方案再重放24次，整卡上界84次 guided/168分支。所有 head、warp、转移和保存计费。任何额外点必须在完整上界内事先登记。

### 5.4 小样本泛化与部署系数

使用 2 prompt 的 leave-one-prompt-out：一条拟合、一条评估，互换；同一视频的状态不随机拆。每个 fold 只产生一套Scalar/两套Band数值，不逐状态用oracle增益部署。

局部筛查后，用两条校准prompt共同拟合一套最终系数，再冻结进入四旧CAL完整视频。其中两条没有参与本轮增益拟合，可先运行作开发留出检查，但它们仍是项目旧CAL，不冒称全新独立TEST。

不预设所有状态同样可预测；若需要分区，只沿用已登记的年龄支持域，不在12点上同时搜索多个阶段阈值。

## 6. 不把增益永远锁在凸组合里，但控制一次扩展

首轮部署盒为 [0,1]²，方便与 FULL/DEEP 端点比较。同时离线计算无约束最优值。

若两个留一方向均出现一致的边界截断，且实际guided响应显示可利用增量，可在单独记录中验证一个预先指定扩展盒 [-0.5,1.5]²。它是有限外推，不再称凸混合。仍共享两支系数，实际 head 验证、有限值和原支持域均保留。

这项是一次有限科学修订候选，不默认开启。不能同时搜索增益范围、滤波器、噪声坐标、阶段窗和alpha。若收益只来自一条输入的大系数，不进入视频扩展。

## 7. 细节与感知：不要用“更锐”或“高频更低”代替质量

Band 仅分解创新量，不把整份 r 或视频低通；kH<1 不必然意味着图像更模糊。观察：

- 实际 guided MSE 与逐支误差；
- 固定空间差分的 teacher-relative detail MSE；
- 高频/梯度能量比（仅诊断）；
- 归一化前的能量与创新量大小；
- E2 视频的 LPIPS、MUSIQ_LONGER512、主体、运动及已有动态诊断。

若视频MSE/LPIPS正向但细节退化，允许**一次有机制依据的修订**，不是立刻永久否定读出：在相同2参数族上，以训练折固定归一化的

    J_struct = mean(e²)/s0 + 0.1*mean(|grad e|²)/s1

重新拟合，s0/s1来自训练教师的预登记尺度并固定数值下界；没有新在线算子。系数0.1是一个先定的备选，不扫描多个权重。它是新候选身份，旧失败保留，E2原质量门不改。若选择了这个修订，本轮不再同时启用外推盒扩展或阶段模型。

“疑似平滑”不是自动拒绝一次小闭环的理由；实际质量门的失败不能被能量图美化。

## 8. 实验阶段与完整范围

### B0：已有资产与代数自检

- 读取已登记E1当前完成状态，只用兼容的已接受数据；不读DEV128部分指标。
- 验证 raw FULL/DEEP恒等、二维空间布局、P_L幂等/重建、CFG共享alpha恒等、past-only历史。
- 1624缺字段时不能估出新Band系数；列缺口，合并到原E1合法采集，不重新采一套全表。
- 已附 CPU 合成测试仅验证公式，不作为科学结果。

### B1：E1增益附录（无新增完整视频）

原五读出不删。增加：IG-Scalar、IG-Band，两者平行比较。
- 先路径控制 P0/P1/P2，再raw oracle/实际guided四角、LOPO和费用。
- 主频带固定2×2块平均投影，主sigma坐标及原alpha不改。
- 默认实际guide MSE拟合；原独立质量只在完整视频有定义。
- 输出相对最强固定baseline、Scalar、DEEP、DCTA的逐prompt/逐state差异；不采用每点挑不同基线的隐藏oracle主分母。
- 计算原最强固定读出与逐状态oracle的差距，但不据此单独否决Band。

局部资源判断：5%改善是正向信号参考，不是硬门。两fold方向一致且成本可接受可直接进小闭环；若总均值略小但Band明显修复某个有解释的细节/长跨度问题，也允许一次闭环。若所有相关raw和actual候选均无实用空间、被同成本近邻稳定超过，则停止具体候选。

### B2：固定D的完整视频，先验证读出

父布局固定Shared25-C：D1–21、24、27、30、36。配置按真实适配器核对，不把示例写成跨模型常量。

核心7角色 × 4旧CAL × seed0 = 28机制输出：
1. WC-C
2. 原phase A
3. FULL
4. DEEP
5. DCTA common-adapter port
6. IG-Scalar
7. IG-Band

Scalar即使局部弱，也作为Band增量的必要消融，不因未胜出而全部删掉。若Band原理与actual输出均无空间而Scalar有效，可去掉Band角色，但需在整卡冻结前改完整范围，不在运行中按好坏改分母。

完整保守上界：
- 核心正式28；
- 同批Native35×4，以及原质量合同的同配额S25-C参考×4，共8支撑正式路径；
- 完整预热拟4；
- 2固定prompt × {WC-C, IG-Scalar, IG-Band}追加一轮平衡计时，共6。
- 总计46完整路径。只有身份/输出/硬件边界匹配时可复用部分质量资产；新时间不跨硬件拼接。代码路径若需要更多warm，报价阶段调整完整上界。

E2不使用C父轨迹的teacher替代候选自由运行；每个候选沿自己的latent、solver、cache自然继续。只有真正相同前缀且完整恢复时可复用，不为了公平把轨迹拉回。

### B3：一轮定向修订，最多一项

选定明确原因后，只允许以下之一：
- 增益盒扩展（稳定边界截断）；
- 同参数的细节敏感拟合（MSE好而教师相对细节/视频质量退化）；
- 新候选自身轨迹上的少量同状态补校准（离线父分布错位且有证据）。

工程身份/重放错误先修，科学失败不要混报。最多新增一个修订候选，最多4CAL候选+必要配对对照/预热约10路径；实际不得突破整轮总预算。新结果不是旧方法被追认成功。

### B4：成功后先新输入，不急着另做调度器

有完整视频成本—质量正向后，冻结一个主读出（可以是Scalar，不必Band）。从未用于选择的新DEV做确认；与WC-C、DCTA和至少一个相关频带预测方法比较。

如果读出确实有效，再在同样GCR/FULL框架下做一个固定25D的同配额D交换或改变采样步数，检验是否存在部署增量。没有不同布局也不妨碍按读出方法写论文，不重新启动完整GRAPH。

### 开发可以继续的信号（满足其一即可讨论小闭环）

- Scalar小改善而Band有清楚增量；
- 平均MSE变化小，但teacher相对细节误差改善且低频未明显损坏；
- 同等误差下实际读出更便宜；
- 局部raw有大空间，当前guided拟合存在一个明确、可修的路径/响应面问题。

这些只是投入理由，不是结果成功。不能用事后挑选的子集包装泛化。

### 最终完整视频与正式候选

从原CAL66合同绑定而不是手抄改版：相对指定同配额S参考与Native35，MUSIQ_LONGER512退化不超过1原分，主体一致性/运动平滑各不超过0.01；动态程度保留诊断，不自创新硬阈值。若原合同的队列、方向或具体定义与摘要不同，以原件为准并注明。

最终请求预算仍为 min(257.7712338712067秒, 0.8×freshNative)。探索诊断不要求每一臂都成为可部署预算点，但候选晋级必须面对完整费用与原质量守卫。

单轮4旧CAL不报统计显著或“普遍保持质量”。报告全部prompt、绝对和相对LPIPS、最差退化、实际时间、质量各维及拒绝/缺失。不能把数万token或93帧当独立样本。

### 停止

在适配正确且一次有限修订后，仍被同成本强近邻支配，或只有teacher逐状态oracle好、冻结系数完全不能利用，停止该候选。结论不是浅层信息永远无用。若读出成功而Band无增量，保留Scalar，不为了频率名义继续探索。

## 11. 最接近的文献与主张

本轮查阅的原文：
- FreqCa, arXiv:2510.08669v1：频带采用不同复用/预测，低频保持、高频二阶Hermite。https://arxiv.org/html/2510.08669v1
- Frequency-Step Cache, arXiv:2610.15922v1：固定exact anchors，频率/年龄控制中间repair等级；不是本方案创新量双增益公式。https://arxiv.org/html/2610.15922v1
- RFC, arXiv:2602.19506v1：当前输入—输出关系修正与预测误差调度。https://arxiv.org/html/2602.19506v1
- DiCache, arXiv:2508.17356v2：DCTA浅层轨迹对齐及在线probe控制。https://arxiv.org/html/2508.17356v2

FreqCa是正式方法阶段必要的频带读出近邻。首轮不为了完整移植它拖延两参数探测；成功后应做可信固定掩码移植并计真实历史/模型成本，不能拿一个二阶近邻的自制简化版冒充原方法。

可争取的主张：当前浅层创新量与深层外推误差存在分尺度相关结构；在真实CFG输出中用极少参数校准这种结构，能够比全残差外推、DCTA、WC-C和统一增益获得更好的实际保真—费用取舍。它不是新的Kalman理论，也不是首次按频率预测。

若只有Scalar有效，就按创新量补偿读出组织；若Band带来留出和终点增量，再主张分尺度结构；刷新安排的独立贡献必须另验证。
