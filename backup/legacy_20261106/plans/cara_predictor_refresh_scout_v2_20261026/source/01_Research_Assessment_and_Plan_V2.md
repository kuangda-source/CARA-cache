## 1. 文献核对与 DiCache 对照边界

已核对 DiCache 的 arXiv v2 方法章节、ICLR 2026 官方收录入口和官方项目说明。正式发表信息可核验；这次未逐行审计官方预测器代码，运行前仍需锁定官方 commit 及所用实现。

DiCache 有两个部分：Online Probe Profiling Scheme 与 Dynamic Cache Trajectory Alignment (DCTA)。本轮只把 DCTA 放到冻结 D 掩码下比较，以隔离读出，不开启其自适应刷新控制器。

按本项目更新顺序 b' < b < t，DCTA 的论文式可以重编号为：

    r_hat_DCTA = r_b' + gamma_t * (r_b - r_b')
    gamma_t = L1_rel(p_t, p_b') / L1_rel(p_b, p_b')

其中 p 是映射到统一残差坐标的 shallow residual。原文 Eq. (7)–(11) 的时间方向与本项目更新编号不同，必须明确 older/newer，不可只照抄减号。分母保护、系数限制、分支计算、数据类型与原代码有差别时逐项标注。

对照身份固定为：

> DCTA readout port under a fixed schedule / common adapter.

它不等于复现完整 DiCache 的动态阈值、缓存调度和总方法性能。全残差 secant 也只能标为 first-order full-residual extrapolation / Taylor-style control，不能直接冒称完整 TaylorSeer。

在同一转换适配器下比较预测构造；若 WC warp 本身对当前真实 hidden 引入明显偏差，则增加一个必要的 native-conversion 诊断，避免将不适合近邻的转换路径强加给近邻后宣称胜出。不得为自己和对手使用暗中不同的 head、归一化或 alpha。

## 2. 关键数学修订：方向持续性不是单独的生死门

### 2.1 相对 A：方向和幅度必须同时匹配

固定同一分支、同一原始残差坐标，定义：

    u = d_t - d_b
    v = kappa * (d_b - d_b')
    kappa = h/H > 0

纯 A 提案的误差是 -u；新深层剩余外推的误差是 v-u。严格有：

    q_res - q_A = ||v||² - 2<u,v>

若 u,v 均非零，新提案优于纯 A 当且仅当：

    cos(u,v) > ||v|| / (2||u||).

因此：
- cos > 0 不够；外推幅度过大会使同方向预测也变差。
- 不能只统计平均夹角；必须记录幅度比和 margin = 2<u,v>-||v||²。
- u 或 v 接近零时，夹角标为 undefined；直接用未归一化 margin 判断，不填 0 或 1。
- 这些是 raw residual 诊断，不能代替经过 warp/head/RF/CFG 后的实际 guided MSE。

### 2.2 相对全残差外推：cos_d 不必高于 cos_r

令：

    eps_d = kappa*(d_b-d_b') - (d_t-d_b)
    eps_p = kappa*(p_b-p_b') - (p_t-p_b).

深层剩余外推的误差为 eps_d；全残差外推的误差为 eps_d+eps_p，因此：

    q_full - q_res = ||eps_p||² + 2<eps_d,eps_p>.

新方法是否更好，取决于用当前 p_t 替换浅层外推后消除/破坏了什么误差；不能用“d 比 r 更平滑”作必要条件。

一个纯代数反例（不是模型实验）：kappa=1，过去/当前深层增量为 (1,0)/(1,1)，浅层增量为 (10,0)/(100,0)。cos_d≈0.707，cos_r≈0.99995，但深层剩余外推误差平方为 1，全残差外推为 8101，A 为 2。故 cos_d <= cos_r 直接淘汰是不正确的。

第一轮应同时输出：cos_p/cos_r/cos_d、三者幅度比、精确 raw 增益、eps_p 与 eps_d 的交叉项，以及实际 guided 输出误差。前四项解释机制，最后一项决定是否值得闭环。

### 2.3 与 DiCache 的差别要区分系数和创新项

令 kappa_D=gamma_t-1，则：

    r_hat_DCTA = r_b + kappa_D*(r_b-r_b').
    r_hat_res = r_b + kappa*(r_b-r_b')
                + [(p_t-p_b)-kappa*(p_b-p_b')].

二者差别包含“时间跨度系数 vs. probe 估计系数”和“显式浅层创新项”两件事。首轮先比较五个实际候选；仅当两者都有潜力且归因需要时，在同一已导出张量上补相同 kappa 的代数对照，不新开系数网格，也不立即增加完整视频角色。

## 3. 数据能力：零新增生成不等于所有诊断都免费

### E0 已有资产能做的

1. 1624 中实际存在的 e2、ed、d2、source/target、原 alpha 与 metadata：可重算其原条件下的 guided q(alpha)，检查 C/A 比值随阶段和当前跨度变化。
2. 这些记录的过去锚点是相邻更新。若 sigma 元数据存在，可计算相邻噪声跨度 H，但 H 与阶段/网格绑定，不能识别部署中稀疏锚点间距 H 的独立作用。
3. 已有 C/A/Native 视频：统一预处理后计算 Native-relative 梯度误差、原有 MUSIQ/主体/运动结果；加一个事先固定的轻模糊 C 作为解释性对照。模糊不能逐视频拟合，不进入部署速度主表。
4. 原已经冻结的掩码、费用和来源日志：检查候选是否只是统一缩放，或是否真正改变合法计划。

### 不能从这些标量恢复的

CFG 各分支 p/r/d、当前精确 hidden、任意旧锚点、跨时间向量内积、DiCache gamma、稀疏历史反事实、完整后缀标签。

不得再声称“零 GPU 拟合 h/H 三维误差模型”。缺失字段写入 assets_manifest，不默填，不为凑理论反推不存在的张量。

0 新增生成仍消耗 CPU、I/O、磁盘和可能的质量模型推理费用；只能将其称为“不新增模型生成”。

## 4. 坐标和样本预登记

### 主坐标

默认使用实际生产 scheduler 导出的 sigma，选择固定递增仿射坐标：

    xi_t = (sigma_start - sigma_t) / (sigma_start - sigma_end).

只在 sigma 单调、分母非零且实际调用对应明确时使用。h=xi_t-xi_b，H=xi_b-xi_b'；不把更新索引当等距噪声坐标。

如果模型没有这一定义，adapter 必须在看新误差之前绑定其原生有限连续坐标，登记变更理由；不允许遍历多个坐标后选择最优者。

敏感性只允许一个备选：正 sigma 公共域内的单调 log-sigma。sigma=0 的点不加可调 epsilon 伪造值，保留为不适用；备选结果不得直接取代主候选成绩。所有模型输入时间、sigma、solver 更新位置分别保存。

### E1 的采集对象

最多 2 个旧 CAL prompt、每个 6 个状态，seed 固定，按历史身份/合法阶段覆盖选取，不按预测器误差选择。

优先从一个冻结真实稀疏父策略（例如当前 Shared25-C）的自然轨迹采集，读取它实际的最近两次真实 D。覆盖转换/中后阶段、短/较长 h，以及实际可得的至少两类 H。若无法完全交叉覆盖，报告结构缺口，不伪造。

当前 36 更新、Shared25-C 下可核对的示例位置为 22、23、25、26、32、35；它们不是跨模型算法常数，也不自动合法。Codex 先根据实际掩码、保护及各候选支持域验证，再在输出前冻结最终列表。超出部署支持域的 shadow 候选只标诊断，不暗中扩展在线合法集。

相邻 Native 轨迹子采样形成的历史只能叫 teacher-history probe，不能冒充相应稀疏策略自然产生的历史。

## 5. E1：一次特征采集，先路径，再几何，再五种读出

### 5.1 必须保存的内容

按每个 CFG 分支分别保存或以无损引用方式绑定：

- 当前输入基准 o_t、p_t、同状态 teacher r_t；
- 最近两个真实锚点的 p_b,r_b,p_b',r_b'，其身份、更新/噪声时间和出生来源；
- 原生 Dense 分支输出、当前 WC-C、原 A 实际输出；
- 冻结工作窗口 W、实际 warp 参数/必要坐标、head/RF 时间和条件转换信息；
- 必要的 solver/cache/RNG 状态身份，prompt/seed/profile/checkpoint/precision。

优先只存 p/r，d=r-p 可重建，不重复保存三个同等大小张量。保持原 dtype/shape/layout；计算差分的精度规则要固定。统计可 FP32/FP64 汇总，但不要悄悄改变生产预测精度。

采集每个点的 teacher 必须是同一状态的 shadow evaluation：不得写回真实锚点、改变父轨迹 solver/history 或污染随机状态。各候选读取同一份只读历史；测试完逐一恢复，不能让前一个候选结果成为后一个候选历史。

采集前根据实际 shape×dtype×branch×anchor×state 计算峰值与磁盘需求。流式写出，复用锚点，禁止在 GPU 常驻全部 12 点的高维张量；遵守现有 StorageGuard，不自动删除原件。

### 5.2 第一个输出：转换路径诊断

同一状态比较：

    P0 = v_D：原生 Dense 输出；
    P1 = NativeHeadRF(o_t+r_t)：精确 hidden 的原生路径重放；
    P2 = Phi_cache(r_t;W)：精确 hidden 经缓存转换；
    P3 = 实际 A / 新预测器输出。

P1 应在已登记数值容差内重放 P0；若失败，先处理 hook/输入/坐标/RNG 等实现问题，不能作为科学负结果。

P2-P0 不为零时，记录为“转换路径偏差”，不直接断言 bug 或不可消除误差地板。预测误差与该偏差可能相互抵消。先检查设计是否本来包含 warp；任何修改转换路径的部署候选都需要新身份，不能把它悄悄计入外推收益。

输出 branch-c、branch-u 及真实 CFG 合成后的差异，并保留原 C/A。

### 5.3 第二个输出：持续性与精确增益

对 p/r/d 分别计算第2节指标，按实际阶段、h、H 展示全部点，不将 12 点或两 CFG 分支当独立 prompt。方向随机或幅度失配可以解释失败，但不单独构成“深层不可预测”结论。

### 5.4 第三个输出：实际五组比较

| 代号 | 候选 |
|---|---|
| R-C | 冻结 WC-C |
| R-A | 冻结原 A / phase alpha |
| R-FULL | r_b+(h/H)(r_b-r_b') |
| R-DEEP | p_t+d_b+(h/H)(d_b-d_b') |
| R-DCTA | 官方 DCTA 的固定掩码读出移植 |

所有候选明确记录原始提案与实际融合输出，统一 head/CFG 坐标后比较。R-FULL/R-DEEP 原则上沿用原共享 alpha 和转换合同。DCTA 若施加同样外层 alpha，应标明 common-adapter port，不宣称官方完整算法。禁止为新方法使用 oracle alpha、给对手默认系数却不给同等信息。

主指标：实际 guided MSE，辅以各分支误差、norm/夹角、历史跨度、数值异常、实际 readout 时间与新增显存。所有 teacher 只评分，不进入部署动作。

### 5.5 费用与筛查门

E1 约 1 GPUh 是规划目标，不是保证；补特征、所有 shadow teacher、五种读出、warm、加载和保存均应进入整卡报价。

“额外 head 约0.18秒”只能作旧经验提示，不用作新硬件/新实现的既定费用。新候选可能复用现存历史，也可能多存锚点；按实际差额测，不预设显存恰好多一份。

推荐在看 E1 输出前冻结以下探索入场规则：
- 至少 8/12 个完整预登记状态上，实际 guided MSE 同时好于原 A 与 R-FULL，差异大于原控制数值噪声；
- 两个 prompt 的聚合误差分别不向坏方向变化，避免一个输入拉高总均值；
- 相对两个固定对照的聚合改善以约 5% 为初始资源投资目标，不是显著性证明；
- DCTA 必须同表报告。若 DCTA 在误差、成本、显存及尾部上清楚占优，则停止 R-DEEP。若误差接近但 R-DEEP 明显更便宜，可按固定质量—成本目标进入下一阶段；
- 缺失、数值失败和支持域外状态不能事后从分母删除。无法形成完整比较先记 evidence-incomplete，不宣称方法失败或通过；
- 路径实现不对只允许一次明确工程修复；科学不优不通过加阶数、网络、频域、单侧刷新等方式救回本候选。

8/12 是预算筛查而非统计定律。不能把“d 的夹角不比 r 大”作为替代门，也不能仅局部通过就宣称质量达标。

## 6. E2：先固定布局读出，再做真正有区别的2×2

先冻结一个实际强对照 j0 与新候选 j1，不逐状态挑赢家；对照选择规则在 E1 前登记，按聚合误差/费用选择固定身份。默认包含 WC-C 与 DCTA 的资格，不能因为近邻强就将其移出。

若已有可区分的布局 S0/S1，必须由同一冻结规则产生，且只在有数据支持的局部变化上探索；不能用 12 点拟合全36步的新高维 GRAPH。若两个布局完全相同，合并为一个布局，结束“专属调度”这一分支，但允许有价值的读出单独验证。

完整最大范围：2布局×2预测器×4旧CAL×seed0 = 16正式输出。按预登记顺序可先完成固定基线布局的8条；若没有可用信号，可在分阶段卡的明确停止边界结束，保留未到达条目。warm、Native缺格、计时、评分均单列，不在运行中偷偷新增角色。

分析每个 prompt 的：

    A0 = L(j0,S1)-L(j0,S0)
    A1 = L(j1,S1)-L(j1,S0)
    Gamma = A0-A1.

主读法是 A0/A1 的各自方向、各格与强简单对照的距离、实际完整请求时间、质量及尾部。Gamma 不是单独成功门；4CAL单seed不提供强交互统计证明。

若没有可信 S1：只做固定布局两个读出。RA 的已验真实 D 掩码可以成为另一个预登记固定布局，从而兼顾 A_NO_P 研究入口；不要在2×2后无条件再开一张几乎重复的 RA 卡。固定 RA 掩码不等于恢复原在线 probe 门控。

E2 拟整卡目标2–3 GPUh；若局部费用或新质量门使候选显然不可能满足实用目标，应停止，不为凑16条而跑完无意义角色。

## 7. 独立质量门与最终预算：继承，不重写

用户本轮明确：CAL66 的 A 类候选因 MUSIQ 门未通过而被排除。该事实作为当前输入接受，但本轮没有读取其原合同与机器结果。

Codex 在报价前绑定：
- 原质量门来源文件/commit/配置hash；
- MUSIQ 相对哪个对照、绝对/相对容差、按何队列聚合、是否使用区间；
- 主体/运动/动态的守卫、预处理和缺失规则；
- 当前完整请求时间、绝对预算和0.8×同批Native定义。

值未知时保留 null 和“待原合同绑定”，不得使用自行猜测阈值。CPU读档和代数分析可继续；不得在看到新候选质量后放宽门、改变主指标或挑输入。

局部 teacher MSE 改善不是通过 MUSIQ 门；旧视频的质量也不是新候选的质量。E2 真实视频就要运行既有质量管线，不能等到大确认后才发现同样的平滑退化。

成本分三层：readout微费用、方法完整请求、校准总GPUh。最终部署门只对冻结完整候选确认，不要求所有诊断角色本身成为预算内方案。固定D布局不等于同总时间。

| 既有数据只有标量 | 不伪造向量诊断；按正式采集范围报价 |
| 局部R-DEEP被同费用近邻清楚超过 | 停止具体候选，不启动E2 |
| q改善但完整MUSIQ/质量门失败 | 不并入主线，不改门；记录取舍后结束本版本 |
| 新读出有效、布局相同 | 继续读出贡献，停止强求预测器专属调度 |
| 2×2只由单prompt支持 | 不并入；仅在已有明确修复原因时允许一次修订 |
| 冻结候选通过成本与质量且跨prompt方向合理 | 申请新输入确认，之后再迁移 |

任何科学停止只针对本候选、本实现和测试范围，不等于所有深层变化不可预测、所有历史无用或所有MSE足够。

## 9. 预算信封与数据隔离

用户估计 DEV128 结算后约剩36 GPUh；这里只作条件规划，不是新账本。

| 用途 | 条件式预留建议 |
|---|---:|
| E1+E2及有限修复 | 至多约4 GPUh |
| 新读出的独立DEV/确认 | 约12 GPUh |
| 可能的Wan/第二骨干 | 约10 GPUh |

总计36仅是示例。真实可用=最新已结/现存预留/授权上限共同决定；不挪用旧未知责任。若余额不足，先缩探索，保护新输入确认的费用，而不是继续旧CAL搜索到无钱确认。

若新DEV结果用于修改候选，其身份即为开发数据；必须保留另一份真正未用于选择的最终测试。完整范围超过既有许可时按原规则一次性申请，不能按单子任务拆卡绕过阈值。本文件不产生预约或执行权限。
