## 2. 数学定义落到实验对象

单位化FFT的Parseval关系意味着 `||FΔp||²=||Δp||²`。有效候选是分带信息或非负加权二次型 `Δp*F*WFΔp`，全部同权退化为原L2。只比较幅度谱会漏掉平移相位，主候选保留复差分与CFG交叉项实部。当前与来源使用同一个当前滤波器，避免把滤波器变化误当来源漂移。

当前系统实际guided误差是 `e_g=8e_c−7e_u`。两分支用同一线性变换；真实e只来自离线同状态D。`8Δp_c−7Δp_u`是浅层代理，不是guided真误差。频带加权近似任务敏感度需要局部线性/近似平移不变等条件；平方特征距离的方向交叉项仍可能改变终点效果，不能把能量公式当LPIPS保证。

Block保持式为 `h_next=h_current+R_cached`，而不是覆盖旧hidden。fresh-KV候选计算 `softmax(Q_active K_current^T/√d) V_current`，仅在同层、同输入、相同位置/有效mask下对应dense的活跃行。未活跃token仍保留完整K/V上下文，重用合法attention/MLP残差。前层近似、时间调制、cross-attention等额外误差及费用单列。

复用全部key时attention主项按活跃比例η缩放，不是η²；FLOPs公式只指导筛查，最终依A6000全动作实测。层/token不同年龄分别记录；真实D锚点独立于近似P工作源。

## 4. E1-F：判别信息与真实增量费用

**输入范围：**起点为四旧CAL的已登记≤16状态，按决策前来源、阶段、年龄选取；保留两原动作P状态的身份。在自然C子集单列分析，不把离线强制C/A称为原策略已执行。需要新增点时先登记选择规则与完整费用，初轮最多32，不在看过teacher/终点后补挑。

|配置|特征与用途|
|---|---|
|F0 / 主强对照|全特征raw/RA＋来源、真实tau/Δtau、年龄/参考跨度；保留最新source×phase表对照|
|F0-sub|同一固定8–16通道的raw能量＋相同元数据，分离子采样与频率贡献|
|F-Haar|保留F0-full已有raw/RA与全部元数据，再加同通道正交Haar低频/细节/CFG相关统计|
|F-FFT|保留F0-full已有raw/RA与全部元数据，再加同通道小型2D FFT两频带复差分/CFG相关统计|

固定通道索引、频带、归一化和处理精度；沿真实H/W做变换，不先跨通道求均值。高频统计在降采样前完成。首版不全3D FFT，不按所有来源×阶段各训一套大表。新增系数2–4个，模型容量/拟合程序相同；标准化、回归与模型选择仅用各训练fold，按提示词留出，不随机拆状态行。γ沿用已曝光CAL冻结值，因此这是模块留出诊断，不是整个算法独立泛化。

训练标签保留未传播加权的绝对 `q(a)=MSE(v_g^a,v_g^D)` 与 `y_CA=q(C)−q(A)`。动作regret用同一主线单位：

```text
J_true(a) = c(a) + lambda * gain² * q_true(a)
regret = J_true(chosen) - min_legal_a J_true(a)
```

先只改变C/A误差预测，读出、λ及预登记的共享开发λ网格、动作费用/保护/支持域都不变。C/A二选与全合法动作选择分别报告；未新标定P/D不得偷偷替换其风险。额外F观察费用对所有该配置调用计费，包括最终选D也已支付的特征费；必要时在实际总时间中比较，不能只在选C时收取。相同F成本是同状态argmin常数，不代表跨配置免费。

主指标：留提示词的动作regret、各来源/阶段的有害选择与C/A真实收益；相关系数/MSE为辅助。新谱分数变小不能自证成功。比较按状态→提示词等权，报告所有状态与最坏例，16点不当独立视频数。

费用测试包含通道读取、布局、滤波/FFT、聚合、源谱维护、controller和同步；记录features-only及features＋controller增量，预热10次/正式30次是待实机卡确认的方案。无iFFT需求时不添加。0.5%整段额外成本是工程目标；超过1%优先检查Haar/调用频率/布局，判断能否收回费用，不直接否定F。

15–20%regret改善只是投入参考，不作一刀切门槛。若仅捕获阶段规律则保留更便宜阶段规则；若有条件性信息继续小桥接；结果接近噪声或样本不足则登记证据不足。

实现前CPU边界：rFFT最后压缩轴的DC/Nyquist/共轭补权、奇偶H/W、padding/有效mask、实数/复数CFG等价、同源ID、真实位置映射及低精度误差。附件合成脚本未覆盖这些真实布局问题。

## 5. E2-B：少量执行器，测完整深层而非单算子

先两旧CAL×两个有合法层历史的中后期状态。具体层集/状态ID在profile后、看候选teacher误差前冻结，不搜索层数×mask×稀疏率大网格。

|执行器|首版范围|必需对照/约束|
|---|---|---|
|P0|现四层、50% MLP|原算法、原来源，保持身份|
|B-M8|八层、50% MLP；attention完整|单一覆盖轴；与主线P profile共享证据，不另重复收费|
|B-L2|两个Block历史残差保持，其余当前计算|保留当前identity；真实条件/调制/残差位置按源码确定|
|B-Q2|两个Block fresh完整K/V、50%活跃Q/输出/MLP|未活跃行合法子层残差；当前K/V全上下文；不默认已有高效kernel|
|D-stateful及普通D|真实完整计算，分别含相应缓存维护/不维护|量化状态税，禁止先dense后blend冒充少算|

两CFG分支共享mask，保留各自数值；先均匀轮换，并保留一个同配额固定随机mask对照，不用频谱选token。旧attention敏感层结论作为参考，不自动永久禁用其MLP/Block；是否选择需按操作类型登记。

先验证同层同输入fresh-KV活跃行与dense对应（精度合理容差）；再让每个候选从同一个实际latent出发，沿自身中间状态运行整个深层，与同状态D比较最终guided输出。不得每层注回dense hidden，或用当前teacher填“历史缓存”。stale-KV只保留一层离线误差分解，不进入首个完整候选。

计费覆盖双CFG深层、选择、gather/scatter、残差读写、K/V投影、head、cache初始化/维护；测驻留及峰值显存，区分部署缓存和离线诊断快照。若实际融合QKV仍全算Q，照实计费。B-Q2接口不支持则标技术缺口，不为首轮重写大kernel；M8/L2仍可独立探索。

出现成本—误差非劣点后，至多选一个P-v2，≤4状态检验age1/2受控后续C/A与P0，记录出生误差、未来D/P和全费用。~5%完整动作可识别省时、争取10%是工程投入参考；不是固定MSE≤5%的方向生死线。只有~1%且质量下降时先检查覆盖/访存，允许一次有明确原因的修订。
