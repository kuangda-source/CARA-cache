## 3. N1：面向自然NONZERO状态的有限同状态诊断（待登记新提案）

### 与旧P卡的区别

旧P卡主要使用KEEP父路径并强制C，适合既定机制问题。本提案选择自然NONZERO退化路径上的实际读出状态，直接研究当前组合失败。两者不是相同实验；旧卡继续暂缓。

### 起点设计

最多4个CAL场景，每场景2个可用自然状态，合计8状态。按预登记的P读取事件序号与D/P间隔分层选择，例如第一次P读取及长间隔组；不看teacher结果之后选最利于候选的点。缺快照不自动扩成大批父路径重跑，先报告重建成本。

第一轮以β=1消除斜率拟合的干扰，固定现有阶段alpha和head/warp实现，比较：

| 模式 | 作用 |
|---|---|
| 现有C | 同源不加A的简单对照 |
| 旧D参考unit-A | 当前失效配置 |
| P一致参考unit-A（γ=1） | 检验重定基点 |
| 融合参考unit-A（γ=0.5） | 检验P新信息需要收缩的可能 |

需要时给少量状态增加旧/新W1，不一开始做所有β×γ×alpha的笛卡尔积。

### 真实计算合同

- 每个候选从完全相同的当前状态读出；包括latent、solver历史、双CFG缓存、source metadata、RNG。
- 一个同状态dense teacher可供全部候选评分，但其结果不写入任何候选缓存或风险决策。
- 先做只读局部诊断，不要求每个候选生成完整视频；所有teacher和候选head照实计账。
- 比较的是真实warp和head后的guided输出误差；附带分支误差和cross-term。
- 恢复当前状态后，只继续事前选定的原路径，不用oracle挑最好分支接管。

### 可区分的解释

| 结果 | 含义与下一步 |
|---|---|
| P一致参考修复大部分局部退化 | 来源参考失配是重要因素；进入完整组合开发 |
| γ=0.5优于γ=1 | P的innovation有用但噪声/偏差较大；融合优于完全替换值得继续 |
| C明显优于全部A | 在这些P状态A不适用；“P来源上A关闭”成为必须超过的廉价强对照 |
| 分支好、guided坏 | 优先检查跨CFG共享强度与相关项，而不是改时序预测容量 |
| 局部好、短/终点坏 | 调度反馈/轨迹传播值得继续；不能把局部MSE当终点保证 |
| 修改来源后风险值未随估计改变 | 读出—风险契约需要同步，而不只是替换base tensor |

这批是定位与开发，不用于宣称泛化或最终创新。

## 4. N2：做出第一个完整候选，而不是再扩大诊断矩阵

### 最小算法

1. 来源一致的读出，或一个固定γ的融合读出。
2. 现有共享阶段alpha，先保留离散值，兼容FAST端点head省算。
3. 按来源/读出校准风险，保留RA的CFG合成与传播基础。
4. H=1的代价—风险选择，与H=2低维预测选择对照。H=2只模拟低维质量和成本，不复制生成器运行四分支。
5. P维护真实工作source、出生误差及token状态；D独占可信完整历史；不得把P当作零误差D。

### 推荐开发对照（分批，复用严格兼容的结果）

| 方法 | 需要回答的问题 |
|---|---|
| 合理校准RA | 基础水平 |
| RA+阶段A、无P | P是否真的必要 |
| NONZERO CPD | 来源规则本身的实际能力 |
| CPD+一致读出A，简单H=1规则 | 正确简单组合是否已经足够 |
| 相同执行器+H=2成本感知调度 | 有限时域是否有额外价值 |

另在少数位置补“把P换成D、时机相同”的对照，隔离部分更新本身与刷新时机。固定未来mask和同规则自适应续推是不同问题，分别记录，不混淆。

开发可做1–2轮有依据的修订，不要求每个模块先独立成功。不引入全量训练、MoE或多层巨大网络来掩盖源契约缺口。

### 观测和费用

每条路径记录完整93帧LPIPS、动作路径、P后C/A使用、首次D间隔、P到下一更新区间的实际成本、全部拒绝/失败、dense branch与pair两种计数、clean采样时间和完整推理时间。不能把head调用节省当整模型加速。

预期成本只用可部署统计；查真实后果选赢家仅用于离线oracle对照。

## 5. N3：P执行器成本的下一步，而不是无限尝试floor

当前P比D只省约1.29%，任何选择器都不能凭空创造大幅成本差。先清楚P的角色：

- 替代D：只有约0.08089秒/双分支更新的直接节省。
- 插入C：额外约6.00485秒，几乎需要减少一次后续双分支D才能直接回本。
- 延长复用：应看完整区间费用，不能只看P后的第一次C。

若来源一致候选能支撑复用，就以同一选取策略、同一50%活跃率，将部分MLP覆盖从4层扩到8层或12层，先选实际MLP成本较高且显存可承受的层。先确认缓存合法初始化；不一边改层数、一边改mask、来源规则和校准目标。

若attention成为主要剩余瓶颈，再用现有块稀疏入口做一个组合版本，完整计入mask、访存和同步。attention边稀疏和部分MLP不是同一算法，也不等于稀疏更新整段深层的所有token。

这项扩展与N2可以在开发层面协同，不必等论文级证据才允许组合；但每次版本、校准数据与结果都需有清楚标签。

## 8. 成功、修订和暂停的解释

- 一致读出修复NONZERO退化：积极信号，但先看正确简单组合，再宣称复杂调度创新。
- 融合后的校准误差更好、闭环也改善：支持“有误差的来源应被估计而非盲信”的方法。
- H=2不优于H=1：保留便宜H=1，并不否定来源设计。
- 新来源规则保持质量却不省时：调整P执行成本/使用位置，报告质量—时间权衡，不夸大DD减少。
- P仍不优于同配置RA+A：无P方法可进入论文主表，P继续作为有界开发或机制分析；不要求整个项目跟着失败。
- 小样本或误差条跨零：INCONCLUSIVE；不是自动STOP，也不是自动扩预算。

本轮不使用“全部四场景都必须超过10%”这样的硬门槛。观察一致性、绝对收益、尾部退化、真实成本和额外模型复杂度，再决定下一笔投入。
