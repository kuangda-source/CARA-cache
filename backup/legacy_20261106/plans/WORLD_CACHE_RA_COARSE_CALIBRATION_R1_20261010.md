# RA 首版共同锚点校准（2026-10-10）

目的：把已经接通的 RA 联合控制器变成有本地观测依据的候选，为完整视频 BASE-R、联合 W1 与稀疏／部分计算组合提供入口。首版采用有限观测的粗校准，随后由完整视频和成本结果指导修订。原生接口实验、旧科学结果与冻结卡保持；本卡是独立问题及独立范围。

在已曝光的 Common/Human seed3 上使用共同 D6 采集策略：逻辑步1–7、13、19、25、31、36双分支完整计算，其余双分支复用。OFF/ON每场景各一个完整父路径；ON在完成12、22、32步后采集两臂。对应当前动作步13、23、33，共同dense锚点7、19、31，年龄6、4、2。年龄与阶段在这个小设计中混合，不能声称分辨了它们各自的规律，也不能用已有混合锚点teacher代替这些自身共同轨迹。

每个起点从相同latent、完整UniPC历史、条件、噪声、生成器、缓存银行和共同策略历史出发，执行真实CC或DD两个post-denoise分支，保持实际CFG算术 `c+7(c-u)`。已测current guided仅在本步原始求解器输入上复用一次，之后双支DD续推到第36步。保存两支、guided和最终latent四个真实FP32张量；当前分支及guided误差与终点差异是校准标签，不是新策略质量结果或未来时间节省标签。

完整真实模型候选范围为4父路径／4完整93帧视频、6同状态起点、12完整子后缀；144父solver加168子solver，共312solver／624实际net调用。子后缀当前已测12pair复用到本步，之后156dense pair，不能重复当前net调用并漏计。每个后缀恢复物理状态及新增执行器自身history／anchor／last；任意分支失败丢弃整批，记录失败，不声称任意故障均可安全回滚继续。

每个父OFF与ON的全36guided、完整solver返回、条件／RNG、状态检查点、最终latent及完整视频必须相同，证明采集没有改变父策略。此处OFF是关闭反事实采集，两个父均执行共同D6策略。它不代替原生接口卡，也不把共同D6当已有效的加速方法。

首版预登记估计规则：对实际六起点两支误差向量计算cosine，所有已定义观测等权取中位数作为全局相关性先验；按13／23／33各两场景的 `||final_CC-final_DD||₂ / ||guided_CC-guided_DD||₂` 已定义值取中位数作为三个传播gain，逻辑时间内线性插值，两侧取最近已测阶段。零分支误差的rho及零guided误差的gain保留undefined，不补0／1；任何阶段没有合法gain或全部rho均undefined，不生成可部署表。

估计相关性只用于共同锚点年龄≤6的grid；更旧或缺项回退DD。grid所有格明确标为estimated prior，不称真实逐格观测。传播gain吸收本步步长和完整UniPC续推，阈值仍须有限调节；绝对终点norm与相对paid delta_y不是同一个量，表的有用性由后续完整策略结果检验。不能用拟合或局部相关性代替视频收益。

当前仅冻结并执行受影响核心CPU卡：实际RF/WC/UniPC源码与Toy权重／attention，两flow各完整4父＋12子，共8父、12起点、24子、624solver／1248net。检查真实OFF/ON父张量相同、完整后缀、状态和新增history恢复、原始张量实际重读、表重建以及拒绝缺起点／改估计／Toy表进入真实部署。无CUDA、实际2B、真实视频、GPU提交或账本写入。

真实模型卡在核心CPU与生产batch／资产验证后另行冻结。完整费用需计入4父、12当前pair、156未来dense pair、实际模型加载、状态复制恢复、写盘与清理。初估采用三批非嵌套teacher计时最大69.116672秒、完整父最大925.025799秒、加载实测最大620.284490秒，加新开销与余量；不能把父平均pair时间当严格上界。首窗口原MF-R 2.5GPUh是预算提案，若完整真实校准估计超过该建议，显式更新分配，不削减对照。

完整单次≤4GPUh按[现行权限](WORLD_CACHE_EXECUTION_POLICY_20261010.md)直接推进，>4GPUh具体确认。48GPUh窗口和全部历史实费继续计账。完成本地表后尽快进入RA完整视频，再加入guided目标W1、协调稀疏／部分MLP及来源感知选择；不增加非必要人评。
