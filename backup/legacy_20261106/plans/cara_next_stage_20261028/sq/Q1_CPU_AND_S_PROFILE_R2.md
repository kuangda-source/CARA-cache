# Q1 受影响 CPU 路径与 S 支持域 R2

本轮遵照持续推进目标，继续已有 CPU 准备授权。无新 GPU、训练、模型采集、预算预约或 cap 调整。长程 GPU 卡获准并实际启动后，按该唯一 launch 的开始时间与整卡 ETA 安排一次半程和终态验收；现在不为尚未启动的实验创建虚假检查。

Q1 执行器已具备八角色：原 C、FP32 M 变换回转 C、I/M 各三个固定 bit 组合。先核对原 C 与同状态 B1 原输出逐值相等；失败则在任何 codec 评分前退出，不放宽容差。每点私有输入，异常恢复 WC/solver/buffer/mode/RNG；保留 q_total、q_codec、两倍交叉项与共同 teacher 归一化。完整 12 状态到齐才运行留一 prompt，随后固定一套全局方向；未压 raw 只作离线 teacher，不报告部署缓存或峰值节省。

本轮双端 CPU 容器各限 2 核（4/5）、8 GiB（含 swap）、1800 s 软墙钟及 10 s 终止余量、单文件 64 MiB、tmpfs 2 GiB、nice10/idle I/O；禁网、隐藏 GPU、原件只读。单端分配 vCPUh 硬上界 1.00556，双端 2.01112；实际 wall、CPU、RSS 单独计量。先恢复相同 stage/launch；存在则不派第二份。

服务器检查包括：9 个新增路径/选择/故障控制；实际固定运行时条件类与 Enum 导入；A6000 上复用 B1 的 12 状态核对真实条件对象恢复、tensor dtype/引用绑定与严格过去锚点；固定 2B checkpoint 的只读 SHA 与 final-layer tensor 元数据。只 mmap checkpoint，不构造完整模型、不执行 head/deep、不采样新状态，不保存权重。四卡没有 B1 raw，先做同一科学源码和运行时/权重检查，不冒充已验证其 B1 数据接线，也不自动复制 bulk。

S 的 max-age=6 来自旧 26D scout 诊断工具，生产 Shared25/DEV profile 的年龄支持为 28。R2 在新父轨迹数据产生前绑定后者，同一语法用于所有风险及简单对照；D24 作为不采该位置标签的 S 设计限制额外保留。结构候选因此为170（R1 的158及其回执保留）。Uniform19 沿主线真实 sigma 规则的已具体化掩码，在该生产 profile 合法；无 teacher 的时间先验角色明确为其别名，仅执行一份。生产年龄支持不是对未见历史的误差接受，仍需父轨迹与实际运行控制。

GPU Q1 的96正式 C pair只是基本机制分母。完整卡还要绑定加载、预热、数值控制、计时重复、编码/传输、I/O、释放与失败余量；新 CPU 证据与完整报价完成后再处理卡级授权。S 公共采集继续保持108标签、最多56额外 Dense teacher pair、最多52 shadow C、最多10父路径，以及仅F19的8个raw；不把它们静默加入Q25。
