# S/Q不成立时：按失败位置选择备用，不以新名字复活旧卡

本文件是条件性候选池。仅在主实验回答了为什么失败之后，最多选择一条进入新的GPU探索。原IG、R4、F/B、旧GRAPH、单支刷新和在线probe门控不自动恢复。

## 1. 先区分失败，不把一个结论扩大成整个方向否定

| 观察 | 优先处理 |
|---|---|
| 19D本身有高保真，但S与DIAG/模板同mask | 当前CFG信息未改变决策；先用唯一预登记新预算/网格检查一次，不强行制造差异 |
| S改变mask、局部q更好，但终点更差 | 启用B-S：终点响应与跨步交互，而不是继续拟合更精确局部q |
| S/Q实现或资产不完整 | 只修受影响工程，不写科学失败 |
| Q隐藏重建好，actual CFG读出不佳 | 检查非线性路径和输出目标，不能再仅按7.5决定bit |
| Q共同/差分无增益，但相邻真实锚点差额明显小 | 允许B-Q预测残差编码CPU筛查 |
| Q有很强容量收益、没有速度收益 | 作为memory-fidelity贡献；不为追1.5×强行改codec |
| 19D保真差、21/25D好，Q整体内存占比又很小 | 允许B-E既有低精度本体执行器小试，改善每次D成本 |
| S/Q与备选均无稳定增量 | 保留已证实工作点，明确方法贡献仍缺；不将负结果自动称成熟分析论文 |

## 2. B-S：用少量终点响应估计“刷新之间的交互”

### 触发原因

S只利用逐步局部q，忽略跨时间误差方向与多步求解器历史。若同状态排名合理但完整生成排序失败，新的信息不是又一个频带，而是终点方向。

### 精确定义

固定一个完整基础计划π，参考Native输出，使用事前固定的终点特征φ。第一版可用保存的final latent或冻结特征，不能把它等同LPIPS。令

    E0 = φ(Vπ) − φ(VNative)
    δ_i = φ(Vπ⊕i) − φ(Vπ)

其中i是合法、同D配额的离散交换，π⊕i必须真实自然续推。对平方φ误差：

    L_i − L_0 = 2<E0,δ_i> + ||δ_i||².

不能仅用||δ_i||小判断i好；还要看它与现有误差的方向。

两个交换i,j的联合响应：

    η_ij = δ_ij − δ_i − δ_j.

如果η小，则组合误差近似

    ||E0 + δ_i + δ_j||²,

其中2<δ_i,δ_j>表示干预之间的强化/抵消。若η大，说明状态/历史相互作用强，简单可加预测不足。

### 最小可证伪实验

从F19-C出发，预先固定两个互不冲突的合法交换例子：
- i：D10→D9；
- j：D27→D23。

两者及联合作用均保持19D，原保护点保留，最大cache年龄不超过当前候选的合法上限；执行前以真实语法验证。

2旧CAL×{π,π⊕i,π⊕j,π⊕i⊕j}=8条机制输出。Native/π合法资产优先复用，warm/控制和额外保存另报；规划约1–2GPUh而非费用承诺。保存完整solver/cache/RNG状态，不能只恢复latent拼后缀。

输出每个干预的LPIPS/终点φ差、η大小、两个prompt方向和实际时间。所有四格预先登记，不看到赢家后挑第二个位置。

### 成立以后才发展成方法

不是八条视频就能学习36步的价值函数。只有发现稳定交互且少量真实干预能预测未参与选择的交换，才登记：低维终点响应模型、最多一轮新增校准、固定提案语法，以及相同终点评价次数的BudCache式搜索/贪心对照。[P2]

候选差别应是用有限真实响应处理非可加效应，而不是宣称“终点优化/预算搜索”首创。ERTACache等已讨论缓存误差传播和轨迹校正，必须正面比较，不把一阶公式包装成独有理论。[P4]

### 止损

若响应在两个prompt间无可迁移规律、交互很强但不能用低成本观察预测、或必须大量视频搜索才能找到胜者，则不扩大到全矩阵。允许将发现写入机制分析，但不自动成为核心方法。

## 3. B-Q：对真实D锚点做预测残差编码，而非预测未知当前深层

### 为什么它与失败的DEEP不同

失败的DEEP用过去趋势猜“当前未计算的深层输出”。这里当前D已经完整计算出R_s，编码器知道真值，只压缩已知值相对已存预测的差额。

令预测器P首轮固定为最近已重建锚点的恒等复制：

    b_s = P(Rhat_previous)
    Δ_s = R_s − b_s
    Rhat_s = b_s + Decode(Encode(Δ_s)).

如果编码器和解码器使用相同的已重建b_s，则条件于实际父状态：

    Rhat_s − R_s = Q(Δ_s) − Δ_s.

这避免了用原始旧锚点编码、用量化旧锚点解码产生的额外失配；不等于量化误差对生成轨迹不累计，也不保证残差一定小。

该思想属于经典预测量化/DPCM，也已有KV缓存预测编码工作。新贡献必须落在跨去噪锚点窗口、实际CFG读出、生命周期和同字节优势，而不是“第一次差分编码”。[P5,P6]

### 首轮CPU比较

固定同一个实际Q码率与量化器：
1. 绝对I编码；
2. 原Q共同/差分编码；
3. 恒等预测的差额编码。

只用真实D锚点，单条链不超过现有必要窗口长度，或每两个锚点重置keyframe；不保存无界历史、不增加新外推阶数。所有必要keyframe、delta、指针、scale和scratch完整计入。

如果原C必须保留两锚点，则可存一个绝对keyframe与一个delta；旧窗口淘汰时按事前规则重基准。重基准/解码延迟、重构缓存驻留必须记录，不靠额外高精度常驻副本假装省内存。

### 继续条件

相同完整驻留bytes下，差额编码在留出prompt上更准；或者相同失真下明显更省，并且actual C解码路径不抹去收益。只看差额范数小不够，归一化scale、量化误差、溢出和代码开销也要测。

没有明确优势即停。禁止扩展成多种预测器+熵编码+SVD+学习码本的组合搜索。

## 4. B-E：若瓶颈在D，使用现成低精度执行器作为速度保险

### 触发条件

19D/18D为了提速损失太多保真，而21/25D仍可用；或者Q节省的缓存占比太小，无法影响完整推理。此时与其继续压缓存，不如降低每次完整D的实际成本。

### 最小测试

只使用已有、与目标GPU和Cosmos路径兼容的低精度执行器。没有可用kernel就暂停，不从头开发量化框架。先做真实kernel profiler和输出等价控制；存储低bit但实际BF16算不算加速。

2旧CAL×2×2：

| | 原模型精度 | 低精度模型 |
|---|---|---|
| Native全计算 | N | N-Q |
| 已验证25D布局 | C25 | C25-Q |

共8正式，加载/预热/codec/评分另计。报告相对原精度Native的总偏移、相对量化Native的缓存增量、两种时钟与真实质量。不能把两个LPIPS相加。

若组合有用，先视为正交部署组件；CacheQuant已有量化和缓存共同优化，SVDQuant也强调量化与融合kernel共同设计。不能以“缓存+量化”本身作新颖性。[P3,P7]

不同时加混合精度调度、单支刷新、token稀疏或蒸馏。组内已有量化工作，应优先复用兼容成果、明确职责，而非另造同一课题。

## 5. 备选优先级与止损原则

S局部→终点失败时，B-S优先；Q跨支表示失败但时间冗余明显时，B-Q优先；算力执行瓶颈优先B-E。没有对应失败证据，不执行备选。

最多一条备选进入GPU；一次备选只改变一个科学因素。若结果接近但方向一致、费用小，可做一次冻结追加，而不是以5%机械淘汰；若靠特定prompt/步号选择才成立，不扩模块救结果。

如果S有效，Q失败，不需要备选Q来凑第二贡献。若Q有效而S失败，可以形成内存保真贡献，但不能据此补上高速调度的新颖性。所有实验成功并不自动保证投稿级别；主张应落在真实得到的机制与外部前沿。
