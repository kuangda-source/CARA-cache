这份包将 v5 严格审阅转成可交给原 Codex 项目的实验与论文修订任务。

## 推荐阅读/使用顺序

1. `02_Codex_Execution_Handoff.md`：可直接复制到原对话的执行指令。
2. `01_Prioritized_Solutions_and_Experiment_Plan.md`：完整问题映射、实验矩阵、复用与预算设计。

4. `04_Review_Issue_Closure_Matrix.md`：逐项关闭审稿问题、更新论文主张。

- 新区间方法不再由旧H1/Efficient的主表、时间与质量结果代为证明。

- 同A次数位置对照、直接近邻和真实费用成为优先证据。
- 25D/26D只是计算配额，正式效率主张基于同队列真实质量—时间。
