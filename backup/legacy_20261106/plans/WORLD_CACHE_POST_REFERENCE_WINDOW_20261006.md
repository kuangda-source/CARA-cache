# WorldCache 五参考补验后的调度：W3 位置价值与 W1 自身轨迹诊断

2026-10-06；v4.1。当前科学证据见[138 完整报告](../research/138_WC_W1_APPROVED_FIVE_REFERENCE_EXECUTION_AND_RESULTS.md)。[v4.0 原计划](WORLD_CACHE_CONFIRMATION_WINDOW_20261006.md)、旧登记、旧结果和失败费用原字节保留。本轮只完成直接获批的 W1 五参考卡；以下新实验设计不是 GPU 授权。

## 1. 新发现及执行选择

五份缺失 Native35 参考全部生成并被接受，21 个可用视频完整解码通过，14 对 CPU FP32/Alex LPIPS 完成。原 8 场景/7 个 W1 接受/1 个拒绝不变。七个可配对场景 **4 改善、3 退化**；等场景平均 LPIPS 从 0.410505 降至 0.408704，仅降低 0.4388%。四个改善场景各 93/93 帧改善；两例大退化各 93/93 帧退化。旧 Common/Human 分数完全复现。

这是全局标量配置的场景异质性证据：既有正信号被补充为完整 CAL 接受子集，不能再从两个约 8% 的正例直接进入“稳定收益”表述。也不能从三个退化场景否定 W1 或整条 WorldCache。工业场景 LPIPS 退化 2.23% 而 MUSIQ 提升，进一步说明保真与成像代理不能混作一个标签；旧 MUSIQ 3 升/4 降、开发 VQA 6 平/1 降保持。

**执行优先级仍是完成已准备的 W3-B 四交换。W1 保留为条件诊断候选，暂不直接扩展到分组、Head、LoRA、专家训练或大规模独立确认。**重大选择由本轮结果与用户共同讨论；不取消或重提已经完成的卡，不自动扩大权限。

## 2. 负结果实现与目标对齐检查

新增 Native 每场景 36 更新/72 CFG、72 次完整深层、0 cache skip；请求、模型/decoder、后端及冻结源匹配。全部新旧视频 SHA 和实际账本原件独立回读通过；旧候选的过去 anchor、后端 flags、72 条执行记录有效，未发现据此需要修复的实现错误。复用旧通过的 OFF/ON parity 与固定 mask 控制，不重跑同源 CPU 或 GPU。

已有机制标签是在原 WC/OFF 状态上比较近似；完整 W1 视频来自候选自己的状态。内部改善不能自动跨状态迁移，也不能替代终点保真。`misc` 的局部和终点同时退化；AV51 局部改善却终点退化，需要区分自身轨迹上的近似恶化与误差传播/目标差异。

旧日志探索性核查发现：`misc`、AV51 的自然缓存判断与固定 mask 分歧 14/16 次，其余接受场景 0–8 次。它们并非因果标签，不能据此给部署策略拟合阈值。Human 有 4 次系数触及旧 clip=4 却改善，AV51 无截断却退化，不能把截断当作唯一原因。见[原日志条件分析](../reports/wc_w1_existing_replay_conditions_exploratory_20261006.json)。没有新测量的 drift 幅度，不用哈希或动作分歧数冒充数值漂移。

## 3. W3-B 完整卡保持原设计

继续沿用[132 生产卡](../research/132_WC_W3_PLACEMENT_PRODUCTION_CARD_AND_CPU.md)：2 父、16 完整后缀、10 输出、四联合位置交换，Common 的 CFG0/1 配额 18/17，Human 20/18。保护动作、重复、历史桥和六个全帧损失全部保留。源码与已通过实际 CPU 的闭包不改，总 9600/child9570/kill5；只在该卡具体范围批准后执行。

W3-A 的自适应总效果与 B 的固定配额位置效果互补。A 中后续调用数变化是干预结果；B 不能作整个方向的唯一门槛。B 若混合或负且控制有效，只解释原四交换及条件，不抹去 Human 的 A 正信号，不要求 4/4 为正。核对逐 CFG 配额与真实成本后再决定是否冻结简单位置规则。

## 4. W1 下一低成本区分实验：自身轨迹上的同状态 shadow

新登记见[post-reference 假设](../manifests/wc_post_reference_hypotheses_r1_20261006.json)。这是看过完整 CAL 后为**未来新 teacher 观测**预先登记的设计，不追认既有结果为预注册确认。

限定三个已曝光场景：负例 `misc_13398218_3840_2160_60fps`、负例 AV51、正对照 AV28。seed0、旧全局 scalar 参数、原 fixed mask、采样/decoder/后端不变。固定观测 calls45/46 和67/68 两个 CFG 对；每个 CFG 对必须从同一实际 solver 输入获得两分支，禁止分别推进 sampler 后配对。

候选自身当前状态上同时保存：官方 WC 近似、W1 近似及完整计算 teacher。teacher 只用于离线测量，不写入部署 cache、校准、latent、solver history 或后续动作；用旧 OFF 与新增 shadow ON 的逐调用输出、cache/校准终态、trace/视频身份检查不干扰性。当前实现尚未接线，不能称此诊断已经执行。

先场景内归约，再报告三个场景的 signed 局部误差，不把 12 个观测当作 12 个独立视频。若负例在自身状态上 W1 局部近似也恶化，支持优先检查校准迁移/候选状态问题；若局部仍改善而终点退化，优先检查传播、误差方向或监督目标。混合结果原样保留；该实验不唯一证明调度原因，也不自行产生正式 W3 训练标签。

下一步是否试 W1 自适应 mask、收缩或简单回退，由该诊断和 B 共同决定；一次只选一个预先冻结的变体，不能从这七个已知结果中拟合一个场景名单路由。必要实现/实际 CPU/费用绑定完成后另提具体卡，纸面暂留 1800 秒，**没有批准或启动**。
