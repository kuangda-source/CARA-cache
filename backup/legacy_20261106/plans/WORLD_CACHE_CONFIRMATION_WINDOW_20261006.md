## 2. W3 保留两条互补证据线

### A：自适应系统中的单动作总效果

两臂从同一真实状态出发，仅改变当前 C/D，之后使用同一个已冻结自适应策略。后续 latent、cache、UniPC 历史、动作数和成本可不同：这些是干预后的结果，不能一概当作外部混杂。

每个样本分别保存 `Y_q = L_C − L_D` 与 `Y_t = T_C − T_D`，连同两 CFG 的当次/后续/全窗口调用数。先画质量—成本配对，保留四种符号组合；不在两个已知点上拟合权重。未来若采用 `A_lambda = Y_q + lambda*Y_t`，必须在新数据前固定单位、lambda、成本边界和预算条件。已有后缀 wall 只标 `diagnostic_suffix`，不能与 `deployment_pipeline` 混算或直接作正式训练目标。

Common 原 WC 已选 D，作为保留正确决策的对照；Human 原选 C，有单点修改空间。策略不能因只学习有害复用样本而变成“总是刷新”。后续便宜特征只能使用决策时已可获得的量；当前没有 probe 漂移数值，哈希不冒充漂移幅度。

### B：固定调用配额的位置联合干预

完整复用 [132 已通过实际 CPU 的生产卡](../research/132_WC_W3_PLACEMENT_PRODUCTION_CARD_AND_CPU.md)，不重跑相同 Toy 或改变已冻结源：

|---|---|---|---|
| Common | 47→49 | 48→50 | 18/17 |
| Human | 61→63 | 46→48 | 20/18 |

卡 `WC-W3-PLACEMENT-SWAP-R1-20261004-A`：2 父轨迹、16 完整后缀、10 新输出、四交换；OFF/OFF、BASE 重复、两 swap 正反重复和历史参考桥全部保留。仅两个指定位置不同，各臂状态自行演化；逐 CFG 配额相同不等于秒数相同。保护动作自然冲突则记录不可行、保留原分母，不覆盖保护或临时换点。

六全帧损失和四有符号位置诊断沿用原评分合同，另按本计划联合质量、成本和适用条件解释。四交换不是四个独立场景，双位置联合收益不是单步刷新标签。原“10%”条件保留其历史用途，作为扩大投入的参考，不用它或“4/4 必须为正”否定方向。

若 B 正：说明存在同配额位置价值，再冻结一个廉价规则；若 B 混合：检查位置、阶段、CFG、误差传播和实际成本，按登记提出少量区分；若 B 负且控制通过：只反证这四个固定交换，不据此抹去 A 的自适应总效果。A 和 B 不互为唯一验收门。

## 4. 随后只确认一个简单候选

## 5. 将诊断成本与真实部署成本分开

后续真实计时使用 2 个固定场景、每场景 3–5 对平衡顺序的重复；重复数在执行前按预算选定。两方法使用同一 GPU、精度、采样、负载准入和暖机规则，完整 pipeline 是主要边界，denoising、加载、评估、离线标注单列。CPU 评分不计作推理速度，恢复/哈希诊断 wall 不替代部署 wall。记录实际 probe、路由、同步、访存等已发生开销；未分离的项目写 UNKNOWN。

报告每对原始 wall、配对差值分布与不确定性，不仅最佳一次；跨场景用场景作为统计单位。小样本不强行宣称稳定加速。更换硬件/实现时另绑定版本，不跨批次拼秒数。
