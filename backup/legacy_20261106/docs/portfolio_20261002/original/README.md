## 相比此前讨论，已经落实的修正

1. WorldCache 本身已包含刷新判据；“当前 W1 固定调度”是隔离近似变量的实验方式，不是说原始 WorldCache 没有调度。
2. cache 步真值不能免费记录；额外教师计算只进诊断预算，不进入部署计时或在线决策。
3. 刷新收益与误差大小不同；同预算反事实与单点额外重算不同。
4. OMR 资源与本地效果是独立门槛；“目标侧梯度”不是向后多 rollout 几个去噪步。
5. 单个收益头不等于专家化蒸馏；单学生有效也不代表 MoE 必要。
6. 固定刷新数、固定激活 FLOPs 和固定真实延迟分别对照，不能相互替代。
7. 三条线不要求强行合并；一个有效模块就可以成为主方法。

## 当前状态与使用边界

本轮核对到的是历史计划、方法文档与公开资料，未获得可确认最新的服务器实验报告。各文档的实际入口必须由项目 CURRENT_STATE、最近结果和预算账本确定；UNKNOWN 不表示从未运行。
