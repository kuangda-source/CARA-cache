# WorldCache＋RA 三模块协同开发：下一轮实验与 Codex 接续

**日期：2026-10-09｜版本：v1.0**
配套原理见 `01_METHOD_AND_MATHEMATICS.md`。本文件是提报方案；不启动 GPU，不覆盖既有报告，不授予新的服务器／付费权限。

## 0. 本轮交付目标

交付一个可完整生成视频的候选系统：

**WorldCache＋RA 联合控制＋CFG 协调 W1＋至少一种真实便宜刷新执行档＋来源质量感知动作选择。**

不再把“是否值得做 W3”作为唯一任务；也不要求 W1、稀疏分别单独成为稳定论文结果才组合。允许有预算的正常方法开发、校准、失败诊断与 1–2 轮针对性修订。

以最简单版本尽早生成完整视频，后续由结果选择修订。不要在进入完整运行前扩展全层×全动作×全历史的局部矩阵。

## 1. 入口与版本兼容

先接续 AGENTS、当前科学状态、运行中任务、权威账本和已批准实验卡。用户最新材料的审计为约 29.8952/50 GPUh、剩 20.1048 GPUh，但执行前刷新；不回滚成 10/4 或 10/5 状态。

已完成的 W1 全帧参考、稀疏算子、恢复设施、真实局部接口和 Toy CPU 控制直接复用。旧结果和超时费用不改写。

旧 H-T63 为 16 条真实路径，预测 6.704 GPUh。建议重新提报分阶段设计：两个场景 × 旧 WC 接口／新成对接口 × 观察 OFF，共四条；根据差异再补 1–2 条观察 ON。它只负责必要接口控制，不应吃掉三分之一开发窗口。

注意 ORIGINAL 是旧 WC 实现，不是 Native 全算；自然执行原策略检查 cnt、ATS、尾部、混合动作与 solver 状态。不通过则修复，不把接口差异当新方法收益。实际单卡是否允许超过 2 GPUh 按现有权限；禁止为绕开上限而机械拆任务。

## 2. 三个工程部件的职责

| 部件 | 输入 | 输出 | 禁止的隐式工作 |
|---|---|---|---|
| approximation | 当前两侧 probe、过去合法 dense anchors、工作源类型 | 两侧修正输出／系数 | C 上先跑 deep teacher；偷用当前真值 |
| refresh_executor | 上层已选模式／密度、真实当前状态与必要工作缓存 | 近似／dense 输出及来源 metadata | 全算再 blend 后宣称加速 |
| action_selector | 决策前廉价观察、预算／时间目标、来源质量模型 | C/A/S/D 及密度档位 | 先把所有昂贵动作做完再挑最优 |

模块输入输出按真实源码映射，不假定已有这些函数名。无需重建自主调度框架。

## 3. MF-00：共同基线和必要控制

**问题：**能否在当前模型中完整运行忠实 RA 风格联合控制，并保持关闭候选时的原行为？

- 两个场景的必要真实接口控制；优先从已准备资产接续。
- 保留原 WC 策略与原深层算子作为关闭态。
- RA 校准使用当前 Cosmos、实际 8/−7 权重、36 更新和 UniPC 时间网格。校准规模与拟合方法记录；不足以称充分复现时标成预算适配实现。
- 原 WC／RA 在同样 CAL、同样调参机会下确定一个中等预算工作点。暂不把 RA 调参变成无限搜索。
- 第一次稳定运行同时记录少量合法 D 的 pre-prediction／post-truth 统计，为 MF-A 复用；干净计时路径关闭 teacher dump。

**输出：**可生成完整视频的原 WC 和 RA 基线，执行映射、干净时间、极小校准包。

## 4. MF-A：W1 联合修正的第一版

**假设：**两个 CFG 分支共同校准，比独立全局标量更适合 guided 目标；β=1 可分离恒等浅层成分。

**首批对照：**原近似、β=1、现有 W1、CFG 共享修正强度。原 warp、head、保护规则保持一致。

- 先拟合共享 α 或极少数阶段参数，不开逐层×逐 token 模型。
- 使用实际 post-warp/head 输出定义 teacher 损失；分支正则防止过度抵消。
- 可复用已有可靠的成对 tensor；不够时从本轮 4 个 CAL 场景各取 2–3 个合法状态，优先与 MF-B 共用。
- 完整视频先覆盖一个正例（如 AV28）和两个困难例（misc、AV51）及 Human。不要只在 Common/Human 上来回挑 seed。
- 固定路由用于机制隔离；随后尽快接 RA 自适应路由，避免仅保留离线未来掩码结果。

**看什么：**实际 guided MSE、分支误差、系数稳定性、完整 LPIPS、退化帧与额外时间；不要求全部局部点都改善。

**正常修订：**共享系数→受正则约束双系数，或按来源 D/S 分两类。一次只增加一种自由度。若 guided 已改善而终点不佳，下一次修订优先使用范围／来源约束，不机械加模型宽度。

## 5. MF-B1：已有稀疏 attention 的联合改造

**假设：**在同密度下，协调 mask 能改善合成误差；mask 重用能减少路由开销。

**对照：**原生 D、同量化全边 MF、当前独立 S、共同 mask S；共同 mask 稳定后才加入有限 mask 重用。

- 复用原有 kernel 和已知注意力敏感层，不重新跑整个 104 点验收。
- 首批 4 场景 × 2 个合法阶段的真实配对状态，最多 8 个起点；兼容部分直接复用。
- 共同 mask 控制实际保留 QK block 数。首版保留当前深层 c→u 顺序：c 生成每层 mask，u 使用同一 mask 和自己的当前 Q/K/V；测量这种参考分支偏置。
- 不把“两个 probe 先完成”当成“每层两个 Q/K 已完成”。使用两侧当前 coarse-QK 的 max／受限 union，需要逐层交错／batch 接线，并单独计量峰值显存与成本；作为第二实现，不是首版必要前提。不能用更高密度冒充共享策略更准。
- 初版最多两档稀疏强度；原 CDF=0.98 的配置保留为既有点，但 CDF 不等于真实 attention 质量保留比例。
- mask 重用计入跨度和重建成本，不能把每次重建开销漏出计时。
- 比较 guided 误差，不只比较各分支 relative error。

**输出：**至少一个可以作为 S 中间档的完整双分支执行器，其真实整组成本已知。小收益可以先供组合测试，不要求它先独立超过全部基线。

## 6. MF-B2：部分 MLP 刷新

**假设：**attention-only 的剩余成本限制可由部分 MLP 计算缓解，而不必第一版改成逐层 KV 稀疏。

### 最小实现

- 先保留所有 token 的 attention，选 4–8 个层的 MLP 做真正 gather→GEMM→scatter。
- 非活跃块读取该层投影后 MLP 输出缓存；正确重做当前门控／调制；不缓存旧 residual gate 后直接加到新 timestep。
- 首版活跃比例仅 0.5／0.75；CFG 两分支共用块集合，由当前双 probe／既有历史／轮换表确定，不偷用未执行的另一分支深层输入。
- 首先使用同配额随机／轮换块，风险选择是下一对照，不是实现的先决条件。
- 块形状符合实际 token 时空布局与 kernel；不能把视频 93 帧当作 latent token 时间长度。
- 稳定后接 B1 sparse attention；在进入组合前只需一组真实调试和干净组计时，不要求所有层独立发表级结果。

### 必须测的成本

新增层缓存字节、峰值显存、gather/scatter、MLP GEMM、attention、selector、同步、完整组时间；比较原 backend 与匹配量化 backend，避免混淆精度转换收益。

只改部分层时，理论省时用这些层的实测 MLP 占比。若内存不够，减少层数、选择非扩展输出缓存；不默认训练低秩缓存或重写模型分片。

### 首次完整生成

至少覆盖前述困难场景之一，与 RA＋全 dense 刷新配对。调试／计时与理论 oracle 输出分开命名。

若 P0 主要通过减少 MLP 兑现收益，它就是本轮稀疏缓存的正式候选；不必为了题目叫“稀疏注意力”而拒绝 FFN 部分贡献。全深层 RAS-style P1 留作后续明确扩大上限的版本。

## 7. MF-C：来源质量感知的 C/A/S/D 控制

**假设：**给不同精度的缓存源保留正确质量语义，可避免机械稀疏替换导致的过度复用／反复刷新，并让 A 与 S 的收益叠加或互补。

### 初版动作集合

C、A、一个保守 S 档、D。B2 完成后用其替换／补充 S，不同时加入全部 sparse×ratio×单边 CFG 组合。

### 必须实现

- dense 校准 anchor 与工作缓存分离。
- 记录 S 的非零来源误差和实际年龄；P 的“计算过”不等于“精确过”。
- C/A/S 各自的联合 proxy 标定，动作成本用 clean measurements。
- 首版规则／查表；允许小参数拟合，不需要完整终点 Q 网络。
- 配额要求与延迟目标分开。不同 S/D 计数不能直接视为相同预算；最终以完整真实时间比较。
- 模式变化、图像／文本条件、缓存布局、head、backend 改变时清理不兼容状态。

### 两个关键对照

1. RA 触发后用固定比例 S 替换 D，其他行为不改：**直接组合**。
2. 相同动作集合、相同近似器与 sparse kernel，增加来源质量和模式选择：**完整方法**。

若有“把 S 当 D 清零”的消融，标记为朴素实现对照；不能只打败它就宣称超过合理 RA 组合。

### 可选的后续小训练

若局部风险选档已能正常运行，再从少量同状态动作续推获得终点＋未来时间标签，训练小 head 或修正规则。不是必须先采完大量终点标签才允许本轮多精度控制生成视频。

## 8. 最小端到端对照矩阵

完整矩阵分批做，不在所有场景跑全笛卡尔积。

| ID | 方法 | 比较目的 |
|---|---|---|
| BASE-N | Native35／必要时 Native23 | 原生保真与少步强对照 |
| BASE-W | 调优原 WC | 本地原方法 |
| BASE-R | WC＋合理校准 RA | 借用的强联合控制基础 |
| A | BASE-R＋CFG 协调修正 | 修正作用 |
| B | BASE-R＋固定规则近似刷新 | 便宜执行器直接收益 |

稀疏策略的随机／轮换对照主要在相同 S 上比较；不把选区器收益与不同 density 混在一起。

## 9. 数据与验证安排

### 开发侧

沿用 CAL8 已曝光性质；优先四场景 AV28、Human、misc、AV51，之后覆盖剩余接受场景。原拒绝保留，不替换成容易样本。CAL 上允许有记录的方法开发和有限调参，不假装是独立测试。

### 小确认侧

方法冻结后先 4 个未参与设计的新提示词 ×1 seed，最有信息价值时补第二 seed。只跑 RA 与一个候选＋匹配 Native，避免同时放入所有消融。这个规模是筛查，不是正式论文完整验证。

### 投稿侧

随后独立提报 16–32 或更多未曝光提示词、多 seed、三档质量—时间工作点、重复计时和一项迁移。样本数按效应与成本扩充，不宣称某个固定数字自动满足顶会标准。

### 指标

主要：场景等权全 93 帧 LPIPS、真实去噪及完整推理时间。辅助：SSIM/RGB、帧间差分、清晰度、运动／语义与盲评。给均值、中位数、尾部与每场景结果；不把 93 帧或多个状态当独立样本。

完整计时包括候选实际使用的 probe、统计、路由、读写和解码边界；teacher、hash、dump、评测从部署口径分开，但全部入研究账本。观察 ON/OFF 和 kernel 预热记录。后缀恢复不能冒充完整推理加速。

## 11. 正常开发的修订规则

- 修正提高质量但使稀疏源不稳定：做一次来源条件化强度，不立即推翻 W1。
- 稀疏组快但全流程不快：检查实际使用覆盖、mask／scatter成本和后续 dense 频率，再选择优化对象。
- 随机块已很好：保留随机，将贡献重心放在联合更新与动作选择，不强求复杂 selector。
- S 后频繁 D：检查来源误差、密度和刷新寿命；这是组合问题，不能仅以一次 S 快否认。
- 单项弱而组合有效：保留组合并做交互消融，不要求单项先独立成功。
- 一版失败：允许 1–2 轮基于具体问题的修订；修改的是实现／假设，不重开“整个方向是否存在”的宏大审查。
- 预算内合理实现与针对性修订后仍无净收益：记录适用范围和明确原因，保留较强模块；这不等于自动否定整个论文愿景或所有稀疏方式。

工程目标可设为 S 的双分支深层组时间比 D 降低约 10–20%，以及完整方法在匹配质量下比合理 RA 快约 10%，或匹配时间下主要失真下降约 10%。这些是争取方向，不是成功承诺和机械淘汰线。更小但稳定的提升或尾部保护也需综合判断。
