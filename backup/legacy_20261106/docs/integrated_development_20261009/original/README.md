日期：2026-10-09。

本包把 W1、稀疏 attention／部分缓存和 W3 放在同一开发周期，而不是等待每个部件单独成功后才组合。

实验事实依据用户上传的 2026-10-09 总结；没有独立审计服务器。新增方法与数值都是设计提案。没有启动 GPU、修改仓库或覆盖原文档。本文不保证论文录用，但给出可形成有意义方法与证据的开发路线。
