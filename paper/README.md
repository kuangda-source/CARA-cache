# 论文主线与证据

当前叙事为：用经验终点响应和自上次刷新以来的特征漂移构造区间代价，用预算化动态规划生成 D/light-C 刷新布局。方法的准确版本及校准来源见 [MAINLINE](../docs/MAINLINE.md)。

主要结果使用 [八个共同可评输入 R18C/F17](../reports/cara_primary11_r1_20261106/REPORT.md)；辅助结果使用同报告中的五驾驶输入 16/18/21D 质量—时间曲线。固定队列交付、护栏拒绝、重用、单种子与原完整门槛限制一并保留。

实验组织见 [EXPERIMENT_REPORT](../EXPERIMENT_REPORT.md)，尚缺的归因、公平对照和独立确认见 [下一步](../research/09_NEXT_ACTIONS.md)。它们没有因目录整理获得执行授权。
